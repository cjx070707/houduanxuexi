索引：
比如一个六百万的一张表。
你做查询可能要几十秒，就是因为数据太大了


优化就是要去做一个索引加快他的搜索速度

索引是帮助数据库高效获取数据的数据结构

无索引1. 全表扫描 耗费很低
有索引：
可能是 1，二叉树搜索

优点肯定就是提高效率，降低成本
缺点需要注意：占用存储空间并且降低增删改效率，因为要重新构造数据结构
索引默认是 B+树，也叫多路平衡搜索树
语法：
create index on
