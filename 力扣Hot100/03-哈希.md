# 哈希

## [1. 两数之和](https://leetcode.cn/problems/two-sum/)[简单]✅

**题目：**给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** `target` 的那 **两个** 整数，并**返回它们的数组下标**。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751530673112-a0564c81-2b8f-462e-898d-74c30951446b.png)

**思路：**这道题本身如果通过暴力遍历的话也是很容易解决的，时间复杂度在 O(n2)

由于哈希查找的时间复杂度为 O(1)，所以可以利用哈希容器 map 降低时间复杂度

使用哈希表存储， key存储数组值、value存储下标

遍历数组 nums，i 为当前下标，每个值都判断map中是否存在 key == target-nums[i] 的值

如果存在，则找到了两个值，如果不存在，则将当前的 (nums[i] , i) 存入 map 中，继续遍历直到找到为止

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // nums = [2,7,11,15], target = 9   输出[0,1]
        // nums = [3,2,4], target = 6       输出[1,2]
        // 用这两个例子,脑子模拟一遍循环的过程就懂了,拿第二个例子举例
        // 遍历到3的时候去看Map中有没有key=3的
        // 遍历到2的时候去看Map中有没有key=4的
        // 遍历到4的时候去看Map中有没有key=2的
        // key存储数组值、value存储下标
        Map<Integer, Integer> map = new HashMap<>();
        for(int i = 0; i < nums.length; i++) {
            int otherValue = target - nums[i];
            if(map.containsKey(otherValue)) {
                return new int[] {map.get(otherValue), i};
            }
            map.put(nums[i], i);   // 记得存入Map, key: 数组值、value: 下标
        }
        return new int[] {};
    }
}
```

## [49. 字母异位词分组](https://leetcode.cn/problems/group-anagrams/)[中等]✅

**题目：**给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751550825172-9e632a7d-a8d8-442a-bf40-11490803c304.png)

**思路：**本质上题意是把同一类词进行分组，所以可以使用Map（key: 同一类词的相同唯一特征, value: 字母异位词的集合）。由于互为字母异位词的两个字符串里所包含的字母相同，因此对两个字符串分别进行排序之后得到的字符串一定是相同的，故可以将排序之后的字符串作为哈希表的键，而原来的字符串都加入到Value(集合)中

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        // key: 排序后的字符串, value: 字母异位词的集合
        Map<String, List<String>> ans = new HashMap<>();
        for (String str : strs) {
            // 遍历字符串,每个字符串按字母大小排序
            char[] chars = str.toCharArray();
            Arrays.sort(chars);
            // 注意 key 是排序后的字符串
            String key = new String(chars);
            if (!ans.containsKey(key)) {
                ans.put(key, new ArrayList<>());
            }
            ans.get(key).add(str);
        }
        // 遍历完所有字符串,则答案构建完成
        return new ArrayList<>(ans.values());
    }
}
```

## [128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)[中等]✅

**题目：**给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为 `O(n)`的算法解决此问题。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751553400230-a7dda01f-d016-4210-8662-0021afe5fccf.png)

**思路：**

- 先将所有数字存入哈希表，用于快速判断某个数字是否存在；
- 然后遍历哈希表中的每个数字num：

- 如果 num - 1 存在，说明这个数字num不是某个连续序列的起点，跳过；
- 如果 num - 1 不存在，则从当前数字num开始向后查找，统计连续递增序列的长度；

- 记录并更新最大长度。

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        // 输入：nums = [100,4,200,1,3,2]  输出：4
        // 这个示例中,其实有三段递增序列,分别是  1、2、3、4 和 100 和 200
        // 这里的技巧是需要找到递增序列的起始点，例如1 ，例如100，例如200
        // 根据起始点,再去找连续递增的序列，并记录最大长度
        if (nums == null || nums.length == 0) {
            return 0;
        }
        Set<Integer> set = new HashSet<>();
        for (int num : nums) {
            set.add(num);
        }
        int maxLen = 1; // 最大递增序列的长度
        for (Integer num : set) {
            int len = 1; // 当前递增序列的长度
            // 如果 num - 1 存在，说明这个数字num不是某个连续序列的起点，跳过；
            if (set.contains(num - 1)) {
                continue;
            }
            // 如果 num - 1 不存在，说明数字num是某个连续序列的起点
            // 则从当前数字num开始向后查找，统计连续递增序列的长度；
            while (set.contains(num + 1)) {   // 往后找下一个递增元素
                len++;  // 当 num + 1 存在，当前递增序列长度+1
                maxLen = Math.max(len, maxLen);
                num++;  // 往后找下一个递增元素
            }
        }
        return maxLen;
    }
}
```
