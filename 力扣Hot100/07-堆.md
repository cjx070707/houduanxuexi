# 堆

**背景知识：**

- **堆的逻辑结构**和完全二叉树一致，但底层实现是数组（完全二叉树的层序遍历结果存储在数组中）
- 堆每次弹出元素，是从堆顶弹出
- 堆又名优先队列，例如 Java 中的 Priority Queue
- **小顶堆：**堆顶元素是整个堆中的最小值
- **大顶堆：**堆顶元素是整个堆中的最大值

## [215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)[中等]✅

**题目：**给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759648363910-a68af510-a55e-451d-8282-4fe7dd42488e.png)

**思路：**TopK 类题都可以用堆解题，那么要用小顶堆还是大顶堆呢？此时就需要根据其特性结合题目选择。

根据堆的特性 (以及题目要求第k最大值) ，我们需要小顶堆(只存储k个元素)

将来最小值不断弹出，而将偏大值留在堆内

或者这里可以直接巧记，如果题目要求找**最大**，那么就用**小**顶堆。如果题目要求找**最小**，那么就用**大**顶堆

由于题目要求找到第k个最大的元素，因此这里使用小顶堆。**并且记住，堆里我们需要维持只存K个元素**

**整体流程**：当然我们需要遍历一遍数组，将每一个元素都尝试将其加入堆中。

**具体流程**：遍历数组

- 先把当前遍历到的元素 加入堆中，由于堆的特性，会根据大小自动调整顺序，将最小的移到堆顶
- 此时判断堆中存储的元素是否超过k个，若超过k个，则把堆顶的元素弹出，这就维持了堆中元素是k个，且注意此时弹出的是最小值，那么堆内留下的就是偏大的值
- 因为数组所有的值都会加入到堆中，并且经过调整和弹出，会把所有小的值弹出
- 最终遍历完成后，堆中留下的就是k个最大值，并且堆顶就是我们需要的第k个最大值

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 找到数组第k个最大的元素
        // 3 2 1 5 6 4    k=2
        // 作一个小顶堆，只维护k个元素,这样写就是小顶堆
        Queue<Integer> queue = new PriorityQueue<>();
        // new PriorityQueue<>((a, b) -> (b - a)); 如果这样写就是大顶堆
        
        for (int i = 0; i < nums.length; i++) {
            queue.offer(nums[i]);
            if(queue.size() > k){
                queue.poll();
            }
        }
        
        return queue.poll();
    }
}
```

## [347. 前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)[中等]✅

**题目：**给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759650513180-7058fda9-8a69-4375-a0bd-a72332d30fde.png)

**思路：**同上，题目要求前k高，那么就是使用小顶堆，并且堆内只维持k个元素。

与前题不同之处，在于此题需要存储的是"频率"，但本质是相同的。

- 我们需要先统计出所有元素的"频率"，存储到Map中，key是元素值，value是元素的"频率"
- 构建小顶堆，堆中存储的是 Map的<key,value> 键值对，并且排序规则是以value为比较, 即以元素的"频率"大小为比较依据，这样就能使得 "频率" 小的键值对 会被放在堆顶
- 遍历Map中的所有键值对

- 先把键值对加入堆中
- 再判断堆中元素的数量是否超过k个，若超过，则弹出堆顶的元素，这就维持了堆中元素是k个，且注意此时弹出的是频率最小的键值对，那么堆内留下的就是频率偏大的键值对
- 因为Map中所有的键值对都会加入到堆中，并且经过调整和弹出，会把所有频率小的值弹出
- 最终遍历完成后，堆中留下的就是k个频率最大的键值对

- 将堆中剩余的k个键值对都取出其key放到数组中返回即可

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 前k个高频元素,小顶堆
        int[] res = new int[k];
        
        // 统计每个元素的"频率"，存储到Map中，key是元素值，value是元素的"频率"
        Map<Integer,Integer> map = new HashMap<>();
        for(int num : nums){
            map.put(num, map.getOrDefault(num, 0) + 1);
        }

        // 使用小顶堆，堆中存储的是 Map的<key,value> 键值对
        // 并且排序规则是以value为比较, 即以元素的"频率"大小为比较
        Queue<Map.Entry<Integer,Integer>> queue = new PriorityQueue<>(
            (o1,o2)-> o1.getValue()-o2.getValue()  // 注意这样写是小顶堆，反过来就是大顶堆
        );
        for(Map.Entry<Integer,Integer> entry : map.entrySet()){
            queue.add(entry);
            if(queue.size() > k){
                queue.poll();
            }
        }
        
        // 将堆内剩余k个元素结果放到数组中返回。剩余k个元素即"频率"最高的k个元素
        for(int i = 0; i < k; i++){
            res[i] = queue.poll().getKey(); // 由于堆中存的是键值对，所以这里需要getKey
        }
        return res;
    }
}
```

## [295. 数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/)[困难]✅

**题目：中位数**是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

- 例如 `arr = [2,3,4]` 的中位数是 `3` 。
- 例如 `arr = [2,3]` 的中位数是 `(2 + 3) / 2 = 2.5` 。

实现 MedianFinder 类:

- `MedianFinder()` 初始化 `MedianFinder` 对象。
- `void addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中。
- `double findMedian()` 返回到目前为止所有元素的中位数。与实际答案相差 `10(-5)` 以内的答案将被接受。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759651470256-87b02dac-dfe2-4cb7-a70e-dcde3d7bac75.png)

**思路：**这里需要巧思，记住解决方案即可

**人为构造一个大顶堆 leftHalf 和 一个小顶堆 rightHalf，且需遵守如下规定**

- 当数据流元素数量为偶数：规定 leftHalf 和 rightHalf 大小相同，此时动态中位数为两者堆顶元素的平均值
- 当数据流元素数量为奇数：规定 leftHalf 比 rightHalf 多一，此时动态中位数为 leftHalf 的堆顶数
- 规定 两个堆加起来的数是 完整的数据流从小到大的所有数

上述是人为规定，而编码需要遵循上述规则

**举个例子：**

- 若数据流的元素为 1、2、3、4、5，那么 leftHalf 会存储 1、2、3 ，rightHalf 会存储 4、5

- 当求中位数时，由于 leftHalf 的数量 > rightHalf 的数量，因此取出 leftHalf 的堆顶数 3 即为答案

- 若数据流的元素为 1、2、3、4，那么 leftHalf 会存储 1、2，rightHalf 会存储 3、4

- 当求中位数时，由于 leftHalf 的数量 == rightHalf 的数量，因此答案为两个堆的堆顶数2和3再求平均值

**如何实现：**题目中需要实现三个函数：MedianFinder的构造函数，添加元素addNum，取中位数findMedian

- **构造函数中**，构造大顶堆 (预计存放数据流的左半边元素) 和 小顶堆 (预计存放数据流的右半边元素) 即可
- **添加元素addNum函数中**，需要分几种情况，假设需要新添加 num

- 若双端为空(即两个堆都为空)，直接把当前要加入的元素，加入到 leftHalf 即可
- 若插入前，leftHalf 中的数量比 rightHalf 中的数量多 1个

- 若 左半边的最大数 leftHalfTop > num，则应将leftHalfTop加到右半边，把 num 加到左半边
- 若 左半边的最大数 leftHalfTop <= num，则应将 num 加到右半边

- 若插入前，leftHalf 中的数量 == rightHalf 中的数量

- 若 leftHalfTop <= num <= rightHalfTop，则应该把 num 加到左半边
- 若 leftHalfTop > num ，则应该把 num 加到左半边
- 若 rightHalfTop < num，则应该把 rightHalfTop 加到左半边，并且把 num 加到右半边

- **取出中位数的findMedian函数中**，就简单了

- 左半边的数量 大于 右半边的数量，直接返回左半边的堆顶数
- 左半边的数量 等于 右半边的数量，返回左右半边堆顶数的平均值

```java
class MedianFinder {

    // 两个堆加起来的数是完整的从小到大的所有数
    Queue<Integer> leftHalf;        // 大顶堆   一出队出的就是最大的数
    Queue<Integer> rightHalf;       // 小顶堆   一出队出的是右半边数的最小数

    public MedianFinder() {
        this.leftHalf = new PriorityQueue<>(
                (o1,o2) -> o2 - o1
        );
        this.rightHalf = new PriorityQueue<>(
                (o1,o2) -> o1 - o2
        );
    }

    /**
     * 人为固定 leftHalf 和 rightHalf 之前存在如下的大小关系：
     * 当数据流元素数量为偶数：leftHalf 和 rightHalf 大小相同，此时动态中位数为两者堆顶元素的平均值；
     * 当数据流元素数量为奇数：leftHalf 比 rightHalf 多一，此时动态中位数为 leftHalf 的堆顶数。
     */
    public void addNum(int num) {
        // 双端为空
        if(leftHalf.size() == 0 && rightHalf.size() == 0){
            leftHalf.offer(num); // 直接加到leftHalf
            return;
        }

        // 插入前 总共为奇数,且leftHalf的数比rightHalf的数多 1个
        if(leftHalf.size() > rightHalf.size()){
            int leftHalfTop = leftHalf.peek();  // leftHalf大顶堆的堆顶数,即左半边的最大数
            if(leftHalfTop > num){
                // 应该把 leftHalfTop加到 rightHalf ; 把 num 新数加到 leftHalf
                rightHalf.offer(leftHalf.poll());
                leftHalf.offer(num);
            }else if(leftHalfTop <= num){
                rightHalf.offer(num);
            }
            return;
        }

        // 插入前 总共为偶数个,leftHalf和rightHalf的个数相等
        if(leftHalf.size() == rightHalf.size()){
            int leftHalfTop = leftHalf.peek();   // leftHalf大顶堆的堆顶数,即左半边的最大数
            int rightHalfTop = rightHalf.peek(); // rightHalf小顶堆的堆顶数,即右半边的最小数
            if(leftHalfTop <= num && num <= rightHalfTop){
                // num是一个中间数
                leftHalf.offer(num);
            }
            if(leftHalfTop > num){
                // num比左半边的最大数还小,应该把num直接加到leftHalf
                leftHalf.offer(num);
            }
            
            if(rightHalfTop < num){
                // num比右半边的最小数还大,应该把rightHalfTop加到leftHalf,然后把num加到rightHalf
                leftHalf.offer(rightHalf.poll());
                rightHalf.offer(num);
            }
        }
    }
    
    public double findMedian() {
        // 左半边的数量 大于 右半边的数量，直接返回左半边的堆顶数 
        if(leftHalf.size() > rightHalf.size()){
            return leftHalf.peek();
        }
        // 左半边的数量 等于 右半边的数量，返回左右半边堆顶数的平均值
        if(leftHalf.size() == rightHalf.size()){
            return (leftHalf.peek() + rightHalf.peek()) / 2.0;
        }
        return -1;
    }
}
```
