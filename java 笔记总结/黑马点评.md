消息队列： 存放消息的队列
三个脚色：
生产者 -> message queue ->消费者
阻塞队列是 java 自己内存里的队列； 消息队列是独立的中间件（redis Stream、RabbitMQ,Kafka 等）
主要区别： 消息队列是额外的一个东西 ； 第二，消息队列可以保证数据安全（服务宕机或重启）
