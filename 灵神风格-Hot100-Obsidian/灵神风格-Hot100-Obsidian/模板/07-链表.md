# Java 链表模板

## 虚拟头节点

```java
ListNode dummy = new ListNode(0);
dummy.next = head;
ListNode prev = dummy;
```

## 反转链表

```java
ListNode prev = null, cur = head;
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
return prev;
```

链表题每次改 next 之前，先保存原来的后继。
