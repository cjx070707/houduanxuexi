## [53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)✅

**题目：**给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。**子数组**是数组中的一个连续部分。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754462292957-43118990-b853-4fd7-8154-54c0070826be.png)

**思路：**

**关键变量：**

1. `res`：存储全局最大和，初始化为数组第一个元素
2. `sum`：存储以当前元素结尾的最大子数组和

**遍历过程：**

1. **决策点**：对于每个元素 `num`，判断是否将当前元素加入已有子数组或开始新子数组

- 如果当前子数组和 `sum > 0`：

- 说明当前子数组对后续元素有增益效果
- 将当前元素加入子数组：`sum += num`

- 如果当前子数组和 `sum ≤ 0`：

- 说明当前子数组对后续元素没有增益（甚至有害）
- 放弃之前的所有元素，从当前元素开始新子数组：`sum = num`

2. **更新全局最大值**：每一步都检查并更新全局最大和：`res = max(res, sum)`

**为什么这样有效？**

- **正数累积**：当遇到正数时，总是累积它们，因为正数会增加子数组和
- **负数处理**：

- 如果当前子数组和为正，可以承受一些负数（只要总和仍为正）
- 如果当前子数组和为负，立即放弃（因为任何后续元素加上负数都会变小）

- **单个元素**：算法能处理全负数数组，因为至少会选取最大的单个元素

```java
class Solution {
     public int maxSubArray(int[] nums) {
        int res = nums[0];
        int sum = 0;
        for (int num : nums) {
            if (sum > 0)
                sum += num;
            else
                sum = num;
            res = Math.max(res, sum);
        }
        return res;
    }
}
```

## [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)✅

**题目：**以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start(i), end(i)]` 。请你合并所有重叠的区间，并返回 *一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间* 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754473833779-7e3d8369-1803-4bc4-a81a-ad16bf5d7a77.png)![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754473840232-aa738d2c-f10a-4cc0-bb95-b17882bae625.png)

**思路：**

**示例演练**

```plain
输入：[[1,3],[2,6],[8,10],[15,18]]
处理过程：
步骤1：排序后 → [[1,3],[2,6],[8,10],[15,18]]
步骤2：当前区间 = [1,3]
步骤3：处理[2,6] → 有重叠 → 当前区间变为[1,6]
步骤4：处理[8,10] → 无重叠 → 保存[1,6]，新当前区间[8,10]
步骤5：处理[15,18] → 无重叠 → 保存[8,10]，新当前区间[15,18]
步骤6：保存最后区间[15,18]
结果：[[1,6],[8,10],[15,18]]
```

1. **先按照 区间的左端点进行排序**： 使重叠区间相邻，便于合并
2. **遍历处理每个区间（核心逻辑）**

```plain
情况1：有重叠（如[1,3]和[2,6]）
● 判断条件： 新区间起点 <= 当前合并区间终点
● 处理方式： 扩展当前合并区间终点（取最大值）
● 示例：
  ○ 当前合并区间：[1,3]
  ○ 新区间：[2,6] → 终点取max(3,6)=6
  ○ 合并后：[1,6]
情况2：无重叠（如[1,6]和[8,10]）
● 判断条件： 新区间起点 > 当前合并区间终点
● 处理方式：
  a. 保存当前合并区间到结果列表
  b. 将新区间设为新的当前合并区间
● 示例：
  ○ 保存[1,6]到结果
  ○ 新当前区间设为[8,10]
```

3. **收尾工作**：**不要忘记** 将最后一个合并区间加入结果

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        // 如果区间数组为空或只有一个区间，直接返回
        if (intervals.length <= 1) {
            return intervals;
        }
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按区间起始点排序
        List<int[]> merged = new ArrayList<>(); // 使用链表存储合并后的区间（便于动态添加）
        // 初始化临时区间的起始和结束
        int start = intervals[0][0];
        int end = intervals[0][1];
        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] <= end) {
                // 当前区间与上一个区间(临时区间)有所重合,更新上一个区间(临时区间)的结束点（取最大值）
                end = Math.max(end, intervals[i][1]); 
            } else {
                // 当前区间与上一个区间(临时区间)无重叠,将上一个区间(临时区间)添加到结果列表
                merged.add(new int[]{start, end});
                // 令当前区间作为新的临时区间
                start = intervals[i][0];
                end = intervals[i][1];
            }
        }
        // 添加最后一个合并区间
        merged.add(new int[]{start, end});
        // 将列表转换为二维数组返回
        return merged.toArray(new int[merged.size()][]);
    }
}
```

## [189. 轮转数组](https://leetcode.cn/problems/rotate-array/)✅

**题目：**给定一个整数数组 `nums`，将数组中的元素向右轮转 `k`个位置，其中 `k`是非负数。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754476721580-67f5ea2e-2ffc-43c1-b554-dec51ebb107e.png)

**思路：**

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754477642123-c8bde690-0861-41b9-bcc1-43a3649bbf51.png)

首先我们**先对**`nums`**进行一次反转**，反转后为`[7,6,5,4,3,2,1]`，观察下反转以后的元素的分布。

我们只需要**对反转后的数组中前**`k`**个元素和后**`n - k`**个元素再分别反转一次**就可以得到轮转后的结果

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int len = nums.length;
        // 对 k 取模，避免 k 大于 nums 的长度
        k = k % len;
        // 整体反转数组
        reverse(nums, 0, len - 1);
        // 反转前 k 个元素
        reverse(nums, 0, k - 1);
        // 反转剩余元素
        reverse(nums, k, len - 1);
    }
    // 定义反转函数
    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

## [238. 除自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)✅

**题目：**给你一个整数数组 `nums`，返回 数组 `answer` ，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积 。

题目数据 **保证** 数组 `nums`之中任意元素的全部前缀元素和后缀的乘积都在 **32 位** 整数范围内。

请 **不要使用除法，**且在 `O(n)` 时间复杂度内完成此题。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754477962596-83b2446a-b8e4-4938-a8da-d348f8f16e05.png)

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754482993012-fe2af16e-ead1-4df8-ba2b-58cf4e635277.png)

**思路：**

[【小白都能听懂的算法课】【力扣】【LeetCode238】除自身以外数组的乘积｜数组 ｜前缀积｜后缀积\_哔哩哔哩\_bilibili](https://www.bilibili.com/video/BV181421S7QY/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

结果 res[i] 等于 nums 中除了 nums[i] 之外其余各元素的乘积

换句话说，如果知道了 i 左边所有数的乘积，以及 i 右边所有数的乘积，就可以算出 结果 res[i]

例如 如果要计算除了3之外的乘积。可以认为是 `3左边所有数的乘积 * 3右边所有数的乘积`

于是引入两个概念，前缀积和后缀积

- 前缀积：第i个元素的前缀积为第i个元素之前所有元素的乘积 pre[i] = pre[i - 1] \* nums[i - 1];
- 后缀积：第i个元素的后缀积为第i个元素之后所有元素的乘积 suf[i] = suf[i + 1] \* nums[i + 1];

那么结果 res[i] = 前缀积pre[i] \* 后缀积suf[i]

因此只需要先遍历两次计算出前缀积和后缀积，再求得结果数组即可

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] pre = new int[n];
        pre[0] = 1;
        // 计算前缀积
        for (int i = 1; i < n; i++) {
            pre[i] = pre[i - 1] * nums[i - 1];
        }
        int[] suf = new int[n];
        suf[n - 1] = 1;
        // 计算后缀积
        for (int i = n - 2; i >= 0; i--) {
            suf[i] = suf[i + 1] * nums[i + 1];
        }
        // res[i]= pre[i] * suf[i]
        int[] res = new int[n];
        for (int i = 0; i < n; i++) {
            res[i] = pre[i] * suf[i];
        }
        return res;
    }
}
```

优化空间复杂度到O(1) （只掌握上面的一种写法就足够了）

1. 使用输出数组存储前缀乘积
2. 使用变量动态计算后缀乘积。

1. 将前缀乘积与后缀乘积相乘
2. 更新后缀乘积：将当前元素乘入后缀

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] res = new int[n];
        
        // 1. 使用输出数组存储前缀乘积
        res[0] = 1; // 第一个元素左边没有元素，乘积为1
        for (int i = 1; i < n; i++) {
            res[i] = res[i - 1] * nums[i - 1];
        }
        
        // 2. 使用变量动态计算后缀乘积
        int suf = 1; // 存储当前元素右侧所有元素的乘积
        for (int i = n - 1; i >= 0; i--) {
            // 将前缀乘积与后缀乘积相乘
            res[i] = res[i] * suf;
            // 更新后缀乘积：将当前元素乘入后缀
            suf *= nums[i];
        }
        
        return res;
    }
}
```

## [41. 缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/)✅

**题目：**给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754483961675-ff87fa95-511c-4f64-85db-efa3cb3ea35c.png)

**思路：**[【力扣hot100】【LeetCode 41】缺失的第一个正数\_哔哩哔哩\_bilibili](https://www.bilibili.com/video/BV1qrVYz6E2Q/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

**核心思想**

- **目标**：在整数数组中找到未出现的最小正整数（例如，[1,2,0] 缺失 3；[3,4,-1,1] 缺失 2）。
- **关键观察**：缺失的最小正整数一定在 `[1, n+1]` 范围内（`n` 是数组长度）。因为：

- 若 `1` 到 `n` 全部出现，则缺失的是 `n+1`。
- 若 `1` 到 `n` 中有缺失，则缺失的最小值在 `[1, n]` 内。

- **核心策略**：通过原地交换，让每个在 `[1, n]` 范围内的数 `x` 回到索引 `x-1` 的位置。遍历交换后的数组，第一个不符合 `nums[i] == i+1` 的位置 `i` 对应的 `i+1` 就是缺失值。

**算法步骤**

1. **原地交换**：遍历数组，对每个元素 `nums[i]`：

- 若 `nums[i]` 在 `[1, n]` 范围内，且它**未在正确位置**（即 `nums[i]` 不在索引 `nums[i]-1` 上），则将其交换到正确位置。
- 使用 `while` 循环：交换后，新到 `i` 位置的元素可能仍需交换（例如，`[3, 4, -1, 1]` 中，`3` 被换到位置 `0` 后，新元素 `-1` 不需要交换）。
- **避免死循环**：若目标位置已存在正确的值（即 `nums[nums[i]-1] == nums[i]`），则停止交换（防止重复值无限交换）。

2. **检查缺失值**：再次遍历数组：

- 第一个满足 `nums[i] != i+1` 的位置 `i`，缺失值即为 `i+1`。
- 若所有位置都满足 `nums[i] == i+1`，则缺失值为 `n+1`。

**举例说明**

- **示例 1**：`nums = [3, 4, -1, 1]`

- 交换过程：

- `i=0`：`3` 应在索引 `2`，交换后 → `[-1, 4, 3, 1]`（位置 `0` 新元素 `-1` 无效，结束循环）。
- `i=1`：`4` 应在索引 `3`，交换后 → `[-1, 1, 3, 4]`；位置 `1` 新元素 `1` 应在索引 `0`，交换后 → `[1, -1, 3, 4]`。

- 检查：位置 `1` 的 `-1 != 2` → 缺失值 `2`。

- **示例 2**：`nums = [1, 1]`

- 交换过程：

- `i=0`：`1` 已在索引 `0`，无需交换。
- `i=1`：`1` 应在索引 `0`，但 `nums[0] == 1`（目标位置值正确），避免死循环不交换。

- 检查：位置 `0` 正确；位置 `1` 的 `1 != 2` → 缺失值 `2`。

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int len = nums.length;

        for (int i = 0; i < len; i++) {
            while (nums[i] >= 1 && nums[i] <= len && nums[nums[i] - 1] != nums[i]) {
                // 当前数nums[i]满足在指定范围内[1,len]、并且没有放在正确的位置上，才交换
                // 例如：数值 3 应该放在索引 2 的位置上
                // 其中nums[nums[i] - 1] != nums[i] 这个判断是为了避免存在重复的元素而导致死循环
                swap(nums, nums[i] - 1, i);
            }
        }

        // 经过上述循环已经使得所有在范围内的数落到映射位置:[1, -1, 3, 4]
        // 此时需要再遍历一次,获取最终结果：若nums[i]!=i+1,那么缺失的就是i+1
        for (int i = 0; i < len; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }
        // 都正确则返回数组长度 + 1
        return len + 1;
    }

    private void swap(int[] nums, int index1, int index2) {
        int temp = nums[index1];
        nums[index1] = nums[index2];
        nums[index2] = temp;
    }
}
```
