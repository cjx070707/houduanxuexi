# 矩阵

## [73. 矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/)[中等]✅

**题目：**给定一个 `m` `x` `n` 的矩阵，如果一个元素为 **0** ，则将其所在行和列的所有元素都设为 **0** 。请使用 [**原地**](http://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) 算法**。**

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762959159740-55a34838-9478-4002-b21d-c29a563d2448.png)

**思路：**使用两个数组，分别记录元素0所在的行数和列数，之后再遍历找到对应的行和列置0

虽然有空间复杂度有更优的解法，但是使用两个数组的方法更容易理解简单

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        if(matrix == null || matrix.length == 0){
            return;
        }
        int row = matrix.length;
        int col = matrix[0].length;
        // 用来存元素0所在的行数和列数
        int[] rowArray = new int[row];
        int[] colArray = new int[col];
        for(int i = 0; i < row; i++){
            for(int j = 0; j < col; j++){
                if(matrix[i][j] == 0){
                    // 记录 '0'所在的行数和列数
                    rowArray[i] = 1;
                    colArray[j] = 1;
                }
            }
        }
        for(int i = 0; i < row; i++){
            for(int j = 0; j < col; j++){
                // 第二次遍历，找到对应的行数和列数，把其所在的行和列的所有元素 全部变为0
                if(rowArray[i] == 1 || colArray[j] == 1){
                    matrix[i][j] = 0;
                }
            }
        }
    }
}
```

## [54. 螺旋矩阵](https://leetcode.cn/problems/spiral-matrix/)[中等]✅

**题目：**给你一个 `m` 行 `n` 列的矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762960688397-dfd0f50a-8077-4006-84fe-429c7e2334ad.png)

**思路：**初始化四个边界，框定我们要遍历的区间范围

- `left = 0`：左边界（第一列）`right = matrix[0].length`：右边界（最后一列的下一列）
- `top = 0`：上边界（第一行）`bottom = matrix.length`：下边界（最后一行的下一行）

四个边界是会变化的

- 当从左向右遍历完区间范围的第一行时，上边界top应该下移，即top--
- 当从上往下遍历完区间范围的最后一列时，右边界right应该左移，即right--
- 当从右往左遍历完区间范围的最后一行时，下边界bottom应该上移，即bottom--
- 当从下往上遍历完区间范围的第一列时，左边界left应该右移，即left++

注意随着每一次遍历完成，边界的改变，"区间范围"是变化的

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        int left = 0, right = matrix[0].length; // 右边界是最后一列的下一列
        int top = 0, bottom = matrix.length;    // 下边界是最后一行的下一行
        List<Integer> res = new ArrayList<>();
        // 最后遍历完中间的元素时,
        while(left < right && top < bottom){
            // 1.遍历区间范围内的最上面一行（行固定，列在变）
            for(int i = left; i < right; i++){
                res.add(matrix[top][i]);
            }
            // 遍历完最上面一行, top(上边界)应该下移
            top++;
            // 如果上下边界重合,说明遍历完成 (例如如果矩阵只有一行)
            if(top == bottom){
                break;
            }
            // 2.遍历区间范围内最右边的一列（列固定，行在变）
            for(int i = top; i < bottom; i++){
                res.add(matrix[i][right-1]);
            } 
            // 遍历完最右边一列, right(右边界)应该左移
            right--;
            // 如果左右边界重合,说明遍历完成
            if(right == left){
                break;
            }
            // 3.遍历区间范围内最下面的一行（行固定，列在变）
            for(int i = right-1; i >= left; i--){
                res.add(matrix[bottom-1][i]);
            }
            // 遍历完最下面一行, bottom(下边界)应该上移
            bottom--;
            if(top == bottom){
                break;
            }
            // 4.遍历区间范围内最左边一列（列固定，行在变）
            for(int i = bottom-1; i >= top; i--){
                res.add(matrix[i][left]);
            }
            left++; 
        }
        return res;
    }
}
```

## [48. 旋转图像](https://leetcode.cn/problems/rotate-image/)[中等]✅

**题目：**给定一个 *n* × *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在[**原地**](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95) 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762963295758-ec52cc20-0cef-4baf-a6fb-dd131d62e90a.png)

**思路：**记住先转置再每行反转即可

```java
原始矩阵：
1 2 3
4 5 6
7 8 9
步骤1：转置后（沿主对角线翻转）得到
1 4 7
2 5 8  
3 6 9
步骤2：每行反转后得到
7 4 1
8 5 2
9 6 3
```

```java
class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;
        // 步骤1：转置矩阵（行列互换）
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) { // 遍历对角线下方元素
                int tmp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = tmp;
            }
        }
        // 步骤2：每行反转（镜像对称）
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                // 交换 matrix[i][left] 和 matrix[i][right]
                int tmp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = tmp;
                left++;
                right--;
            }
        }
    }
}
```

## [240. 搜索二维矩阵 II](https://leetcode.cn/problems/search-a-2d-matrix-ii/)[中等]✅

**题目：**编写一个高效的算法来搜索 `m` `x` `n` 矩阵 `matrix` 中的一个目标值 `target` 。该矩阵具有以下特性：

- 每行的元素从左到右升序排列。
- 每列的元素从上到下升序排列。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762966124314-dd8680e6-b7b1-4a80-bd07-d6292dc10faf.png)

**思路：**从右上角开始与目标值比较

若右上角的数 大于 目标值，那么这一列的数都会大于目标值，那么可以排除这一整列，即 j--

若右上角的数 小于 目标值，那么这一行的数都会小于目标值，那么可以排除这一整行，即 i++

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int i = 0;
        int j = matrix[0].length - 1; // 从右上角开始
        while (i < matrix.length && j >= 0) { // 还有剩余元素
            if (matrix[i][j] == target) {
                return true; // 找到 target
            }
            if (matrix[i][j] > target) {
                j--;  // 这一列的数都会大于目标值，排除
            } else {
                i++;  // 这一行的数都会小于目标值，排除
            }
        }
        return false;
    }
}
```
