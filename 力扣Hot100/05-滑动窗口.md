# 滑动窗口

## [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)[中等]✅

**题目：**给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1752986345376-acddbb0a-bf9e-40eb-bfc5-8d811a830630.png)

**思路：**

基于 **滑动窗口** 的方式来解此题。所谓滑动窗口，其实就是**由两个索引维护一个区间**，**满足一定条件时会动态的去调整这个区间**。这里的两个索引决定了滑动窗口的起点和终点，始终保持滑动窗口中的元素是不重复的，这题就变成了找到包含非重复元素的最长窗口。

- 双指针指向不含重复字符的连续字串的头和尾：定义 right 和 left 指针，初始值都为 0
- 用集合存储子串中的元素：Set<Character> set = new HashSet<>();

**具体流程：**

- 当前窗口为 (0,0)，当前 right 指向元素在当前窗口中不重复

- 因此 `right 指向元素加入集合`、`当前窗口长度++`、`更新无重复字符的最长子串的长度`、`right 指针右移，扩大窗口`

- 当窗口中出现重复的元素时

- 因此 `集合移除 left 指向元素`、`当前窗口长度--`、`left 指针右移，缩小窗口，期望使得窗口内无重复 (注意这里只是期望，并不一定移除了 left 指向元素就会使得窗口内无重复元素，但是没关系，只要继续循环，会重复走入该分支情况，终将会使得窗口中无重复元素)`

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 左右指针维护滑动窗口、Set
        int max = 0; // 无重复字符的最长子串的长度
        int right = 0;
        int left = 0;
        int winLen = 0; // 当前窗口长度

        Set<Character> set = new HashSet<>();
        while (right < s.length()) {
            if (!set.contains(s.charAt(right))) {
                // 当前right指向元素在当前窗口中不重复
                set.add(s.charAt(right));       // right指向元素加入集合
                winLen++;                       // 当前窗口长度++
                max = Math.max(max, winLen);    // 更新无重复字符的最长子串的长度
                right++;					    // right指针右移，扩大窗口
            } else {
                // 当前right指向元素在当前窗口中有重复
                set.remove(s.charAt(left));   // 集合移除left指向元素
                winLen--;                     // 当前窗口长度--
                left++;						  // left指针右移，缩小窗口，期望使得窗口内无重复
            }
        }
        return max;
    }
}
```

## [438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)[中等]✅

**题目：**给定两个字符串 `s` 和 `p`，找到 `s`中所有 `p`的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1752986369834-5f196be6-39df-49bb-97ea-40a1ee9dde82.png)![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759589713702-f529e66f-e8fb-4090-90b5-12585c900047.png)

**思路：**

因为字符串`p`的长度是固定的，那么就需要在字符串`s`中找到长度相同的子串

即需要遍历字符串`s`中所有长度与p相同的子串，此时就可以使用滑动窗口来解决

定义两个索引`left`和`right`

保证字符串`s`中 由区间`[left, right]`组成窗口的长度 始终等于字符串`p`的长度

令这个窗口向后不断滑动，不断检查当前窗口组成的子串字符是否是字符串`p`的异位词

如何快速的判断当前窗口组成的子串字符，是否就是字符串`p`的异位词呢？

- 方案一：把当前窗口组成的子串排序，以及字符串p内部也排序，如果两个字符串排序后相同，则说明当前窗口的子串就是字符串p的异位词。但需要排序，整体时间复杂度就会很高
- 方案二：可以引入`两个数组 (只需要数组的长度为26，因为题目明确了s和p只包含小写字母)`，一个用于记录当前窗口中所有字符的频次，另一个用于记录字符串p中所有字符的频次。那么判断当前窗口是否是字符串`p`的异位词，就只需要判断这`两个数组`是否完全相同。

- 例如【用于记录当前窗口中所有字符的频次数组】的下标为0上的值如果是2，则说明当前窗口有两个a，如果下标为25上的值是1，则说明当前窗口有一个z，以此类推

方案一代码：

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        if (p.length() > s.length()) {
            return res;
        }
        char[] chs = p.toCharArray();
        Arrays.sort(chs);
        // 定义滑动窗口，其长度与p的长度相同
        int left = 0, right = p.length() - 1;
        while (right < s.length()) {
            String win = s.substring(left, right + 1);	// 截取出滑动窗口
            char[] winArr = win.toCharArray();
            Arrays.sort(winArr);
            // 判断当前窗口是否是p的异位词，即判断两个数组是否相同
            if (Arrays.equals(chs, winArr)) {
                res.add(left);
            }
            // 窗口滑动
            left++;
            right++;
        }
        return res;
    }
}
```

方案二代码：

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        if (p.length() > s.length()) {
            return res;
        }
        int[] pCharCount = new int[26];		// 字符串p 所有字符的频次
        int[] windowCount = new int[26];
        // 统计字符串 p 中字符的频次
        for (int i = 0; i < p.length(); i++) {
            pCharCount[p.charAt(i) - 'a']++;
        }
        // 统计滑动窗口中字符的频次,起始状态下的滑动窗口就是[0,p.length()-1]
        for (int i = 0; i < p.length(); i++) {
            windowCount[s.charAt(i) - 'a']++;
        }
        // 定义滑动窗口，其长度与p的长度相同
        int left = 0, right = p.length() - 1;
        while (right < s.length()) {
            // 判断当前窗口是否是p的异位词，即判断两个数组是否相同
            if (Arrays.equals(pCharCount, windowCount)) {
                res.add(left);
            }
            // 窗口滑动,那么窗口中的字符频次也要改变
            windowCount[s.charAt(left) - 'a']--;
            left++;
            right++;
            // 当滑动到最后一个窗口了，想要再次滑动，此时right就越界了，因此这里需要判断是否越界
            if (right < s.length()) {
                windowCount[s.charAt(right) - 'a']++;
            }
        }
        return res;
    }
}
```
