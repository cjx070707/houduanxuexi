# Java 回溯模板

```java
void backtrack(int start) {
    if (/* 到达答案状态 */) {
        ans.add(new ArrayList<>(path));
        return;
    }

    for (int i = start; i < choices.length; i++) {
        if (/* 不合法 */) continue;
        path.add(choices[i]);
        backtrack(/* 下一层参数 */);
        path.remove(path.size() - 1);
    }
}
```
