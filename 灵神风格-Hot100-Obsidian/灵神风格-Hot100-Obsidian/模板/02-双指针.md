# Java 双指针模板

## 相向双指针

```java
int left = 0, right = nums.length - 1;
while (left < right) {
    if (/* 应移动左侧 */) {
        left++;
    } else {
        right--;
    }
}
```

## 快慢指针

```java
int slow = 0;
for (int fast = 0; fast < nums.length; fast++) {
    if (/* nums[fast] 应保留 */) {
        nums[slow++] = nums[fast];
    }
}
```
