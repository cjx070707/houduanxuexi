## [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)[中等]✅

**题目：**给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 *该数组中和为* `k`*的子数组的个数* 。

子数组是数组中元素的连续非空序列。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754140529030-0b0524c9-8038-4593-bca0-02204c4d4ca6.png)

**思路：**

***前缀和的概念***

- 首先，我们使用一个叫做“前缀和”的概念。对于数组中的任何位置 j，前缀和 preSum[j] 是数组中从第一个元素到第 j 个元素的总和
- 这意味着如果你想知道从元素 i+1 到 j 的子数组的和，你可以用 preSum[j] - preSum[i] 来计算

***使用 Map 来存储前缀和***

- 在代码中，我们用一个 Map（哈希表）来存储 **每个前缀和出现的次数**
- 这是为了快速检查某个特定的前缀和是否已经存在，以及它出现了多少次

***核心逻辑解析***

- 当我们在数组中向前移动时，我们逐步增加 preSum（当前的累积和）
- 对于每个新的前缀和 preSum 值，我们检查 preSum - k 是否在 Map 中
- **preSum - k 的意义**：这个检查的意义在于，如果 preSum - k 存在于 Map 中，说明之前在某个点的累积和是 preSum - k。由于当前的累积和是 preSum，这意味着从那个点到当前点的子数组之和恰好是 k（因为 preSum - (preSum - k) = k）
- **如何使用这个信息**：如果 preSum - k 在 Map 中，那么 preSum - k 出现的次数表示从不同的起始点到当前点的子数组和为 k 的不同情况。这是因为每一个 preSum - k 都对应一个起点，使得从那个起点到当前点的子数组和为 k
- 因此，每当我们找到一个 preSum - k 存在于 Map 中时，我们就把它的计数（即之前这种情况发生的次数）加到 count 上，因为这表示我们又找到了相应数量的以当前元素结束的子数组，其和为 k

***例子***

- 假设 k = 7，并且我们当前的累积和 preSum 是 10，如果在 Map 中 3（即 10 - 7）出现了两次，这表示存在两个不同的起始点，使得从那些起始点到当前点的子数组之和是 7

***总结***

- **前缀和+哈希表：**遍历数组时计算前缀和，将前缀和作为key以及出现的次数作为value存进哈希表。对于遍历到下标`i`时，只需要知道在之前的前缀和值为`preSum[i] - target`出现的次数即可，然后把次数相加

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int count = 0;
        int preSum = 0; 	// 不断变化的前缀和
        HashMap<Integer, Integer> mp = new HashMap<>(); // 记录前缀和以及前缀和出现的次数
        mp.put(0, 1);	// 含义为：初始前缀和为 0 出现了 1 次 或者理解为可能存在preSum[i] == k的情况，为这种情况做铺垫
        for (int i = 0; i < nums.length; i++) {
            preSum += nums[i];
            // 核心逻辑: 对于每个新的前缀和 preSum值,检查preSum-k是否存在Map中
            if (mp.containsKey(preSum - k)) {
                count += mp.get(preSum - k);
            }
            // 若当前的 前缀和存在则value+1, 若不存在则插入该前缀和为key & 置value为0
            mp.put(preSum, mp.getOrDefault(preSum, 0) + 1); 
        }
        return count;
    }
}
```

## [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)[困难]✅

**题目：**给你一个整数数组 `nums`，有一个大小为 `k`的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。返回 *滑动窗口中的最大值* 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754325545901-392e7b5b-3465-4acb-9d9a-70d1486b5a35.png)

**思路：**

最简单的解法就是每次移动窗口就重新计算滑动窗口中的最大值，这样就需要遍历一遍滑动窗口，整个过程下来需要遍历`n - k`次滑动窗口，每遍历一次的时间复杂度为 *O(k)* ，所以总的时间复杂度为 *O(k·(n - k))*。实际上我们是可以通过**空间换时间的方式**把获取每个窗口中最大值的时间复杂度变成*O(1)* ，整体的时间复杂度变成*O(n)*。

下面我们根据题目中的例子`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3`，来分析一下整个过程。

1. 对于第一个窗口`[1,3,-1]`，很显然`3`是当前窗口的最大值，而且`3`和`-1`都有可能是未来窗口的最大值，所以我们需要把`3`和`-1`按照顺序保存下来，暂且把它们先保存到`candidate`中，`candidate = [3,-1]`。我们获取当前窗口最大值的时候只需要把`candidate`最左边的元素返回就可以。
2. 滑动窗口向右移一步，窗口中的元素变成`[3,-1,-3]`，`candidate = [3,-1]`中的元素均在当前窗口中，新加入窗口的`-3`有可能是未来窗口的最大值，并且`-3`会比`-1`更晚成为未来窗口的最大值，所以我们把`-3`加入`candidate`中，放到`-1`的右边，`candidate = [3,-1,-3]`。我们依旧把`candidate`最左边的元素`3`作为当前窗口的最大值返回。
3. 窗口继续向右移一步，窗口中的元素变成`[-1,-3,5]`，`candidate = [3,-1,-3]`中最左边的`3`已经不属于当前窗口了，它也不会再是未来窗口的最大值，我们需要从左边把它在`candidate`中移除，`candidate = [-1,-3]`。新加入窗口的元素`5`比`candidate`中的`-3`，`-1`都要大，所以`-3`和`-1`也不会再是当前窗口或未来窗口的最大值，我们把`-3`和`-1`从右到左 依次在`candidate`中移除，然后把`5`加进`candidate`的右边，`candidate = [5]`。我们依旧把`candidate`最左边的元素`5`作为当前窗口的最大值返回。
4. 窗口继续向右移一步，窗口中的元素变成`[-3,5,3]`，`candidate = [5]`中的元素均在当前窗口中，新加入窗口的`3`有可能是未来窗口的最大值，我们把它加到`candidate`的右边，`candidate = [5，3]`。我们依旧把`candidate`最左边的元素`5`作为当前窗口的最大值返回。
5. 窗口继续向右移一步，窗口中的元素变成`[5,3,6]`，新加入窗口的`6`比`candidate = [5，3]`中的`3`，`5`都要大，所以`3`和`5`不会再是当前窗口或未来窗口的最大值，我们把`3`和`5`从右到左依次在`candidate`中移除，然后把`6`加进`candidate`的右边，`candidate = [6]`。我们依旧把`candidate`最左边的元素`6`作为当前窗口的最大值返回。
6. 窗口继续向右移一步，窗口中的元素变成`[3,6,7]`，新加入窗口的`7`比`candidate = [6]`中的`6`要大，所以`6`不会再是当前窗口或未来窗口的最大值，我们从右边把`6`在`candidate`中移除，然后把`7`加进`candidate`的右边，`candidate = [7]`。我们依旧把`candidate`最左边的元素`7`作为当前窗口的最大值返回。

通过上面`6`个步骤我们可以发现：

1. `candidate`中的元素从左到右始终保持单调递减。
2. 窗口每移动一步我们要**从左到右**检查`candidate`中的元素是否还在当前窗口中，如果不在就移除`candidate`中对应的元素。然后**从右到左**把`candidate`中的元素跟新加入当前窗口的元素对比，看`candidate`中的元素是否还有可能成为未来窗口的最大值，如果没有可能就移除`candidate`中对应的元素，然后把新加入窗口的元素加到`candidate`的最右边。
3. 每次从两端调整完`candidate`中的元素，`candidate`最左边的元素就是当前窗口的最大值。

上面的步骤需要对`candidate`两端都进行操作，数组肯定不是最好的选择，最适合的数据结构就是**双端队列**，我们可以很方便的从队列的两端存取，删除元素，保证队列中的元素从左到右单调递减。

可以把双端队列想象成一个"候选人队列"，它有以下特点：

1. **单调递减**：队首的值最大，往队尾方向值逐渐变小
2. **时效性**：只存储当前窗口内和可能成为未来最大值的元素
3. **淘汰机制**：

- 过期的淘汰（超出窗口范围）
- 弱小的淘汰（比新来的小）

**工作流程：**

- 每次新元素进来时，先把过期的候选人踢掉
- 再把比自己小的候选人都踢掉（因为它们永远不可能成为最大值了）
- 然后自己加入候选人队列
- 当前窗口的最大值就是队首的候选人

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        // 创建结果数组：总共有 nums.length - k + 1 个窗口
        int[] res = new int[nums.length - k + 1];
        // 使用双端队列存储元素索引（需要令其保持单调递减）
        Deque<Integer> deque = new ArrayDeque<>();
        
        // 遍历数组中的每个元素
        // [i-k+1, i]（滑动窗口的左闭右闭区间）
        for (int i = 0; i < nums.length; i++) {
            // 1. 移除超出窗口范围的队首元素
            // 检查队首索引是否在 [i-k+1, i] 范围内
            // 如果队首索引 < i-k+1，说明它已离开当前窗口
            while (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
                deque.pollFirst();  // 移除过期元素
            }
            
            // 2. 维护单调递减特性
            // 从队尾开始，移除所有小于等于当前值的元素索引
            // 保证队列中元素对应的值从大到小排列
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();  // 移除尾部较小的元素
            }
            
            // 3. 将当前元素索引加入队尾
            deque.offerLast(i);  // 当前索引入队
            
            // 4. 当窗口形成后（i ≥ k-1）即i必须遍历到k-1才开始有窗口，记录当前窗口最大值
            // 队首元素始终是当前窗口的最大值
            if (i >= k - 1) {
                res[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return res;
    }
}
```

## [76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)[困难]✅

**题目：**给你一个字符串 `s` 、一个字符串 `t` 。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""` 。

**注意：**

- 对于 `t` 中重复字符，我们寻找的子字符串中该字符数量必须不少于 `t` 中该字符数量。
- 如果 `s` 中存在这样的子串，我们保证它是唯一的答案。

**什么是「涵盖」**

看示例 1，*s* 的子串 BANC 中每个字母的出现次数，都**大于等于** *t*=ABC 中每个字母的出现次数，这就叫**涵盖**。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1754325566231-ab56446d-e0c2-4f87-8fef-fdcc71bd6148.png)

**思路：**

本题是经典的滑动窗口类型，解决这类问题的关键是窗口左右边界的滑动策略。

**定义**

- 哈希表`targetMap<Character,Integer>`保存字符串`t`中字符的频率，哈希表`windowMap<Character,Integer>`保存滑动窗口中字符出现的次数
- `left`保存窗口的左边界，`right`保存窗口的右边界
- `resStart`保存最小子串的起始位置，`resLen`保存最小子串的长度

**在字符串s上的窗口滑动策略如下：**

1. `targetMap`中的元素不全在`windowMap`中，`right`向右滑动，并更新`windowMap[s[right]]++`，直到`targetMap`中的元素全在`windowMap`中
2. `targetMap`中的元素全在`windowMap`中，`left`向右滑动，并更新`windowMap[s[left]]--`、最小覆盖子串的起始位置`resStart`和最小覆盖子串的长度`resLen`，直到`targetMap` 中的元素不全在`windowMap`中

**效果：**

根据上面的滑动策略 **我们可以获得 以**`s`**任意位置为左边界 (枚举左边界) 的所有候选窗口**，只需要把其中最短的一个窗口返回即可。

**如何判断targetMap中的元素是否全在windowMap中，即如何判断当前窗口的字符串已经覆盖了目标字符串**

**方案一：**可以采用遍历`targetMap`对其中的元素一个个去`windowMap`中比较。

掌握方案一即可，方案二会更复杂一些，但是面试只需要能写出方案一就足够了

```java
class Solution {
    public String minWindow(String s, String t) {
        int sLen = s.length();
        int tLen = t.length();
        if (sLen == 0 || tLen == 0) {
            return "";
        }
        Map<Character, Integer> targetMap = new HashMap<>();  // 保存t中字符出现的次数
        Map<Character, Integer> windowMap = new HashMap<>();  // 保存滑动窗口中的字符出现的次数
        // 统计t中的字符
        for (int i = 0; i < tLen; ++i) {
            char ch = t.charAt(i);
            targetMap.put(ch, targetMap.getOrDefault(ch, 0) + 1);
        }

        int resStart = 0, resLen = Integer.MAX_VALUE;   // resStart最小覆盖子串的起始位置,resLen最小覆盖子串的长度
        int left = 0, right = 0;                    // 滑动窗口的左右边界
        
        while (right < sLen) {
            char rightChar = s.charAt(right);       // 右边界字符
            windowMap.put(rightChar, windowMap.getOrDefault(rightChar, 0) + 1); // 更新窗口中字符出现的次数

            // 若当前窗口的子串已是覆盖子串
            while (isFullStr(targetMap, windowMap)) {
                // 若窗口的大小 < 已保存的最小覆盖子串的长度，则更新最小覆盖子串的起始位置和最小子串的长度
                int windowLen = right - left + 1;
                if (windowLen < resLen) {
                    resStart = left;        
                    resLen = windowLen;
                }
                
                // 右移窗口左边界，缩小窗口，尝试取得更短的覆盖子串
                char leftChar = s.charAt(left);         // 左边界字符
                windowMap.put(leftChar, windowMap.get(leftChar) - 1);   // 更新窗口中字符出现的次数
                left++;
            }
            // 当跳出循环时，说明当前窗口的子串已不是t的覆盖子串,所以扩大窗口右边界,进入下一次循环
            right++;
        }
        // 滑动窗口遍历完毕,若resLen未曾更新,说明不存在覆盖子串,返回空字符串
        if (resLen == Integer.MAX_VALUE) return "";
        // 否则截取最小覆盖子串返回, substring(int beginIndex, int endIndex):含beginIndex，不含endIndex
        return s.substring(resStart, resStart + resLen);
    }

    // 判断当前窗口的字符串 是否涵盖了 目标字符串
    public boolean isFullStr(Map<Character, Integer> targetMap, Map<Character, Integer> windowMap){
        for (Map.Entry<Character, Integer> key : targetMap.entrySet()) {
            Character ch = key.getKey();
            Integer value = key.getValue();
            if(windowMap.containsKey(ch)){
                Integer windowCount = windowMap.get(ch);
                if(windowCount < value){
                    return false;
                }
            }else{
                return false;
            }
        }
        return true;
    }
}
```

**方案二：优化判断当前窗口是否覆盖子串：**

借用一个整型变量`tInWindow`在窗口滑动的过程中就对窗口中字符情况进行统计，大大节省了每次判断都要去遍历`hash`表的时间。

```java
class Solution {
    public String minWindow(String s, String t) {
        int sLen = s.length();
        int tLen = t.length();
        if (sLen == 0 || tLen == 0) {
            return "";
        }
        Map<Character, Integer> targetMap = new HashMap<>();  // 保存t中字符出现的次数
        Map<Character, Integer> windowMap = new HashMap<>();  // 保存滑动窗口中的字符出现的次数
        // 统计t中的字符
        for (int i = 0; i < tLen; ++i) {
            char ch = t.charAt(i);
            targetMap.put(ch, targetMap.getOrDefault(ch, 0) + 1);
        }
        
        int tCount = targetMap.size();              // t中不重复字符的个数,例如t为ABCA,则tCount=3
        int tInWindow = 0;                          // window完全包含t中不重复字符的数量
        int resStart = 0, resLen = Integer.MAX_VALUE;   // resStart最小覆盖子串的起始位置,resLen最小覆盖子串的长度
        int left = 0, right = 0;                    // 滑动窗口的左右边界
        
        while (right < sLen) {
            char rightChar = s.charAt(right);       // 右边界字符
            windowMap.put(rightChar, windowMap.getOrDefault(rightChar, 0) + 1); // 更新窗口中字符出现的次数

            // 窗口新增字符rightChar后,（t中存在rightChar的前提下）若使得rightChar在t和window中出现的次数相等，就增加tInWindow的计数
            if (targetMap.containsKey(rightChar) && windowMap.get(rightChar).equals(targetMap.get(rightChar))) {
                tInWindow++;
            }
            
            // 若窗口中含有t的有效字符数 == t中不重复字符的个数, 则说明当前窗口的子串已是覆盖子串
            while (tInWindow == tCount) {
                // 若窗口的大小 < 已保存的最小覆盖子串的长度，则更新最小覆盖子串的起始位置和最小子串的长度
                int windowLen = right - left + 1;
                if (windowLen < resLen) {
                    resStart = left;        
                    resLen = windowLen;
                }
                
                // 右移窗口左边界，缩小窗口，尝试取得更短的覆盖子串
                char leftChar = s.charAt(left);         // 左边界字符
                windowMap.put(leftChar, windowMap.get(leftChar) - 1);   // 更新窗口中字符出现的次数
                // 窗口减去字符leftChar后,（t中存在rightChar的前提下）若使得leftChar在t和window中出现的次数不等，就减小tInWindow的计数
                if (targetMap.containsKey(leftChar) && windowMap.get(leftChar) < targetMap.get(leftChar)) {
                    tInWindow--;
                }
                left++;
            }
            // 当跳出循环时，说明 tInWindow != tCount 即当前窗口的子串已不是t的覆盖子串,所以扩大窗口右边界,进入下一次循环
            right++;
        }
        // 滑动窗口遍历完毕,若resLen未曾更新,说明不存在覆盖子串,返回空字符串
        if (resLen == Integer.MAX_VALUE) return "";
        // 否则截取最小覆盖子串返回, substring(int beginIndex, int endIndex):含beginIndex，不含endIndex
        return s.substring(resStart, resStart + resLen);
    }
}
```
