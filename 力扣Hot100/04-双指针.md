# 双指针

## [283. 移动零](https://leetcode.cn/problems/move-zeroes/)[简单]✅

**题目：**给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751610251371-03f0d79c-53d2-4d4b-b028-c8232d7b94c8.png)

**思路：**

**方案一(两次遍历)**

- 第一次遍历：将所有非零元素移到左侧

- 定义两个指针，`slow = 0, fast = 0`，不断移动fast指针，在循环内，如果fast指针指向元素不是零，则把该元素放到slow指针对应的位置，并且slow指针右移一位

- 第二次遍历：将 除了 [移动过的非零元素] 外的 【其余元素】都置为0

```java
class Solution {
    public void moveZeroes(int[] nums) {
        // 以 nums = [0,1,0,3,12] 举例，输出: [1,3,12,0,0]
        int len = nums.length;
        // 指向当前已处理的非零元素的末尾
        int slow = 0;

        // 第一次遍历：将所有非零元素移到左侧
        for (int fast = 0; fast < len; fast++) {
            if (nums[fast] != 0) {
                nums[slow] = nums[fast];
                slow++;
            }
        }
        // slow=0,fast=0 第一次循环后 [0,1,0,3,12]
        // slow=0,fast=1 第二次循环后 [1,1,0,3,12]
        // slow=1,fast=2 第三次循环后 [1,1,0,3,12]
        // slow=1,fast=3 第四次循环后 [1,3,0,3,12]
        // slow=2,fast=4 第五次循环后 [1,3,12,3,12] slow=3,fast=5

        // 第二次遍历：将剩余位置填充为 0
        for (int i = slow; i < len; i++) {
            nums[i] = 0;
        }
    }
}
```

掌握方案一即可

**方案二(一次遍历)**

**一次遍历，只要把左侧的零和右侧的非零数字进行交换即可**

定义两个指针，`slow = 0, fast = 0`

1. 如果nums[fast] == 0，fast指针就往右移一步
2. 如果nums[fast] != 0，就交换nums[slow]和nums[fast]的值，slow和fast同时向右移一步。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; ) {
            // 如果nums[fast] == 0，fast指针就往右移一步
            if(nums[fast] == 0){
                fast++;
            }else{
                // fast指向元素不为0时，交换slow和fast指向元素，且slow和fast同时右移一步
                int temp = nums[fast];
                nums[fast] = nums[slow];
                nums[slow] = temp;
                slow++;
                fast++;
            }
        }
    }
}
```

## [11. 盛最多水的容器](https://leetcode.cn/problems/container-with-most-water/)[中等]✅

**题目：**给定一个长度为 `n` 的整数数组 `height` 。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])` 。找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751614237730-b8cc8186-7245-4cc4-84e8-ec86a4c92e97.png)

**思路：**

题意为：求如上图围成的最大面积，面积等于宽×高 `宽为 j-i` `高为 min(height[i], height[j])`

即给定数组`height`，任选两个下标`i`和`j`，求`(j-i) * min(height[i],height[j])`的最大值

解题思路为双指针，左指针从最左侧开始向右检索，右指针从最右侧开始向左检索，

但每次只移动高度较小的那个指针，遍历过程中计算出当前围成的面积，并且记录最大面积

***为什么每次只移动高度较小的指针？****这就和水桶的盛水量是由最矮的阀决定的道理一致*

（这里的 i 和 j 是下标，下面的比较需要配合着上图来看）因为

- 如果 height[i] < height[j]，那么在 (i , i+1)、 (i , i+2)、... 、(i , j-1) 区间的面积都小于（i , j）区间的面积。 因为 固定了i，因此中间围成的面积，其高 最高不超过i，其宽 最宽也不超过 j-i

- 所以此时如果移动 j 是没有意义的，因此需要移动 i ，而 i 正是那个高度较小的指针

- 如果 height[i] > height[j]，那么在（i+1 , j)、（i+2 , j）、... 、(j-1 , j) 区间的面积都小于 ( i, j ) 区间的面积。因为 固定了j，因此中间围成的面积，其高 最高不超过j，其宽 最宽也不超过 j-i

- 所以此时如果移动 i 是没有意义的，因此需要移动 j，而 j 正是那个高度较小的指针

```java
class Solution {
    public int maxArea(int[] height) {
        int i = 0;
        int j = height.length - 1;
        int maxArea = 0;
        while (i <= j) {
            int curArea = (j - i) * Math.min(height[i], height[j]);
            maxArea = Math.max(maxArea, curArea);
            // 每次移动高度较小的指针，若高度相等可任意移动
            if (height[i] <= height[j]) {
                i++;
            } else {
                j--;
            }
        }
        return maxArea;
    }
}
```

## [15. 三数之和](https://leetcode.cn/problems/3sum/)[中等]✅

**题目：**给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1752983959851-43dd4e0e-f459-46f3-83a9-51e3a25e0dd5.png)

**思路：**

- 固定一个数，将三数之和转换为两数之和
- 数组排序，使用双指针求解两数之和
- 移动指针过程中，对组合去重

**具体解释：**

先排序，固定第一个数 nums[i]，则目标值变为 `0 - nums[i]`

再使用双指针 j 和 k 求解两数之和 `nums[j] + nums[k]` ==`0 - nums[i]`

- 此处的 `j = i +1`，`k = nums.length-1`
- 若 `nums[j] + nums[k]` > `0 - nums[i]`，则应该令两数之和减小, 即 k--
- 若 `nums[j] + nums[k]` < `0 - nums[i]`，则应该令两数之和增大, 即 j++
- 若 `nums[j] + nums[k]` == `0 - nums[i]`，则 这三个数就是满足条件的，应该加入结果集

- 加入结果集后 需要对`第二个数的后面`和`第三个数的前面`进行去重。先记录当前指针的值，然后一直移动指针，直到数值不相等为止。

- 接着 对第一个数进行去重

然后 循环下一个 nums[i]，重复上述过程

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            // 已经排序了,如果第一个数都大于0,则后面就不再存在三数之和为0的结果,退出循环
            if (nums[i] > 0) {
                break;
            }
            int twoSumTarget = -nums[i];
            int j = i + 1;
            int k = nums.length - 1;
            while (j < k) {
                int twoSum = nums[j] + nums[k];
                if (twoSum > twoSumTarget) {
                    k--; // 两数之和大于目标值,则应该令两数之和减小,即k--
                } else if (twoSum < twoSumTarget) {
                    j++; // 两数之和小于目标值,则应该令两数之和增大,即j++
                } else {
                    // 这三个数就是满足条件的，应该加入结果集
                    res.add(Arrays.asList(nums[i], nums[j], nums[k]));
                    // 此时额外的需要去重
                    int second = nums[j];
                    int third = nums[k];
                    while (j < k && nums[j] == second) {
                        j++; // 对第二个数进行去重
                    }
                    while (j < k && nums[k] == third) {
                        k--; // 对第三个数进行去重
                    }
                }
            }
            // 对第一个数进行去重
            int first = nums[i];
            while (i + 1 < nums.length && nums[i + 1] == first) {
                i++;
            }
        }
        return res;
    }
}
```

## [42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)[困难]✅

**题目：**给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1752983987704-703695a1-05ba-49c9-9947-12da46dccada.png)

**思路：**把上图 切分为`宽度为1、高度不定的柱子`，分别计算每个柱子可接的雨水 = 宽(即1) \* 高度不定

而每个柱子可接的雨水的高度 是由什么决定的呢？

是由该柱子的`左边区间的最高柱子`和`右边区间的最高柱子` 以及`当前柱子的高度`三者共同决定的

即每个柱子可接的雨水的高度 = `Min（左边区间的最高柱子，右边区间的最高柱子）- 当前柱子的高度`

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1752941944881-f1fcb242-ff42-4dd9-95f8-92886f0c763d.png)

因此先统计`每一个柱子`的 `左边区间` 和 `右边区间` 的`最高柱子的高度`

用`这两个高度的最小值` 减去 `当前柱子高度`再乘x以 宽度(即1) = 当前这个柱子可接的雨水

- 如何统计`每一个柱子`的 `左边区间` 和 `右边区间` 的`最高柱子的高度`

- 定义两个数组，leftMax[n] 前缀最大值 和 rightMax[n] 后缀最大值
- 例如 leftMax[2] 表示从0-2中最高柱子的高度，rightMax[5]表示从5-11中最高柱子的高度
- 则 leftMax[i] = Math.max(leftMax[i - 1], height[i]);
- rightMax[i] = Math.max(rightMax[i + 1], height[i]);

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;

        // 构建前缀最大值数组leftMax, 例如 leftMax[2] 表示 从0-2中最高柱子的高度
        int[] leftMax = new int[n];
        leftMax[0] = height[0];
        for (int i = 1; i < n; i++) {
            leftMax[i] = Math.max(leftMax[i - 1], height[i]);
        }

        // 构建后缀最大值数组rightMax, 例如 rightMax[5] 表示 从5-11中最高柱子的高度
        int[] rightMax = new int[n];
        rightMax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            rightMax[i] = Math.max(rightMax[i + 1], height[i]);
        }

        int res = 0;
        for (int i = 1; i < n-1; i++) {
            // 若当前柱子太高[比左边最高的高或者比右边最高的高]无法装水
            if(height[i] >= leftMax[i-1] || height[i] >= rightMax[i+1]){
                continue;
            }
            // 当前柱子可蓄水累加到Res中
            // 当前柱子可蓄水：Math.min([左区间最高柱子],[右区间最高柱子])-当前柱子高度
            res += Math.min(leftMax[i-1], rightMax[i+1]) - height[i];
        }
        return res;
    }
}
```
