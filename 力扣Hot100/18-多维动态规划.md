## [62. 不同路径](https://leetcode.cn/problems/unique-paths/)[中等]✅

**题目：**一个机器人位于一个 `m x n`网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765465309212-0312f64f-46c6-46ec-8c62-49d527a64900.png)

**思路：**动态规划，**可参考思路讲解：**[**62. 不同路径**](https://www.bilibili.com/video/BV1rJYKeFESo/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

假设网格大小为 m=1、n=1，此时机器人就在终点，总共只有1条路径，设为dp[1,1]

假设网格大小为 m=1、n=2，此时机器人只能一路向左走，总共也只有1条路径，设为dp[1,2]

假设网格大小为 m=1、n=3，此时机器人只能一路向左走，总共也只有1条路径，设为dp[1,3]

......

假设网格大小为 m=1、n=7，此时机器人只能一路向左走，总共也只有1条路径，设为dp[1,7]

--------

假设网格大小为 m=2、n=1，此时机器人只能向下走，总共只有1条路径，设为dp[2][1]

假设网格大小为 m=2、n=2，肉眼观察出总共有2条路径，设为dp[2][2]

假设网格大小为 m=2、n=3，肉眼观察出总共有3条路径，设为dp[2][3]

观察规律，dp[2][3] = dp[2][2] + dp[1][3] = 2+1 = 3

综上所述，可以总结出

- dp[i][j] 代表 大小 m=i , n=j 的网格从左上角到右下角有多少不同的路径
- 递推公式：dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765466503672-0e162d57-fbfd-4b9d-9c6a-101612d189c9.png)

```java
class Solution {
    public int uniquePaths(int m, int n) {
        // 初始化dp数组，行列都多开1个（方便从i=1、j=1开始计算）
        // 所有位置初始值设为1（因为第一行和第一列的路径数都是1）
        int[][] dp = new int[m + 1][n + 1];
        // 初始化第一行：只有“一直向右走”1种路径
        for (int j = 1; j <= n; j++) {
            dp[1][j] = 1;
        }
        // 初始化第一列：只有“一直向下走”1种路径
        for (int i = 1; i <= m; i++) {
            dp[i][1] = 1;
        }

        // 遍历每个位置（从第2行第2列开始）
        for (int i = 2; i <= m; i++) {
            for (int j = 2; j <= n; j++) {
                // 递推公式
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m][n];
    }
}
```

## [64. 最小路径和](https://leetcode.cn/problems/minimum-path-sum/)[中等]✅

**题目：**给定一个包含非负整数的 `m` `x` `n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。**说明：**每次只能向下或者向右移动一步。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765467417325-0f99ab92-0253-4604-9886-3d16771533e8.png)

**思路：**动态规划，**可参考思路讲解：**[**64. 最小路径和**](https://www.bilibili.com/video/BV1PMKezqEQC/?spm_id_from=333.1391.0.0&vd_source=9297c4d03d5f37a56605a3cb4627b688)

我们设定 从左上角(0,0)到右下角(i,j) 的最小路径和为 dp[i,j]，依照设定，则

- 从左上角(0,0)到(i,j-1)的最小路径和为dp[i,j-1]
- 从左上角(0,0)到(i-1,j)的最小路径和为dp[i-1,j]

由于每次只能向右走或向下走，所以 dp[i,j] = Math.min (dp[i,j-1], dp[i-1,j]) + grid[i][j]

有了递推公式，只需要从 dp[0][0] 一层一层推导到 dp[i][j] 即可，边界条件dp[0][0] = grid[0][0]

其中第一行(只能从左边走过来)路径和累加左边的值 和 第一列(只能从上面走下来)路径和累加上面的值 即可

```java
class Solution {
    public int minPathSum(int[][] grid) {
        // 获取网格的行数和列数
        int row = grid.length;
        int col = grid[0].length;
        // 初始化第一行：第一行只能从左边走过来，路径和累加左边的值
        for (int i = 1; i < col; i++) {
            grid[0][i] += grid[0][i - 1];
        }
        // 初始化第一列：第一列只能从上面走下来，路径和累加上面的值
        for (int i = 1; i < row; i++) {
            grid[i][0] += grid[i - 1][0];
        }
        // 遍历网格的其他位置（从第二行第二列开始）
        for (int i = 1; i < row; i++) {
            for (int j = 1; j < col; j++) {
                // 状态转移：当前位置的最小路径和 = 自身值 + 上方/左方路径和的较小值
                // 因为只能向下或向右走，所以只需要比较上方和左方的路径和
                grid[i][j] += Math.min(grid[i - 1][j], grid[i][j - 1]);
            }
        }
        // 返回右下角位置的最小路径和（网格最后一行最后一列）
        return grid[row - 1][col - 1];
    }
}
```

## [5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)[中等]✅

**题目：**给你一个字符串 `s`，找到 `s` 中最长的回文子串。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765472545425-7885c814-f3bf-4c8b-ae64-e367bd21ca9a.png)

**思路：**双指针，**可参考思路讲解：**[**5. 最长回文子串**](https://www.bilibili.com/video/BV1w7421Z798/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

情况1：回文长度为奇数（如"bab"）

- 想要判断是否回文串，我们可以枚举每一个字符，以每一个 单个字符为中心，定义L指针和R指针指向单个字符后，L和R向左右两边扩展，在L和R不越界的情况下，直到L和R所指字符不相等为止，在扩展过程中，记录下最长回文子串的长度和起始点

情况2：回文长度为偶数（中心是两个字符，如"baab"）

- 当回文长度为偶数时，我们的中心不再是单个字符了，而应该是两个字符为整体作为中心，因此例如L指向i，则R指向i+1，L和R向左右两边扩展，在L和R不越界的情况下，直到L和R所指字符不相等为止，在扩展过程中，记录下最长回文子串的长度和起始点

```java
class Solution {
    public String longestPalindrome(String s) {
        int resLen = 0;       // 记录最长回文子串的长度
        int resStart = 0;     // 记录最长回文子串的起始索引

        // 遍历每个字符，从字符为中心扩展（处理两种回文情况）
        for (int i = 0; i < s.length(); i++) {
            // 情况1：回文长度为奇数（中心是单个字符，如"bab"）
            int left = i;
            int right = i;
            // 向左右扩展，直到字符不相等或越界
            while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
                // 更新最长回文子串的信息
                if (right - left + 1 > resLen) {
                    resLen = right - left + 1;
                    resStart = left;
                }
                left--;
                right++;
            }

            // 情况2：回文长度为偶数（中心是两个字符，如"baab"）
            left = i;
            right = i + 1;
            // 向左右扩展，直到字符不相等或越界
            while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
                // 更新最长回文子串的信息
                if (right - left + 1 > resLen) {
                    resLen = right - left + 1;
                    resStart = left;
                }
                left--;
                right++;
            }
        }
        // 截取并返回最长回文子串
        return s.substring(resStart, resStart + resLen);
    }
}
```

## [1143. 最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)[中等]✅

**题目：**给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在 **公共子序列** ，返回 `0` 。

一个字符串的 **子序列**是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765472577091-6012c611-425b-48c6-b8ff-b81f219da99b.png)

**思路：**动态规划，**可参考思路讲解：**[**1143. 最长公共子序列**](https://www.bilibili.com/video/BV1RovheZEHf/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688) **或者** [**1143. 最长公共子序列**](https://www.bilibili.com/video/BV12GgQzaECe/?spm_id_from=333.788.videopod.sections&vd_source=9297c4d03d5f37a56605a3cb4627b688)

假设 text1 = ...... a b c d e 总长度为m+1， text2 = ...... a c e 总长度为 n+1 （这里忽略前几位字符）

那么最后一个字符，text1中的e的索引为m，text2中的e的索引为n

- 假如 text1[m] == text2[n] 即e==e，原问题text1和text2的最长公共子序列就可以转换为

- text1的从0到m-1区间 和 text2的从0到n-1区间 这两个子字符串的最长公共子序列 + 1

- 假如 text1[m] != text2[n] ，原问题text1和text2的最长公共子序列就可能存在于

- text1的从0到m-1区间 和 text2的从0到n区间 这两个子字符串的最长公共子序列
- 或者 text1的从0到m区间 和 text2的从0到n-1区间 这两个子字符串的最长公共子序列
- 原问题就可以转化为上述两者的较大值

综上所述，可以得到递推公式：f(0~m,0~n) =

- f(0~m-1,0~n-1) + 1，在text1[m] == text2[n] 的情况下
- Math.max(f(0~m-1,0~n),f(0~m,0~n-1)) ，在text1[m] != text2[n] 的情况下

从上往下一层一层填表即可，最终答案为dp[len1][len2]

表格中的第一行和第一列全部默认为0，表示空字符串的情况

dp[i][j]：表示text1的前i个字符 和 text2的前j个字符的最长公共子序列长度

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765476666172-5f67f72a-52d7-4d10-8040-30c30fd48d99.png)

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        // 获取两个字符串的长度
        int len1 = text1.length();
        int len2 = text2.length();

        // dp[i][j]：表示text1的前i个字符 和 text2的前j个字符的最长公共子序列长度
        // 初始化dp数组，行列都多开1个（方便处理i=0或j=0的边界情况，此时公共子序列长度为0）
        int[][] dp = new int[len1 + 1][len2 + 1];

        // 遍历text1的每个字符
        for (int i = 0; i < len1; i++) {
            // 遍历text2的每个字符
            for (int j = 0; j < len2; j++) {
                if (text1.charAt(i) == text2.charAt(j)) {
                    // 情况1：当前字符相等，公共子序列长度 = 前i-1和前j-1的长度 + 1
                    dp[i + 1][j + 1] = dp[i][j] + 1;
                } else {
                    // 情况2：当前字符不相等，取“text1前i个+text2前j-1个”或“text1前i-1个+text2前j个”的较大值
                    dp[i + 1][j + 1] = Math.max(dp[i + 1][j], dp[i][j + 1]);
                }
            }
        }
        // 最终结果：text1整个字符串和text2整个字符串的最长公共子序列长度
        return dp[len1][len2];
    }
}
```

## [72. 编辑距离](https://leetcode.cn/problems/edit-distance/)[中等]✅

**题目：**给你两个单词 `word1` 和 `word2`， *请返回将* `word1` *转换成* `word2` *所使用的最少操作数* 。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765472560981-75b42596-dfa7-4086-888f-0e91d7495611.png)

**思路：**动态规划，**可参考思路讲解：**[**72. 编辑距离**](https://www.bilibili.com/video/BV1reK9znEJQ/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

假设 word1 = a b c ， word2 = a d c，定义两个指针i和j分别指向两个字符串的最后一个字符

目标是求 把 word1 转换成 word2 最小的编辑距离

**定义 f(i,j) 为 把 [0,i] 区间的 word1 转换为 [0,j] 区间的 word2 需要的最小的编辑距离**

当前 i 在word1中指向的字符是c，j在word2中指向的字符也是c，因此此时不需要任何的编辑，可知

- **f(i,j) = f(i-1,j-1)，在word1[i] = word2[j]的情况下**

----

假设 word1 = a b e ， word2 = a d c，此时 i 和 j 指向的 分别是 e 和 c，**即 word1[i] != word2[j]的情况下**

为了把word1转换成word2

可以在word1的i处位置，插入元素或删除元素或替换元素，来使得word1[i] == word2[j]

- 若插入元素c：则 word1=a b e c，word2=a d c 此时需要继续将word1的 [0,i] 转换为word2的 [0,j-1]

- 则原问题转换为 **f(i,j) = f(i,j-1)+1**

- 若删除元素：则 word1=a b ，word2=a d c 此时需要继续将word1的 [0,i-1] 转换为word2的 [0,j]

- 则原问题转换为 **f(i,j) = f(i-1,j)+1**

- 若替换元素：则 word1=a b c，word2=a d c 此时需要继续将word1的 [0,i-1] 转换为word2的 [0,j-1]

- 则原问题转换为 **f(i,j) = f(i-1,j-1)+1**

**因此在word1[i] != word2[j]的情况下，我们需要从上述三种情况，取得编辑距离最小的**

边界条件 f（0，0） = 0

填表：第一行的元素都是通过左边的元素进行状态转移，第一列的元素都是通过上边的元素进行状态转移

其余元素，则按照递推公式判断即可

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765476804395-7621bce2-f0b7-4cb4-a279-edfa7f5443bf.png)

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int len1 = word1.length();
        int len2 = word2.length();
        // 定义dp数组：dp[i][j]表示word1前i个字符 转成 word2前j个字符的最少操作数
        int[][] dp = new int[len1 + 1][len2 + 1];
        // 初始化：word1为空时，转成word2需要逐个插入（操作数=word2长度）
        for (int i = 1; i <= len2; ++i) {
            dp[0][i] = dp[0][i - 1] + 1;
        }
        // 初始化：word2为空时，转成word2需要逐个删除（操作数=word1长度）
        for (int i = 1; i <= len1; ++i) {
            dp[i][0] = dp[i - 1][0] + 1;
        }
        // 填充dp数组
        for (int i = 1; i <= len1; ++i) {
            for (int j = 1; j <= len2; ++j) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相同，无需操作，继承之前的状态
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 字符不同，取“替换、删除、插入”三种操作的最小值+1,即表格中上方，左方，左上方三个元素的最小值+1
                    dp[i][j] = Math.min(Math.min(dp[i - 1][j - 1], dp[i - 1][j]), dp[i][j - 1]) + 1;
                }
            }
        }
        // dp[len1][len2]就是最终结果
        return dp[len1][len2];
    }
}
```
