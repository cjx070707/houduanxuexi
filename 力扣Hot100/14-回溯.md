## [46. 全排列](https://leetcode.cn/problems/permutations/)[中等]✅

**题目：**给定一个不含重复数字的数组 `nums` ，返回其 *所有可能的全排列* 。你可以 **按任意顺序** 返回答案。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764768502800-fcd33762-a733-4677-bb24-e544ef01367c.png)

**思路：**回溯法，**可参考思路讲解：**[46. 全排列](https://www.bilibili.com/video/BV1VFVSzCEzS/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688) 、[labuladong 视频题解](https://www.bilibili.com/video/BV1P5411N7Xc?spm_id_from=333.788.videopod.sections&vd_source=9297c4d03d5f37a56605a3cb4627b688)

全排列的核心特征是：每个元素必须出现且仅出现一次，元素的顺序不同属于不同的排列

本题的本质是**遍历一棵决策树**(脑海中需要有如下图的内容)

每个节点代表当前的排列路径，每条从根到叶的路径对应一个完整的全排列

- **选择**：从数组中选一个未使用的元素，加入当前排列路径。
- **递归**：基于当前选择，继续递归选择下一个元素，直到路径长度等于数组长度（得到一个完整排列）。
- **回溯**：递归返回后，撤销当前选择（将元素移出路径、标记为未使用），尝试下一个可能的元素。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765043810022-5243f1a0-d2de-4afc-a5b9-9b942261e880.png)

```java
class Solution {
    // 存储最终所有全排列的结果集
    List<List<Integer>> res = new LinkedList<>();
    
    public List<List<Integer>> permute(int[] nums) {
        // 标记数组元素是否被使用过，「路径」中的元素会被标记为 true，避免重复使用
        boolean[] used = new boolean[nums.length];
        // 存储当前正在构建的排列路径
        List<Integer> route = new LinkedList<>();
        // 开始递归遍历构建排列
        traverseTree(nums, route, used);
        return res;
    }
    public void traverseTree(int[] nums, List<Integer> route, boolean[] used) {
        // 终止条件：当前路径长度等于数组长度，说明已构建完成一个全排列
        if (route.size() == nums.length) {
            // 将当前路径的副本加入结果集（避免后续修改影响已存储的结果）
            res.add(new LinkedList<>(route));
            return; // 结束当前递归分支
        }
        // 遍历数组中的每个元素，尝试选择未使用的元素加入路径
        for (int i = 0; i < nums.length; i++) {
            // 如果当前元素已被使用，跳过该元素
            if (used[i]) {
                continue;
            }
            // 选择当前元素：加入路径，并标记为已使用
            route.add(nums[i]);
            used[i] = true;
            // 递归遍历下一层，继续构建排列
            traverseTree(nums, route, used);
            // 回溯：撤销选择，将元素移出路径，并标记为未使用
            route.removeLast();
            used[i] = false;
        }
    }
}
```

## [78. 子集](https://leetcode.cn/problems/subsets/)[中等]✅

**题目：**给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765030537122-901d9434-895e-4233-bc47-a195ed742315.png)

**思路：**回溯法，**可参考思路讲解：**[78. 子集](https://www.bilibili.com/video/BV12GVfzxEG9?spm_id_from=333.788.videopod.sections&vd_source=9297c4d03d5f37a56605a3cb4627b688)

子集包括空集和数组本身，且子集元素的顺序无关（例如`[1,2]`和`[2,1]`视为同一个子集

选子集，其实就是针对每个元素都有两种选择，例如[1,2,3]，有1没1，有2没2，有3没3，2x2x2=8个子集

所以根据题意，脑海中要能想出如下图的决策树，那么答案就是所有叶子节点的值的集合

其中 pathLen 是当前递归处理到数组nums的第几个元素，也可以理解为递归的深度

1. **决策定位**：`pathLen`指向当前需要做出 “选或不选” 决策的数组元素下标。例如，当`pathLen=0`时，处理`nums[0]`；`pathLen=1`时，处理`nums[1]`，以此类推。
2. **终止条件**：当`pathLen == nums.length`时，说明已经对数组中所有元素都完成了 “选或不选” 的决策，此时当前构建的子集`temp`已确定，将其加入结果集即可。
3. **递归推进**：每次递归调用时`pathLen + 1`，表示处理完当前元素后，转向下一个元素的决策，确保数组中的每个元素都被依次处理，且不重复、不遗漏。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765118219207-6adb709c-81dc-4acb-8e54-303a1d4fa52c.png)

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>(); // 存储所有子集的结果集
        List<Integer> temp = new ArrayList<>();      // 存储当前正在构建的子集
        dfs(nums, 0, temp, res);                     // 从第0个元素开始递归
        return res;
    }
    // pathLen 是当前递归处理到数组nums的第几个元素（即元素下标），也可以理解为递归的深度
    private void dfs(int[] nums, int pathLen, List<Integer> temp, List<List<Integer>> res) {
        // 终止条件：处理完所有元素（pathLen等于数组长度）
        if (pathLen == nums.length) {
            res.add(new ArrayList<>(temp)); // 将当前子集的副本加入结果集
            return;
        }

        // 分支1：选择当前元素（将nums[pathLen]加入当前子集）
        temp.add(nums[pathLen]);
        dfs(nums, pathLen + 1, temp, res); // 递归处理下一个元素
        temp.remove(temp.size() - 1);      // 回溯：撤销选择

        // 分支2：不选择当前元素（直接处理下一个元素）
        dfs(nums, pathLen + 1, temp, res);
    }
}
```

## [17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)[中等]✅

**题目：**给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765035455871-5f6403a4-2e63-41ca-8755-2fd52368d9f8.png)

**思路：**回溯法，**可参考思路讲解：**[17. 电话号码的字母组合](https://www.bilibili.com/video/BV1w9sPzFEUB/?spm_id_from=333.337.search-card.all.click)

根据题意，脑海中要能想出如下图的决策树，那么答案就是所有叶子节点的值的集合

那么通过 DFS 或 BFS 遍历这颗决策树即可，下面使用DFS实现

- **树的节点分支**：每一层的节点分支数等于当前数字映射的字母个数（如数字`2`对应 3 个分支：`a`、`b`、`c`）；
- **树的叶子节点**：当遍历完所有数字字符时，到达叶子节点，此时的字母组合即为一个有效结果。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765044008364-f10ad469-d12a-47fc-aff0-9adc68766534.png)

```java
class Solution {
    // 存储最终的字母组合结果集
    List<String> res = new ArrayList<>();
    // 临时存储当前构建的字母组合字符串
    StringBuilder sb = new StringBuilder();

    public List<String> letterCombinations(String digits) {
        // 边界条件：若输入数字字符串为空，直接返回空结果集
        if (digits.isEmpty()) {
            return res;
        }
        // 构建数字到字母的映射表，对应电话键盘的布局
        Map<Character, String> map = new HashMap<>();
        map.put('2', "abc");
        map.put('3', "def");
        map.put('4', "ghi");
        map.put('5', "jkl");
        map.put('6', "mno");
        map.put('7', "pqrs");
        map.put('8', "tuv");
        map.put('9', "wxyz");
        // 从数字字符串的第0个位置开始递归遍历构建组合
        traverseTree(digits, 0, map);
        return res;
    }

    public void traverseTree(String digits, int index, Map<Character, String> map) {
        // 终止条件：当前构建的字符串长度等于数字字符串长度，说明已完成一个组合
        if (digits.length() == sb.length()) {
            res.add(sb.toString()); // 将当前组合加入结果集
            return; // 结束当前递归分支，返回上一层
        }
        // 获取当前索引对应的数字字符，并得到其映射的字母字符串
        String str = map.get(digits.charAt(index));
        // 遍历当前数字映射的每个字母，尝试加入组合
        for (int i = 0; i < str.length(); i++) {
            sb.append(str.charAt(i)); // 选择当前字母，加入临时字符串
            traverseTree(digits, index + 1, map); // 递归处理下一个数字字符
            sb.deleteCharAt(sb.length() - 1); // 回溯：撤销选择，删除最后一个字母
        }
    }
}
```

## [39. 组合总和](https://leetcode.cn/problems/combination-sum/)[中等]✅

**题目：**给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有**不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两种组合是不同的。 对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765118669051-e5c68165-6d8f-4ab9-822f-03dfdb1713cb.png)

**思路：**回溯法，**可参考思路讲解：**[39. 组合总和](https://www.bilibili.com/video/BV1xyiueHEb4/?spm_id_from=333.337.search-card.all.click)

根据题意，脑海中要能想出如下图的决策树，但是我们能发现[4,5]和[5,4]是重复的，只能取一个，这就需要剪枝

在图最右边当第一轮选了5之后，第二轮选择开始，就不能再选择3和4了，这就是通过start指示遍历起点来控制的

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765120474501-8a580ee4-e7a3-4edd-b2ec-d1686ffd8b52.png)

```java
class Solution {
    // 存储所有符合条件的组合结果
    List<List<Integer>> res = new LinkedList<>();
    // 当前路径，用于存储当前尝试的组合
    LinkedList<Integer> route = new LinkedList<>();
    // 当前路径中数字的总和
    int sum = 0;

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        // 从第一个元素开始深度优先搜索
        traverseTree(candidates, target, 0);
        return res;
    }

    // start 是当我们在做选择时，从candidates整数数组中的第几个元素开始选择(避免重复组合,剪枝)
    void traverseTree(int[] candidates, int target, int start) {
        // 终止条件1：当前路径和等于target，找到有效组合
        if (sum == target) {
            res.add(new ArrayList<>(route)); // 创建新列表保存当前组合
            return;
        }
        // 终止条件2：当前路径和超过target，剪枝（因为数组元素均为正整数）
        if (sum > target) {
            return;
        }

        // 遍历从start开始的所有候选元素
        for (int i = start; i < candidates.length; i++) {
            // 选择当前元素：加入路径并更新总和
            route.add(candidates[i]);
            sum += candidates[i];

            // 关键：下一层递归仍然从i开始，因为同一个数字可以重复使用
            traverseTree(candidates, target, i);

            // 撤销选择：回溯到上一步状态
            route.removeLast();
            sum -= candidates[i];
        }
    }
}
```

## [22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)[中等]✅

**题目：**数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765121342564-e0720551-5ef5-4fa0-8c06-7954af529566.png)

**思路：**回溯法，**可参考思路讲解：**[22. 括号生成](https://www.bilibili.com/video/BV14pJLzHEEE/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

为保证生成的括号的合法性，并不是任何状态能够随意选择左括号或右括号的

设当前状态下 已使用的左括号数量为left，已使用的右括号的数量为right，那么显然初始状态两者均为0

- 只有在 左括号的数量小于n时，当前状态才有权力选择左括号
- 只有在 右括号的数量小于左括号的数量时，当前状态才有权力选择右括号

因此依据上述两条原则，在遍历过程中，看本次是添加左括号或右括号，就能够画出决策树

遍历决策树到叶子节点收集答案

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765121797715-1993c671-e340-40ef-8191-b5ae76adba12.png)

```java
class Solution {
    // 存储最终生成的有效括号组合结果
    List<String> res = new ArrayList<>();

    public List<String> generateParenthesis(int n) {
        // 启动递归遍历，初始状态：左括号数0、右括号数0、当前字符串为空
        traverseTree(n, 0, 0, new StringBuilder());
        return res;
    }

    /**
     * 递归遍历生成括号的决策树
     * @param n 括号的总对数
     * @param left 寻找过程中已有的左括号的数量
     * @param right 寻找过程中已有的右括号的数量
     * @param curStr 当前构建的括号字符串
     */
    public void traverseTree(int n, int left, int right, StringBuilder curStr) {
        // 递归终止条件：左括号和右括号都用完（数量等于n），找到有效组合
        if (left == n && right == n) {
            res.add(curStr.toString()); // 将当前字符串转为String加入结果集
            return;
        }

        // 选择1：尝试在当前状态添加左括号（前提：已使用左括号数量<n）
        if (left < n) {
            curStr.append("("); // 追加左括号
            traverseTree(n, left + 1, right, curStr); // 递归处理下一层
            curStr.deleteCharAt(curStr.length() - 1); // 回溯：删除最后一个字符（撤销选择）
        }

        // 选择2：尝试在当前状态添加右括号（前提：已使用右括号数量小于已使用左括号数量，保证括号有效）
        if (right < left) {
            curStr.append(")"); // 追加右括号
            traverseTree(n, left, right + 1, curStr); // 递归处理下一层
            curStr.deleteCharAt(curStr.length() - 1); // 回溯：删除最后一个字符（撤销选择）
        }
    }
}
```

## [79. 单词搜索](https://leetcode.cn/problems/word-search/)[中等]✅

**题目：**给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765122970233-c724e271-84a1-4fda-9336-e6d6bf423043.png)

**思路：**回溯法，**可参考思路讲解：**[79. 单词搜索](https://www.bilibili.com/video/BV1HBpTe6EvS/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

在矩阵的每一个位置，都需要作为DFS的起始点去搜索最终是否能组成单词

在矩阵的每一个位置时，挑选下一个位置，可以向上下左右四个方向去选择，但前提是需要组成单词

例如示例中，当前状态若为A， 向上、向左、向下 搜索时 都不是期望字符 B，因此都需要回溯，直到向右搜索

终止条件是当搜索组成的单词的长度达到给定word的长度

```java
class Solution  {
    public boolean exist(char[][] board, String word) {
        int rows = board.length;    // 矩阵的行数
        int cols = board[0].length; // 矩阵的列数
        boolean[][] visited = new boolean[rows][cols]; // 标记矩阵元素是否被访问过

        // 遍历矩阵的每个位置，作为DFS的起始点
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                // 若当前位置字符DFS后能找到匹配的答案,直接返回true
                if (dfs(board, word, i, j, 0, visited)) {
                    return true; 
                }
            }
        }
        // 所有位置都尝试过，未找到匹配路径
        return false;
    }

    /**
     * DFS回溯搜索核心方法
     * @param board 字符矩阵
     * @param word 目标单词
     * @param row 当前探索的行索引坐标
     * @param col 当前探索的列索引坐标
     * @param index 当前匹配到word单词的对应的字符索引
     * @param visited 访问标记数组
     * @return 是否能从当前位置匹配到剩余单词
     */
    private boolean dfs(char[][] board, String word, int row, int col, int index, boolean[][] visited) {
        // 终止条件：单词所有字符匹配完成
        if (index == word.length()) {
            return true;
        }

        int rows = board.length;
        int cols = board[0].length;
        // 无效情况判断：越界、字符不匹配、已访问过 → 此路径无效
        if (row < 0 || row >= rows || col < 0 || col >= cols 
                || board[row][col] != word.charAt(index) 
                || visited[row][col]) {
            return false;
        }

        // 标记当前位置为已访问，避免同一路径重复使用
        visited[row][col] = true;

        // 依次尝试向上、下、左、右四个方向递归探索
        boolean up = dfs(board, word, row - 1, col, index + 1, visited);    // 向上
        boolean down = dfs(board, word, row + 1, col, index + 1, visited);  // 向下
        boolean left = dfs(board, word, row, col - 1, index + 1, visited);  // 向左
        boolean right = dfs(board, word, row, col + 1, index + 1, visited); // 向右

        // 只要有一个方向匹配成功，整体结果为true
        boolean found = up || down || left || right;

        // 回溯：撤销当前位置的访问标记，供其他路径复用
        visited[row][col] = false;

        return found;
    }
}
```

## [131. 分割回文串](https://leetcode.cn/problems/palindrome-partitioning/)[中等]✅

**题目：**给你一个字符串 `s`，请你将`s`分割成一些子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751529222204-92e72dc7-c86e-4a12-bc2f-48115db2a10c.png)

**思路：**回溯法，**可参考思路讲解：**[131. 分割回文串](https://www.bilibili.com/video/BV19ij3zLEAR/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

分割回文串做的选择是 在哪个位置进行分割，分割后，必须保证子串是回文串，根据题意可画出决策树

- **递归的 “起点”**：从字符串的下标`0`开始，尝试分割。
- **枚举分割点**：对于当前起点`index`，枚举所有可能的结束点`i`（`i`从`index`到字符串末尾），相当于把字符串分成`s[index..i]`和剩下的部分。
- **剪枝条件**：如果`s[index..i]`不是回文串，直接跳过这个分割点（没必要继续往下走，节省时间）。
- **递归深入**：如果`s[index..i]`是回文串，就把它加入当前的分割路径，然后从`i+1`开始继续递归分割剩下的字符串。
- **递归终止**：当分割起点`index`等于字符串长度时，说明已经把字符串分割完了，且所有子串都是回文，这是一个有效结果，把当前路径保存下来。
- **回溯**：递归返回后，要把当前路径的最后一个子串删掉，回到上一步，尝试下一个分割点（比如刚才选了`i=1`，现在试`i=2`）。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765124725750-b23df020-cb34-4b79-8bfa-26606476e214.png)

```java
class Solution {
    // 存储最终的所有分割结果
    List<List<String>> res = new ArrayList<>();
    // 存储当前路径的分割结果
    List<String> route = new ArrayList<>();
   
    public List<List<String>> partition(String s) {
        // 从下标0开始遍历字符串，尝试分割
        traverseTree(s, 0);
        return res;
    }

    /**
     * 回溯遍历函数：递归尝试所有分割可能
     */
    public void traverseTree(String s, int index) {
        // 递归终止条件：如果分割到字符串末尾，说明当前路径是一个有效分割
        if (index == s.length()) {
            // 将当前路径的副本加入结果集
            res.add(new ArrayList<>(route));
            return;
        }
        // 枚举从index开始的所有分割点（i为分割的结束下标）
        for (int i = index; i < s.length(); i++) {
            // 检查子串s[index..i]是否是回文串，不是则跳过当前分割点
            if (!isPalindrome(s, index, i)) {
                continue;
            }
            // 若是回文串，将该子串加入当前路径
            route.add(s.substring(index, i + 1));
            // 递归处理下一个分割点（i+1为新的开始下标）
            traverseTree(s, i + 1);
            // 回溯：移除当前路径的最后一个元素，尝试下一个分割点
            route.removeLast();
        }
    }

    /**
     * 双指针法判断子串s[lo..hi]是否为回文串
     */
    public boolean isPalindrome(String s, int lo, int hi) {
        // 左右指针向中间移动，逐一比较字符
        while (lo < hi) {
            if (s.charAt(lo) != s.charAt(hi)) {
                return false;
            }
            lo++;
            hi--;
        }
        return true;
    }
}
```

## [51. N 皇后](https://leetcode.cn/problems/n-queens/)[困难]✅

**题目：**按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n****皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765036502545-05fea843-a29b-4f28-b3d4-0c19ad31b141.png)

**思路：**回溯法，**可参考思路讲解：**[**51. N 皇后**](https://www.bilibili.com/video/BV1P5411N7Xc?spm_id_from=333.788.videopod.sections&vd_source=9297c4d03d5f37a56605a3cb4627b688)

从上往下每一行只放一个皇后

在每一行中：都需要遍历每一列，尝试在该列放皇后，若安全，则放，否则继续尝试该行的下一列

- **每一层的选择是 “当前行的某一列”**：尝试在当前行的某一列放皇后，若安全则进入下一行；
- **回溯**：下一行处理完后，撤销当前行的选择，尝试当前行的下一列。

**关键逻辑：如何判断 “当前位置是否安全”**

要确保`(row, col)`位置可以放皇后，需要排除 3 种攻击情况：

1. **同一列**：当前列的上方所有行不能有皇后；
2. **左上方对角线**：行 - 1、列 - 1 的方向不能有皇后；
3. **右上方对角线**：行 - 1、列 + 1 的方向不能有皇后。

（注：不需要检查左和右和下，因为我们是 “从上往下的逐行摆放” 的，同一行只会放一个皇后）

```java
class Solution {
    // 存储所有合法的N皇后摆放方案结果集
    private List<List<String>> res = new ArrayList<>();
    
    public List<List<String>> solveNQueens(int n) {
        // 初始化n×n的字符数组棋盘，char数组默认值为'\u0000'（空字符）
        char[][] board = new char[n][n];
        // 遍历每一行，将整行填充为'.'（表示空位）
        for (char[] row : board) {
            Arrays.fill(row, '.'); // 利用Arrays.fill快速填充数组元素
        }
        // 从第0行开始回溯，尝试摆放皇后
        backtrack(board, 0);
        return res;
    }

    private void backtrack(char[][] board, int row) {
        int n = board.length; // 棋盘的边长（皇后数量）
        // 终止条件：当处理完所有行（row == n），说明找到一个合法方案
        if (row == n) {
            // 将字符数组表示的棋盘转换为List<String>格式，存入结果集
            List<String> validBoard = new ArrayList<>();
            for (char[] r : board) {
                validBoard.add(new String(r)); // 字符数组转字符串
            }
            res.add(validBoard); // 加入结果集
            return; // 结束当前递归分支，返回上一层
        }

        // 遍历当前行的每一列（0~n-1），尝试在该列摆放皇后
        for (int col = 0; col < n; col++) {
            // 检查当前位置(row, col)是否可以安全摆放皇后（无冲突）
            if (isValid(board, row, col)) {
                // 做出选择：在(row, col)位置放置皇后（标记为'Q'）
                board[row][col] = 'Q';
                // 递归处理下一行的皇后摆放
                backtrack(board, row + 1);
                // 回溯：撤销选择，将(row, col)位置恢复为'.'（空位）
                board[row][col] = '.';
            }
        }
    }

    /**
     * 辅助方法：检查指定位置(row, col)是否可以安全摆放皇后
     * 皇后的攻击规则：同一列、左上方对角线、右上方对角线不能有其他皇后
     * （同一行无需检查，因为每行只尝试摆放一个皇后）
     * @param board 当前的棋盘状态
     * @param row   待检查的行号
     * @param col   待检查的列号
     * @return true表示可以安全摆放，false表示存在冲突
     */
    private boolean isValid(char[][] board, int row, int col) {
        int n = board.length; // 棋盘边长
        // 1. 检查当前列是否已有皇后（遍历当前行上方的所有行）
        for (int i = 0; i < row; i++) {
            if (board[i][col] == 'Q') {
                return false; // 同一列存在皇后，冲突
            }
        }
        // 2. 检查左上方对角线（行号递减，列号递减，直到边界）
        for (int i = row - 1, j = col - 1; i >= 0 && j >= 0; i--, j--) {
            if (board[i][j] == 'Q') {
                return false; // 冲突
            }
        }
        // 3. 检查右上方对角线（行号递减，列号递增，直到边界）
        for (int i = row - 1, j = col + 1; i >= 0 && j < n; i--, j++) {
            if (board[i][j] == 'Q') {
                return false; // 冲突
            }
        }
        // 所有攻击方向均无皇后，位置安全
        return true;
    }
}
```
