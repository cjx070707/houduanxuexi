## [94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)[简单]✅

**题目：**给定一个二叉树的根节点 `root` ，返回 *它的* ***中序*** *遍历* 。

递归遍历(中序遍历是左根右)

```java
class Solution {
    List<Integer> list;
    public List<Integer> inorderTraversal(TreeNode root) {
        list = new ArrayList<>();
        travel(root);
        return list;
    }
    public void travel(TreeNode root) {
        if (root == null) {
            return;
        }
        travel(root.left);  // 访问左子树
        list.add(root.val); // 访问根节点
        travel(root.right); // 访问右子树
    }
}
```

**不仅需要掌握递归写法，也需要掌握迭代写法**

迭代写法思路(中序遍历是左根右)：使用栈来模拟递归的调用过程，栈记录了我们访问过的路径

1. 首先不断向左深入，把所有左节点压入栈中

2. 弹出栈顶节点（这是当前最左的节点），访问它

3. 然后转向该节点的右子树，重复上述过程

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        // 用于存储中序遍历结果的列表
        List<Integer> result = new ArrayList<>();
        // 辅助栈，用于模拟递归的过程
        Stack<TreeNode> stack = new Stack<>();
        if (root == null) {
            return result;
        }

        TreeNode cur = root;
        // 继续条件：当前节点不为空 或 栈不为空
        while (cur != null || !stack.isEmpty()) {
            // 情况1：当前节点不为空
            if (cur != null) {
                // 将当前节点压入栈中
                stack.push(cur);
                // 继续向左子树深入（相当于处理左子树）
                cur = cur.left;
            } 
            // 情况2：当前节点为空，说明已经到达最左侧
            else {
                // 从栈中弹出节点,它相当于是根节点
                cur = stack.pop();
                // 访问该节点（相当于处理根节点）
                result.add(cur.val);
                // 转向右子树（相当于处理右子树）
                cur = cur.right;
            }
        }
        return result;
    }
}
```

## [144. 二叉树的前序遍历](https://leetcode.cn/problems/binary-tree-preorder-traversal/)[简单]✅

递归遍历(前序遍历是根左右)

```java
class Solution {
    List<Integer> ans = new ArrayList<>();
    public List<Integer> preorderTraversal(TreeNode root) {
        if (root == null) return new ArrayList<>();
        ans.add(root.val);
        preorderTraversal(root.left);
        preorderTraversal(root.right);
        return ans;
    }
}
```

迭代遍历思路(前序遍历是根左右)：利用栈模拟递归，第一步，先把根节点压入栈

而后循环处理：1. 弹出栈顶节点（当前要处理的节点）

2. 访问当前节点（前序遍历先访问根节点）

3. 将右子节点压入栈中

4. 将左子节点压入栈中

注意：先右后左，因为栈是后进先出，我们希望左子节点先被处理，所以要后压入栈

```java
class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        if (root == null) {
            return new ArrayList<>();
        }
        List<Integer> result = new ArrayList<>();
        // 辅助栈，用于存储待处理的节点
        Stack<TreeNode> stack = new Stack<>();
        
        // 第一步：将根节点压入栈中
        stack.push(root);
        // 循环处理，直到栈为空
        while (!stack.isEmpty()) {
            // 1. 弹出栈顶节点（当前要处理的节点）
            TreeNode currentNode = stack.pop();
            // 2. 访问当前节点（前序遍历先访问根节点）
            result.add(currentNode.val);
            // 3. 将右子节点压入栈中（如果有）
            // 注意：先右后左，因为栈是后进先出
            // 我们希望左子节点先被处理，所以要后压入栈
            if (currentNode.right != null) {
                stack.push(currentNode.right);
            }
            // 4. 将左子节点压入栈中（如果有）
            if (currentNode.left != null) {
                stack.push(currentNode.left);
            }
        }
        return result;
    }
}
```

## [145. 二叉树的后序遍历](https://leetcode.cn/problems/binary-tree-postorder-traversal/)[简单]✅

递归遍历(后序遍历是左右根)

```java
class Solution {
    List<Integer> ans = new ArrayList<>();
    public List<Integer> postorderTraversal(TreeNode root) {
        if (root == null) return new ArrayList<>();
        postorderTraversal(root.left);
        postorderTraversal(root.right);
        ans.add(root.val);
        return ans;
    }
}
```

迭代遍历思路(后序遍历是**左右根**)：

已知二叉树的前序遍历的代码，得到的结果是根左右，如果在二叉树的前序遍历中，调换左右子树入栈的顺序，那么二叉树的前序遍历代码得到的结果将会是：**根右左**

因此此时再把结果颠倒过来，就得到了本题答案：**左右根**

```java
class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> tempRes = preorderTraversal(root); // 根右左
        // 左右根
        Collections.reverse(tempRes);
        return tempRes;
    }
    // 前序遍历(根左右)的变种：根右左（让左子节点先入栈，才能后被处理）
    public List<Integer> preorderTraversal(TreeNode root) {
        if (root == null) {
            return new ArrayList<>();
        }
        List<Integer> result = new ArrayList<>();
        // 辅助栈，用于存储待处理的节点
        Stack<TreeNode> stack = new Stack<>();
        
        // 第一步：将根节点压入栈中
        stack.push(root);
        // 循环处理，直到栈为空
        while (!stack.isEmpty()) {
            // 1. 弹出栈顶节点（当前要处理的节点）
            TreeNode currentNode = stack.pop();
            // 2. 访问当前节点（前序遍历先访问根节点）
            result.add(currentNode.val);
            // 3. 将左子节点压入栈中（如果有）
            if (currentNode.left != null) {
                stack.push(currentNode.left);
            }
            // 4. 将右子节点压入栈中（如果有）
            if (currentNode.right != null) {
                stack.push(currentNode.right);
            }
        }
        return result;
    }
}
```

## [104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)[简单]✅

**题目：**给定一个二叉树 `root` ，返回其最大深度。

二叉树的 **最大深度** 是指从根节点到最远叶子节点的最长路径上的节点数。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1763911783959-ee1f6255-77d1-4872-8925-68d44703bd98.png)

**思路：**递归，明确子问题和原问题的关系（已知子问题如何求解出原问题）

计算最大深度，可以转化为求 Math.max(左子树的最大深度, 右子树的最大深度)+1

不断递归，直到遇到空节点，返回空节点的最大深度0

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null){
            // 叶子节点
            return 0;
        }
        int leftMax = maxDepth(root.left);
        int rightMax = maxDepth(root.right);
        return Math.max(leftMax,rightMax) + 1;
    }
}
```

## [101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)[简单]✅

**题目：**给你一个二叉树的根节点 `root` ， 检查它是否轴对称。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764172449158-983a111c-db66-4df3-bc16-dde5e47a3c05.png)

**思路：**检查这棵树是否对称，即检查根节点的左右子树是否镜像对称

比较两个树是否是镜像对称：

- left.val 等于 right.val。
- left 的左子树与 right 的右子树互为镜像。这是一个和原问题相似的子问题，可以递归判断。
- left 的右子树与 right 的左子树互为镜像。这是一个和原问题相似的子问题，可以递归判断。

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null){
            return true;
        } 
        // 检查root的左右子树是否对称
        return check(root.left, root.right);
    }

    // 检查两棵树是否是对称的
    public boolean check(TreeNode left, TreeNode right) {
        if (left == null && right == null) return true;
        if (left == null || right == null) return false;
        if (left.val != right.val) return false;
        // 递归检查 left的左子树与right的右子树是否对称 以及  left的右子树与right的左子树是否对称
        return check(left.left, right.right) && check(left.right, right.left);
    }
}
```

## [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)[简单]✅

**题目：**给你一棵二叉树的根节点，返回该树的 **直径** 。

二叉树的 **直径** 是指树中任意两个节点之间最长路径的 **长度** 。这条路径可能经过也可能不经过根节点 `root` 。

两节点之间路径的 **长度** 由它们之间边数表示。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764172789967-45c8d586-816c-4f7c-9fb7-d8d52473c4df.png)

**思路：**首先，每一条直径都会有一个顶点(即处于更上层的节点)，那么以某个节点为顶点的最长直径怎么求？

可以等价于该节点的 左子树最大深度+右子树最大深度

以示例一举例，显然最长直径是 4-2-1-3 顶点是1，那么

- 1的左子树的最大深度是2
- 1的右子树的最大深度是1
- 因此以1为顶点的最长直径 = 2+1 = 3

因此分解问题: 求最长直径, 相当于对每一个节点求出左右子树的最大深度之和后，再从中取出去最大值

```java
class Solution {
    public int maxDimeter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        maxDepth(root);
        return maxDimeter;
    }

    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }
        int leftMaxDepth = maxDepth(root.left); // 左子树最大深度
        int rightMaxDepth = maxDepth(root.right);  // 右子树最大深度
        // 在后序位置 更新最大直径（外部变量）
        // 以root为顶点的最长直径 = 左子树最大深度+右子树最大深度
        maxDimeter = Math.max(maxDimeter, leftMaxDepth + rightMaxDepth);
        // 返回当前节点的深度 = 左右子树深度的最大值 + 1
        return Math.max(leftMaxDepth, rightMaxDepth) + 1;
    }
}
```

## [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)[中等]✅

**题目：**给你二叉树的根节点 `root` ，返回其节点值的 **层序遍历** 。 （即逐层地，从左到右访问所有节点）。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764174767825-899b05c9-1710-41a8-90ec-aa9a90565010.png)

**思路：**使用队列辅助实现，注意初始化时： 把根节点加入队列

当队列不为空的情况下，获取当前队列中的数据个数，意味着当前这一层有几个节点需要弹出

当从队列中取出节点时，要把该节点的左孩子和右孩子以此加入队列，等待下一次循环时再弹出

达到一层一层遍历的目的

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        // 使用队列(先进先出)辅助 
        Queue<TreeNode> queue = new ArrayDeque<>(); 
        if (root == null){
            return res;
        } 
        queue.add(root);
        while (!queue.isEmpty()) {
            int size = queue.size(); // 获取这一层数据的个数,然后才知道这一层需要弹出几个元素
            List<Integer> inside = new ArrayList<>(); // 保存每一层的数据
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();   // 弹出根节点
                inside.add(node.val);           // 把根节点加入当前层的集合
                if (node.left != null) {        // 根节点的左子节点加入
                    queue.add(node.left);
                }
                if (node.right != null) {       // 根节点的右子节点加入
                    queue.add(node.right);
                }
            }
            res.add(inside);
        }
        return res;
    }
}
```

## [108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)[简单]✅

**题目：**给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵平衡二叉搜索树。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751529217062-8d347216-65d8-400f-acac-0ac7d609b19c.png)

**思路：**

示例 1 nums=[−10,−3,0,5,9]，我们从数组正中间的数 nums[2]=0 开始，把数组一分为二，得到两个小数组：

- 左：[−10,−3]
- 右：[5,9]

答案由三部分组成：

- 根节点：节点值为 nums[2]=0
- 把 nums[2] 左边的 [−10,−3] 转换成一棵平衡二叉搜索树，作为答案的左儿子。这是一个和原问题相似的子问题，可以递归解决
- 把 nums[2] 右边的 [5,9] 转换成一棵平衡二叉搜索树，作为答案的右儿子。这是一个和原问题相似的子问题，可以递归解决

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    // 把 nums[left] 到 nums[right] 转成平衡二叉搜索树
    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) {
            return null;
        }
        // 中间元素作为当前二叉树的根节点root
        int mid = (left + right) / 2;
        TreeNode root = new TreeNode(nums[mid]);
        // 根节点的左子树由数组左半区间构成
        root.left = build(nums, left, mid - 1);
        // 根节点的右子树由数组右半区间构成
        root.right = build(nums, mid + 1, right);
        return root;
    }
}
```

## [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)[中等]✅

**题目：**给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：

- 节点的左子树只包含 **小于** 当前节点的数。
- 节点的右子树只包含 **大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764476593011-6f05b132-7378-4be2-9dfb-2d2806c98e0f.png)

**思路：**如果一颗二叉树是二叉搜索树，那么它的中序遍历的结果，一定是递增的

因此只需要求出二叉树的中序遍历结果，并且判断是否递增即可

```java
class Solution {
    // 存储中序遍历结果的列表
    private List<Integer> inorderList;
    
    public boolean isValidBST(TreeNode root) {
        inorderList = new ArrayList<>();
        // 通过中序遍历获取所有节点值
        performInorderTraversal(root);
        
        // 检查是否严格递增
        for (int i = 0; i < inorderList.size() - 1; i++) {
            if (inorderList.get(i) >= inorderList.get(i + 1)) {
                return false;
            }
        }
        return true;
    }
    
    // 中序遍历
    private void performInorderTraversal(TreeNode node) {
        if (node == null) return;
        
        performInorderTraversal(node.left);
        inorderList.add(node.val);
        performInorderTraversal(node.right);
    }
}
```

## [230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)[中等]✅

**题目：**给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k`小的元素（从 1 开始计数）。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764486695015-426d50f5-6061-49e8-a0d1-c8126140ce85.png)

**思路**：因为是二叉搜索树，所以它的中序遍历结果一定是递增的，因此先求出中序遍历结果，再取出其第k小的数

```java
class Solution {
    // 存储中序遍历结果的列表
    private List<Integer> inorderList;

    public int kthSmallest(TreeNode root, int k) {
        inorderList = new ArrayList<>();
        // 通过中序遍历获取所有节点值
        performInorderTraversal(root);
        // 第k小的数即中序遍历结果中的第k-1个数(注意下标从0开始)
        return inorderList.get(k - 1);
    }

    // 中序遍历
    private void performInorderTraversal(TreeNode node) {
        if (node == null)
            return;

        performInorderTraversal(node.left);
        inorderList.add(node.val);
        performInorderTraversal(node.right);
    }
}
```

## [199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)[中等]✅

**题目：**给定一个二叉树的 **根节点**`root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764487113234-ccbe3280-d65f-4fbe-8e40-147e7581431a.png)

**思路：**层序遍历，遍历每一层时都会有最后一个节点，把每一层的最后一个节点记录下来，即为答案

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        
        // 使用队列(先进先出)辅助 
        Queue<TreeNode> queue = new ArrayDeque<>();
        if (root == null) {
            return res;
        }
        queue.add(root);
        while (!queue.isEmpty()) {
            int size = queue.size(); // 获取这一层数据的个数,然后才知道这一层需要弹出几个元素
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll(); // 弹出根节点
                if (node.left != null) { // 根节点的左子节点加入
                    queue.add(node.left);
                }
                if (node.right != null) { // 根节点的右子节点加入
                    queue.add(node.right);
                }
                if (i == (size - 1)) {
                    res.add(node.val);
                }
            }
        }
        return res;
    }
}
```

## [114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)[中等]✅

**题目：**给你二叉树的根结点 `root` ，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。
- 展开后的单链表应该与二叉树 [**先序遍历**](https://baike.baidu.com/item/%E5%85%88%E5%BA%8F%E9%81%8D%E5%8E%86/6442839?fr=aladdin) 顺序相同。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764487857602-9fdd8357-1d7c-4378-b3cd-a41662893492.png)

**思路：**

**方案一：**展开后的单链表与二叉树的先序遍历相同，所以先把二叉树的先序遍历求解出来，再构造展开的二叉树

```java
class Solution {
    public void flatten(TreeNode root) {
        preorderTraversal(root);
        TreeNode cur = root;
        // 根据先序遍历的结果，构造展开的单链表
        for (int i = 1; i < list.size(); i++) {
            cur.right = list.get(i); // 不断的设置右子树
            cur.left = null;		// 左子树通通设置为null
            cur = cur.right;
        }
    }

    List<TreeNode> list = new ArrayList<>();
    // 先序遍历
    public void preorderTraversal(TreeNode root) {
        if (root == null)
            return;
        list.add(root);
        preorderTraversal(root.left);
        preorderTraversal(root.right);
    }
}
```

**方案二：**递归，分解问题，展开整个二叉树，可以理解为：

展开左子树和展开右子树，并且再把左子树放到右子树的位置上，再把右子树拼接在左子树的最右下的节点上

```java
class Solution {
    public void flatten(TreeNode root) {
        if(root == null){
            return;
        }
        flatten(root.left);     //展开左子树
        flatten(root.right);    //展开右子树
        // 暂存右子树
        TreeNode tempRight = root.right;
        // 把展开后的左子树放到右子树的位置上
        root.right = root.left;
        // 把左子树置为空
        root.left = null;
        // 先找到展开后的左子树的最右边的节点
        TreeNode curRightest = root;
        while(curRightest.right != null){
            curRightest = curRightest.right;
        }
        // 把之前展开的右子树放在最右边节点的右子树上
        curRightest.right = tempRight;
    }
}
```

## [105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)[中等]✅

**题目：**给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764489862561-a42f78a7-5ed2-426a-b9df-1de2728fb4a2.png)

**思路：**已知前序遍历和中序遍历的结果，那么从这两个数组，我们可以获得什么信息，以示例一举例

- 从前序遍历的结果数组来看，第一个元素 3 一定是根节点
- 在中序遍历的结果数组中找到3(由于在题目补充条件中已说明二叉树中的值是各不相同的)，那么3的左边[9]即是左子树，3的右边[15,20,7]即是右子树
- 通过知道3的左右子树的元素个数，进一步也可以知道在前序遍历中，[9]是左子树，[20,15,7]是右子树

递归，分解问题，构建左子树和右子树的过程都可以通过上述两个步骤进行

例如右子树的在前序遍历中的内容是 [20,15,7]； 在中序遍历中的内容是 [15,20,7]，那么即可知道

- 右子树的根节点是20，右子树的左子树部分是[15]，右子树的右子树部分是[7]

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764517927820-8b6b5e19-15dd-4c98-8912-8d3d3823f440.png)

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        int len = preorder.length;
        if (len == 0) {
            return null;
        }
        TreeNode root = new TreeNode(preorder[0]);
        // 找到根节点在中序遍历中的索引位置,这个值也是左子树的所有元素个数
        int rootInInorder = indexOf(inorder, preorder[0]);
        // 前序遍历中左子树的部分和右子树的部分
        int[] preLeft = Arrays.copyOfRange(preorder, 1, 1 + rootInInorder);   // 复制是左闭右开区间
        int[] preRight = Arrays.copyOfRange(preorder, 1 + rootInInorder, len);
        // 中序遍历中左子树的部分和右子树的部分
        int[] inLeft = Arrays.copyOfRange(inorder, 0, rootInInorder);
        int[] inRight = Arrays.copyOfRange(inorder, 1 + rootInInorder, len);
        // 递归构建左右子树
        root.left = buildTree(preLeft, inLeft);
        root.right = buildTree(preRight, inRight);
        return root;
    }
    // 返回 x 在 a 中的下标，保证 x 一定在 a 中
    private int indexOf(int[] a, int x) {
        for (int i = 0; ; i++) {
            if (a[i] == x) {
                return i;
            }
        }
    }
}
```

## [437. 路径总和 III](https://leetcode.cn/problems/path-sum-iii/)[中等]✅

**题目：**给定一个二叉树的根节点 `root` ，和一个整数 `targetSum` ，求该二叉树里节点值之和等于 `targetSum` 的 **路径** 的数目。

**路径** 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764519823980-9e5ba28b-2107-4029-86fd-b1767ab5826e.png)

**思路：**

1. 遍历(枚举)所有节点——可以使用DFS或BFS，这里使用DFS
2. 计算以某一个节点为起点的满足条件的路径的个数，即以当前节点为起点，搜索所有向下的路径——用DFS

```java
class Solution {
    private int result;      // 存储最终结果（路径数量）
    private int targetSum;   // 目标路径和
    
    public int pathSum(TreeNode root, int targetSum) {
        this.targetSum = targetSum;
        this.result = 0;
        // 遍历每个节点，以每个节点为起始点进行深度优先搜索
        traverseAllNodes(root);
        return result;
    }
    
    /**
     * 遍历二叉树的所有节点，为每个节点调用dfs深度优先搜索
     * @param node 当前节点
     */
    private void traverseAllNodes(TreeNode node) {
        // 递归终止条件：当前节点为空
        if (node == null) {
            return;
        }
        // 以当前节点为起点，搜索所有向下的路径,在dfs中统计满足条件的路径数目
        dfs(node, (long)node.val);
        // 遍历枚举左子树和右子树的所有节点
        traverseAllNodes(node.left);
        traverseAllNodes(node.right);
    }
    
    /**
     * dfs深度优先搜索，计算以当前节点为起点的所有路径和
     * @param node 当前节点
     * @param currentSum 当前路径和
     */
    private void dfs(TreeNode node, long currentSum) {
        // 检查当前路径和是否等于目标值
        if (currentSum == targetSum) {
            result++;
        }
        // 向左右子树继续搜索
        if (node.left != null) {
            dfs(node.left, currentSum + node.left.val);
        }
        if (node.right != null) {
            dfs(node.right, currentSum + node.right.val);
        }
    }
}
```

## [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)[中等]✅

**题目：**给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764595775984-64536254-3b77-4d95-a72f-6dc07de55d25.png)

**思路**：以示例一的二叉树举例要找到6和4的最近公共祖先，首先

- 用dfs找到从根节点到6的路径：3 5 6
- 用dfs找到从根节点到4的路径：3 5 2 4

将这两条路径，分别保存到集合中，然后同时遍历两条路径，找到最后一个相同的节点5，即是最近公共祖先

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 临时存储当前路径，用于深度优先搜索
        List<TreeNode> tempPath = new ArrayList<>();
        // 存储从根节点到节点p的路径
        List<TreeNode> pathToP = new ArrayList<>();
        // 存储从根节点到节点q的路径
        List<TreeNode> pathToQ = new ArrayList<>();
        
        // 通过深度优先搜索找到两条路径
        dfs(root, p, q, tempPath, pathToP, pathToQ);
        
        TreeNode res = null;
        // 同时遍历两条路径，找到最后一个相同的节点（即最近公共祖先）
        for (int i = 0; i < pathToP.size() && i < pathToQ.size(); i++) {
            if (pathToP.get(i) == pathToQ.get(i)) {
                // 当前节点相同，更新结果
                res = pathToP.get(i);
            } else {
                // 遇到第一个不同的节点，停止比较
                break;
            }
        }
        return res;
    }

    // 深度优先搜索函数，用于查找节点p和q的路径
    public void dfs(TreeNode node, TreeNode p, TreeNode q, 
                    List<TreeNode> tempPath, 
                    List<TreeNode> pathToP, 
                    List<TreeNode> pathToQ) {
        // 基本情况：如果当前节点为空，直接返回
        if (node == null) {
            return;
        }
        
        // 1. 添加当前节点到临时路径
        tempPath.add(node);
        
        // 2. 检查当前节点是否为p
        if (node == p) {
            // 找到p的路径，将当前路径复制到pathToP
            pathToP.addAll(tempPath);
        }
        // 3. 检查当前节点是否为q
        if (node == q) {
            // 找到q的路径，将当前路径复制到pathToQ
            pathToQ.addAll(tempPath);
        }
        
        // 4. 如果还没找到两个节点的路径，继续搜索左右子树
        if (pathToP.isEmpty() || pathToQ.isEmpty()) {
            dfs(node.left, p, q, tempPath, pathToP, pathToQ);
            dfs(node.right, p, q, tempPath, pathToP, pathToQ);
        }
        
        // 5. 回溯：移除当前节点，回到上一层
        tempPath.remove(tempPath.size() - 1);  // 回溯
    }
}
```

## [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)[困难]✅

**题目：**二叉树中的 **路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764595155504-a90ec997-7ffe-4ad3-a109-7286fe0fed51.png)

**思路：**对每个节点，计算“以它为最高点的最大路径”，在过程中记录全局最大值。

我们把大问题分解成小问题：**对于每个节点，计算“以它为转折点的最大路径和”**

什么是“转折点”？比如路径 2-1-3，1 就是转折点，路径从左子树来到右子树。

关键概念

1. **单边最大路径**：从某个节点**往下走**（只能选左或右一支）能获得的最大和
2. **以当前节点为转折点的最大路径**：左最大单边路径 + 节点值 + 右最大单边路径

算法步骤

1. **从叶子节点开始计算**（递归到底部）
2. **对每个节点**：

- 计算左子树的“单边最大路径”（如果是负数就取0，因为可以不要）
- 计算右子树的“单边最大路径”
- **更新全局最大值**：  
  `最大路径和 = max(当前最大值, 左+右+当前节点值)`
- **返回给父节点** 为什么返回的是单边路径？：  
  `当前节点的单边最大路径 = 当前节点值 + max(左单边, 右单边)`因为递归时，当前节点需要告诉父节点：“从我这里往上，最好的情况是多少”。父节点只能选择左或右一支，所以返回最大的单边。

```java
class Solution {
    int res = Integer.MIN_VALUE;
    public int maxPathSum(TreeNode root) {
        dfs(root);
        return res;
    }
    int dfs(TreeNode node){
        if(node == null){
            return 0;
        }
        // 递归求解左子树和右子树的最大单边路径和,如果出现负数的情况则取0
        int leftMax = Math.max(0, dfs(node.left));
        int rightMax = Math.max(0, dfs(node.right));
        // 在递归过程中，计算当前节点为中心向下能找到的最大路径和
        res = Math.max(res, leftMax + rightMax + node.val);
        // 在递归过程中返回的不是“当前节点为中心的最大路径”，而是“从当前节点向上延申能组成的最大单边路径和”，以供父节点使用
        return node.val + Math.max(leftMax, rightMax);
    }
}
```
