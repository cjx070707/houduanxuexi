## [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)[简单]✅

**题目：**给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759653569820-8c475047-91d1-4fe2-b9c5-ecc19b215be4.png)

**思路：**遍历字符串的每个字符，如果遇到左括号就放入栈中，如果遇到右括号，就取出栈顶的左括号与之匹配

若不匹配说明当前字符串不是有效的括号，直接返回false，若匹配，则消掉栈顶的左括号和当前右括号

当遍历完成后，若栈内是空的，则说明当前字符串是有效的括号，若栈内还剩余有左括号，说明不符合

```java
class Solution {
    public boolean isValid(String s) {
        int n = s.length();
        if (n % 2 == 1) {
            return false;
        }
        // 哈希表的键为右括号,值为相同类型的左括号,用于快速判断括号是否匹配
        Map<Character, Character> pairs = new HashMap<Character, Character>() {{
            put(')', '(');
            put(']', '[');
            put('}', '{');
        }};
        Deque<Character> stack = new LinkedList<Character>();
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            // 若当前字符为 右括号
            if (pairs.containsKey(ch)) {
                // 若栈内为空 或 栈顶元素(左括号) 不是与当前右括号匹配的类型，直接返回false
                if (stack.isEmpty() || stack.peek() != pairs.get(ch)) {
                    return false;
                }
                // 匹配,则弹出栈顶元素(左括号)
                stack.pop();
            } else {
                // 若当前字符不是右括号，则加入栈中
                stack.push(ch);
            }
        }
        // 遍历完成，若栈内为空，则返回true，若栈内还剩余元素，则说明不符合返回false
        return stack.isEmpty();
    }
}
```

## [155. 最小栈](https://leetcode.cn/problems/min-stack/)[中等]✅

**题目：**设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

实现 `MinStack` 类:

- `MinStack()` 初始化堆栈对象。
- `void push(int val)` 将元素val推入堆栈。
- `void pop()` 删除堆栈顶部的元素。
- `int top()` 获取堆栈顶部的元素。
- `int getMin()` 获取堆栈中的最小元素。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759657089954-5f2986f4-0e1d-4497-bd17-378420e55e03.png)

**思路：**

- 需要两个栈，主栈用于保存正常push进的元素，一个辅助栈 min\_stack，用于存 以及 获取 stack 中最小值
- **算法流程：**

- push() 方法： 每当 push() 新值进来时，如果 新值 <= min\_stack的栈顶值，则把新值也存入 min\_stack，使得 min\_stack 的栈顶始终是整个栈 stack 中的最小值
- pop() 方法： 若当前要弹出的元素 (是最小值) == min\_stack 的栈顶值(即最小值)，那么也要把min\_stack的栈顶值弹出，这样可以保证 min\_stack 栈顶元素始终是整个栈 stack 中的最小值
- getMin()方法： 返回 min\_stack 栈顶元素即可
- top()方法：返回 stack 栈顶元素即可

- **min\_stack 作用分析：**

- 因为 stack 是可能弹出元素的，所以整个栈的最小值是动态变化的，有可能 最小值由 a 变成 b（因为弹出b） 再变成 a ；因此最小值也需要动态的记录，而 **min\_stack 专门用于跟踪和存储主栈中的最小值序列**，它维护了一个"最小值的历史记录"，使得我们能够在O(1)时间内获取当前栈中的最小元素

```java
class MinStack {
    private Stack<Integer> stack;
    private Stack<Integer> min_stack;

    public MinStack() {
        stack = new Stack<>();
        min_stack = new Stack<>();
    }
    public void push(int x) {
        stack.push(x);
        // 新值 <= min_stack的栈顶值，则把新值也存入 min_stack
        if (min_stack.isEmpty() || x <= min_stack.peek()) {
            min_stack.push(x);
        }
    }
    public void pop() {
        Integer stackTop = stack.pop();
        // 若当前要弹出的元素 (是最小值) == min_stack的栈顶值(即最小值)，那么也要把min_stack的栈顶值弹出
        if (stackTop.equals(min_stack.peek())) {
            min_stack.pop();
        }
    }
    public int top() {
        return stack.peek();
    }
    public int getMin() {
        return min_stack.peek();
    }
}
```

## [394. 字符串解码](https://leetcode.cn/problems/decode-string/)[中等]✅

**题目：**给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

- 你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。
- 此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759661479904-6871d817-33ed-4d22-bb75-125537604c38.png)

**思路：**`这种题最好先看视频题解`

需要借助一个栈，遍历字符串的每个字符，遍历过程中

1. 只要字符不是右括号']'，就将字符压入栈，压栈直到遇到右括号']'
2. 此时遇到右括号']'，右括号']'就不用入栈了，此时那么只要栈顶的元素不是左括号'['时，就把栈顶元素弹出，即解析最里层[]内的字符串，用temp暂存。一直弹出栈直到遇到'['，
3. 此时遇到了左括号'['，说明最里层 [] 内的字符串已经解析完毕，即temp
4. 弹出栈顶的左括号'['
5. 接着解析左括号'['左边的数字,可能是多位,也可能是0，弹栈直到栈顶不为数字
6. 当数字解析完毕后，根据 []内的字符串 和 [] 左边的数字 重新拼接一个字符串
7. 拼接完成，把新的字符串压入栈中

遍历过程完成后，将stack里的结果取出拼接后返回即可

- 如果是像这种有多个括号分开的"3[a]2[bc]",最终stack中会有两个字符串[aaa,bcbc]因此需要将栈里的字符串拼接起来
- 如果是像有一个整体大括号包裹的"3[a2[c]]",那么最终stack中就只会有一个字符串[accaccacc]

**注意**：我们使用栈来存储字符串片段，遇到右括号时，将直到左括号的字符串弹出，然后弹出左括号，再弹出数字，然后根据数字重复字符串片段，再将重复后的字符串压入栈中。这样，内层的括号会先被处理，符合从内到外解码的顺序。可以结合代码和代码下面的实例运行流程或视频综合理解。

```plain
我们以输入字符串 s = "3[a]2[bc]" 为例，模拟整个程序的运行过程。
初始化：栈 stack 为空。
遍历字符串 s 的每个字符：
    第一个字符：'3'
    不是 ']'，所以将 "3" 压入栈。 stack: ["3"]
    第二个字符：'['
    不是 ']'，所以将 "[" 压入栈。 stack: ["3", "["]
    第三个字符：'a'
    不是 ']'，所以将 "a" 压入栈。 stack: ["3", "[", "a"]
    第四个字符：']'
    遇到 ']'，开始处理：
            1. 弹出栈顶元素直到遇到 '['，将弹出的字符串拼接（注意顺序，先弹出的在后面）：
    弹出 "a"，此时 temp = "a"（注意：我们是用 temp = 弹出的元素 + temp，所以顺序正确）
    然后栈顶是 "["，停止。 stack: ["3", "["]
            2. 弹出 '['，现在 stack: ["3"]
            3. 然后弹出数字，直到栈为空或者栈顶不是数字。当前栈顶是 "3"，是数字，弹出，num = "3"（注意：数字可能是多位，这里只有一位）
    然后栈为空，停止。 stack: []
            4. 将 num 转换成整数，repeatNum = 3。
            5. 将 temp 重复 repeatNum 次，得到 newStr = "a"重复3次，即 "aaa"。
            6. 将 newStr 压入栈。 stack: ["aaa"]
    第五个字符：'2'
    不是 ']'，将 "2" 压入栈。 stack: ["aaa", "2"]
    第六个字符：'['
    不是 ']'，将 "[" 压入栈。 stack: ["aaa", "2", "["]
    第七个字符：'b'
    不是 ']'，将 "b" 压入栈。 stack: ["aaa", "2", "[", "b"]
    第八个字符：'c'
    不是 ']'，将 "c" 压入栈。 stack: ["aaa", "2", "[", "b", "c"]
    第九个字符：']'
    遇到 ']'，开始处理：
            1. 弹出栈顶元素直到遇到 '['：
    先弹出 "c"，temp = "c"
    再弹出 "b"，temp = "b" + "c" -> "bc"
    然后栈顶是 "["，停止。 stack: ["aaa", "2", "["]
            2. 弹出 '['，现在 stack: ["aaa", "2"]
            3. 弹出数字，栈顶是 "2"，弹出，num = "2"。 stack: ["aaa"]
            4. repeatNum = 2。
            5. newStr = "bc"重复2次，即 "bcbc"。
            6. 将 "bcbc" 压入栈。 stack: ["aaa", "bcbc"]
遍历结束。
然后，将栈中所有元素弹出并拼接（注意顺序，先弹出的在后面）：
先弹出 "bcbc"，res = "bcbc"
再弹出 "aaa"，res = "aaa" + "bcbc" -> "aaabcbc"
所以最终输出为 "aaabcbc"。
```

```java
class Solution {
    public String decodeString(String s) {
        Stack<String> stack = new Stack<>();
        for (char ch : s.toCharArray()) {
            if (ch != ']') {
                // 只要不是']',就把字符转成字符串压入栈中
                stack.push(String.valueOf(ch));
            } else {
                // 遇到了 ']', ']'就不用入栈了
                // 而只要栈顶的元素不是'['时，就把栈顶元素弹出，即解析最里层[]内的字符串,用temp暂存
                String temp = "";
                while(!stack.peek().equals(String.valueOf('['))){
                    temp = stack.pop() + temp;
                }
                // 当跳出循环时,即遇到了'[',说明最里层[]内的字符串已经解析完毕，即temp
                // 弹出栈顶的左括号
                stack.pop();
                // 解析'['左边的数字,可能是多位,也可能是0
                String num = "";
                while(!stack.isEmpty() && Character.isDigit(stack.peek().charAt(0))){
                    num = stack.pop() + num;
                }
                int repeatNum = num.equals("") ? 0 : Integer.valueOf(num);

                // 当跳出循环，说明数字已经解析完毕,即repeatNum
                // 根据 temp 和 repeatNum 重新拼接一个字符串
                String newStr = "";
                for(int i = 0; i < repeatNum; i++){
                    newStr += temp;
                }
                // 拼接完毕，把新的字符串压入栈中
                stack.push(newStr);
            }
        }
        // 如果是像这种有多个括号分开的"3[a]2[bc]",最终stack中会有两个字符串[aaa,bcbc]因此需要将栈里的字符串拼接起来
        // 如果是像只有一个整体大括号包裹的"3[a2[c]]",那么最终stack中就只会有一个字符串[accaccacc]
        String res = "";
        while(!stack.isEmpty()){
            res = stack.pop() + res; // 注意拼接的顺序
        }
        return res;
    }
}
```

## [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)[中等]✅

**题目：**给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759672135474-de99a233-885b-468f-b6bc-c3a06b9f0cf2.png)

**思路：**`这种题最好先看视频题解`

我们使用单调栈（单调递减栈）来存储数组下标，栈中的下标对应的温度是递减的（从栈底到栈顶）

遍历每日温度数组，当我们遍历到一个新的温度时

- 如果 当前遍历的温度 比 栈顶对应的温度 高，那么就找到了栈顶元素的下一个更高温度，计算(当前遍历的温度和栈顶温度的)天数差，且将天数差存入对应位置，最后将栈顶元素弹出栈顶（因为它的下一个更高温度已经找到了，没有用处了）
- 如果 当前遍历的温度 小于等于 栈顶对应的温度，那么我们就将当前温度的索引压入栈，保持栈的单调性

当遍历完成，如果栈中还有元素，那么说明 其对应的温度 是没有下一个更高温度的，其结果默认为 0，符合要求

```java
我们以输入 temperatures = [73,74,75,71,69,72,76,73] 为例，模拟过程：
初始化：栈 stack = []，结果数组 res = [0,0,0,0,0,0,0,0]
for(int i = 0; i < temperatures.length; i++) 循环开始
第0天: i=0, temperature=73
    栈为空，所以将0入栈 -> stack = [0]
第1天: i=1, temperature=74
    栈非空，且74>73（栈顶0对应的温度），所以：
    index = stack.peek() = 0
    res[0] = 1-0 = 1
    弹出0 -> stack = []
    然后栈为空，将1入栈 -> stack = [1]
第2天: i=2, temperature=75
    栈非空，且75>74（栈顶1对应的温度），所以：
    index = 1
    res[1] = 2-1 = 1
    弹出1 -> stack = []
    然后栈为空，将2入栈 -> stack = [2]
第3天: i=3, temperature=71
    栈非空，但71<=75（栈顶2对应的温度），所以将3入栈 -> stack = [2,3]
第4天: i=4, temperature=69
    栈非空，但69<=71（栈顶3对应的温度），所以将4入栈 -> stack = [2,3,4]
第5天: i=5, temperature=72
    栈非空，且72>69（栈顶4对应的温度），所以：
    index = 4
    res[4] = 5-4 = 1
    弹出4 -> stack = [2,3]
    继续，栈非空，且72>71（栈顶3对应的温度），所以：
    index = 3
    res[3] = 5-3 = 2
    弹出3 -> stack = [2]
    现在栈顶是2，温度75>72，所以不再弹出，将5入栈 -> stack = [2,5]
第6天: i=6, temperature=76
    栈非空，且76>72（栈顶5对应的温度），所以：
    index = 5
    res[5] = 6-5 = 1
    弹出5 -> stack = [2]
    继续，栈非空，且76>75（栈顶2对应的温度），所以：
    index = 2
    res[2] = 6-2 = 4
    弹出2 -> stack = []
    栈为空，将6入栈 -> stack = [6]
第7天: i=7, temperature=73
    栈非空，但73<=76（栈顶6对应的温度），所以将7入栈 -> stack = [6,7]
遍历结束，此时栈中还有[6,7]，对应的res[6]和res[7]为0（初始化值），符合要求。
最终结果: [1,1,4,2,1,1,0,0]
通过模拟，我们可以看到单调栈的过程：我们维护一个单调递减的栈，当遇到一个比栈顶温度高的天数时，我们依次弹出栈顶并更新结果，直到栈顶温度比当前温度高（或栈空）为止，然后将当前天数入栈。
```

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        Stack<Integer> stack = new Stack<>();  // 栈存储的是 温度数组的下标索引，而非值
        int[] res = new int[temperatures.length];
        // 遍历每日温度数组
        for(int i = 0; i < temperatures.length; i++){
            // 若栈不为空,且 今天的温度 大于 栈顶温度，那么就找到了 距离栈顶温度最近的 下一个更高温度: 即今天
            while(!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]){
                int index = stack.peek();   // 栈顶温度那天的下标
                res[index] = i - index;     // 距离栈顶温度最近的下一个更高温度出现在 = [今天-栈顶温度那天的下标] 天后
                stack.pop();                // 已经找到了栈顶温度那天的结果，无用了就弹出
            }
            stack.push(i);                 // 今天的温度的下标先存入栈
        }
        return res;
    }
}
```

## [84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)[困难]✅

**题目：**给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759672164700-1907c655-e137-4ffe-910a-3848e00ac92e.png) ![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1759672174501-456e56b7-8811-466b-b9bc-109b104e211f.png)

**思路：**对每一个柱子，需要获取到它左右两边的第一个小于该柱子高度的柱子的位置，以当前柱子为高度，左右两边第一个小于该高度的柱子之间的距离作为宽度求出当前柱子能勾勒出的矩形的面积，记录下最大值。

例如 以示例一中的 `柱子 5` 为例，左边第一个小于 5 的是 `柱子 1 (索引为1，记为left)`，右边第一个小于 5 的是 `柱子2 (索引为4，记为right)`，因此 柱子5 所能勾勒出的矩形的面积是 `高(5) x 宽(right - left -1 = 2) = 10`

那么对每一个柱子，如何获取到柱子左右两边第一个小于当前高度的柱子的位置呢？我们可以使用 left[] 和 right[] 两个数组 进行记录，规定：

- left[i] 表示 柱子[i] 左边第一个小于 柱子[i] 高度的柱子的索引位置，例如 柱子5 对应的是 left[2] = 1
- right[i] 表示 柱子[i] 右边第一个小于 柱子[i] 高度的柱子的索引位置，例如 柱子5 对应的是 right[2] = 4

结合栈，可以遍历数组一遍，即可把 left[] 和 right[] 都填满，具体方式：

**可参考思路讲解：**<https://www.bilibili.com/video/BV1V6TgzHE8V/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688>

遍历数组时，在遍历到当前元素时，只能确定出当前元素的左边界，以及能确定出部分过往元素的右边界

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        Stack<Integer> stack = new Stack<>(); // 栈只保存heights的索引
        int n = heights.length;
        int[] left = new int[n]; // left[i] 表示 柱子[i] 左边第一个小于 柱子[i] 高度的柱子的索引位置
        int[] right = new int[n]; // right[i]  表示 柱子[i] 右边第一个小于 柱子[i] 高度的柱子的索引位置
        // 初始化left和right数组
        for(int i = 0; i < n; i++){
            left[i] = -1;
            right[i] = n;
        }
        for (int i = 0; i < n; i++) {
            // 如果栈不为空,并且 栈顶的元素 >= 当前元素, 那么当前元素对应的索引 就是 栈顶元素的右边界
            while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
                int idx = stack.pop();
                right[idx] = i;
            }
            // 退出上述循环后,如果栈不为空,那么一定有: 当前元素 > 栈顶的元素，那么可以确定当前元素的左边界
            if (!stack.isEmpty()) {
                left[i] = stack.peek();
            }
            stack.push(i);
        }
        // 计算最大面积
        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, (right[i] - left[i] - 1) * heights[i]);
        }
        return ans;
    }
}
```
