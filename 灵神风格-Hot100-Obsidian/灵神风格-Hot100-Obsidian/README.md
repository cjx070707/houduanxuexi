# 灵神风格 Hot 100 · Obsidian 学习库

这是一套 **可直接放入 Obsidian** 的 Hot 100 学习库，共 100 道题、17 个专题。

## 重要说明

- 这不是灵茶山艾府原题解的批量复制。
- 每道笔记是根据公开题单的算法分类和经典解法，重新写成的大白话总结。
- 每题保留了力扣原题、灵神公开专题题单、灵神题解检索入口。
- Java 部分采用“专题模板 + 每题实现提醒”，避免复制 100 份几乎相同的代码。
- 你自己的独立代码应写入每题的 `我的 Java 代码` 区域。

## 使用方法

1. 解压 ZIP。
2. 把整个文件夹拖进 Obsidian，或选择“打开本地文件夹作为仓库”。
3. 从 [[00-Hot100总目录]] 开始。
4. 每做完一题，修改 YAML 中的 `status`：
   - `todo`
   - `learning`
   - `review`
   - `mastered`
5. 在 [[01-复习看板]] 勾选复习进度。

## 推荐刷法

不要按 1 到 100 随机乱刷。先按专题刷：

1. 哈希、双指针、滑动窗口
2. 链表、二叉树、回溯
3. 二分、栈、堆、图论
4. 动态规划
5. 最后混合模拟面试

灵神公开文章也主张先进行专题训练；面试时间紧时再用 Hot 100 做突击复习。
