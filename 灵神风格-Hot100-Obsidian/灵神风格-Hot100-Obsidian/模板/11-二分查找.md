# Java 二分查找模板

## 第一个大于等于 target 的位置

```java
int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length; // [left, right)
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
}
```

每次二分前先写清楚：寻找什么边界，答案是否可能等于 n。
