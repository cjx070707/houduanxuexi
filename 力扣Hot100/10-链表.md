## [160. 相交链表](https://leetcode.cn/problems/intersection-of-two-linked-lists/)[简单]**✅**

**题目：**给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null` 。

![](https://cdn.nlark.com/yuque/0/2025/png/35797418/1753117457674-ed4903fd-2bdc-46c4-9209-3858e27cf84f.png)

**思路：**如果两个指针同时遍历两个链表，其实两个指针是不能够同时遍历到相交的起始节点的。

那么这里换个思路：指针p1遍历完链表A后接着遍历链表B，而指针p2遍历完链表B后接着遍历链表A

如此那么两个指针就一定会同时遍历到两个链表的相交的起始节点。

```java
class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if(headA == null || headB == null){
            return null;
        }
        ListNode p1 = headA;
        ListNode p2 = headB;
        while(p1 != p2){
            // p1走完链表A走链表B, p2走完链表B走链表A
            // 会不会存在死循环？不会,因为当p1和p2走完两条链表后都会到null,while条件不成立
            p1 = (p1 == null) ? headB : p1.next;
            p2 = (p2 == null) ? headA : p2.next;
        }
        return p1;
    }
}
```

## [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)[简单]**✅**

**题目：**给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753190157126-6e3f6431-31c7-445a-a02c-2dc545e49b2f.png)

**思路：**定义 pre 指针(指向前一个元素)和 cur 指针(指向当前元素)，遍历链表，在遍历的过程中不断的把 链表节点之间的 指针进行反转，即 cur.next = pre。接着 pre 和 cur 指针都向后移动，接着重复上述过程。直到最后，cur 会移动到 null，而 pre 会移动到最后一个节点。此时就可以返回了，因此，while 循环的条件应该是 cur != null，且应当返回 pre 指针。这个题看动画或结合图才会比较清楚。

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        while(cur != null){
            // 记录cur的next为temp
            ListNode temp = cur.next;
            // 指针反转
            cur.next = pre;
            // pre、cur 指针都向后移动一位
            pre = cur;
            cur = temp;
        }
        return pre;
    }
}
```

## [234. 回文链表](https://leetcode.cn/problems/palindrome-linked-list/)[简单]**✅**

**题目：**给你一个单链表的头节点 `head` ，请你判断该链表是否为回文链表。如果是，返回 `true` ；否则，返回 `false` 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753192220093-2d0ac023-8062-45ab-81b3-60b50e0f6bcd.png)

**思路：**

**方案一**：将链表的内容复制到数组，再使用数组双指针一头一尾遍历判断是否回文

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        ArrayList<Integer> num = new ArrayList<>();
        // 将链表的内容复制到数组
        ListNode p = head;
        while (p != null) {
            num.add(p.val);
            p = p.next;
        }
        // 数组双指针一头一尾遍历判断是否回文
        for (int left = 0, right = num.size() - 1; left < right; left++, right--) {
            if (num.get(left) != num.get(right)) {
                return false;
            }
        }
        return true;
    }
}
```

**方案二(优)**：寻找中间节点+反转后半段的链表。再用链表双指针一头一尾都向中间走，遍历判断是否回文

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        //               	 head       head2
        // 1->2->3->2->1      1->2->3<-2<-1   其中3的next为null  
        ListNode midNode = findMidNode(head);   // 找到中间结点
        ListNode head2 = reverseList(midNode);	// 反转后半部分链表
        while(head2 != null){	// 注意反转后，head2部分的链表最后一个节点是指向null的
            // 一头一尾同时向中间走
            if(head.val != head2.val){
                return false;
            }else{
                head = head.next;
                head2 = head2.next;
            }
        }
        return true;
    }
    
    // 876.链表的中间结点：快慢指针,慢指针每次走一步，快指针每次走两步，最终slow就是中间节点
    public ListNode findMidNode(ListNode head){
        ListNode slow = head;
        ListNode fast = head;
        while(fast != null && fast.next != null){
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
    
    // 206.反转链表
    public ListNode reverseList(ListNode head){
        ListNode pre = null;
        ListNode cur = head;
        while(cur != null){
            ListNode temp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = temp;
        }
        return pre;
    }
}
```

## [141. 环形链表](https://leetcode.cn/problems/linked-list-cycle/)[简单]**✅**

**题目：**给你一个链表的头节点 `head` ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：**`pos` **不作为参数进行传递** 。仅仅是为了标识链表的实际情况。

*如果链表中存在环* ，则返回 `true` 。 否则，返回 `false` 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753195457495-7de727dc-31d1-44d1-b075-62de78cb0df1.png)

**思路：**快慢指针，初始时快慢指针都指向head头节点，慢指针每次走一步，快指针每次走两步，**如果链表中存在环**，那么快指针一定会追上慢指针(套圈)，也就是说两个指针一定会相遇。但**如果快指针或快指针的next指针指向空则说明链表中不存在环**。

```java
class Solution {
    public boolean hasCycle(ListNode head) { 
        // 环型链表  可以利用快慢指针
        ListNode fast = head;
        ListNode slow = head;
        while(fast != null && fast.next != null){
            fast = fast.next.next;
            slow = slow.next;
            if(fast == slow){
                return true;	// 相遇,存在环
            } 
        }
        return false;
    }
}
```

## [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)[中等]**✅**

**题目：**给定一个链表的头节点 `head` ，返回链表开始入环的第一个节点。 *如果链表无环，则返回* `null`*。*

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（**索引从 0 开始**）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：**`pos` **不作为参数进行传递**，仅仅是为了标识链表的实际情况。**不允许修改** 链表。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753196194571-f4a0c248-9059-489a-9e95-d4321a3d4354.png)

**思路：**由前一题的基础，我们知道如果有环，slow 每次走一步，fast 每次走两步，那么 slow 和 fast 会在某一点相遇，如果不存在环，则 fast 或 fast.next 会指向null

假设链表中有环，那么当 slow 和 fast 相遇时，我们应该如何找到环的第一个节点

此时由数学推理而出，只需要将 slow 或 fast 任意选一个指针 重新指向head

然后 slow 和 fast 同时每次走一步，最终就会在 链表的 环的第一个节点相遇

（数学推理其实就不用管，只需要记住这个技巧 或 自己用实例模拟去跑一遍，就很简单能够解决）

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753244987251-80ac4adf-dfc9-43bd-b54b-6a516889bce5.png)

```java
class Solution {
    public ListNode detectCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while(fast != null && fast.next != null){
            slow = slow.next;
            fast = fast.next.next;
            if(slow == fast){
                break;
            }
        }
        // 当从循环中出来时,有两种情况
        // 情况1:因while条件不成立而跳出循环，即不存在环,
        // 情况2:因slow==fast成立而break跳出循环，即存在环，且fast和slow相遇了
        // 先判断是否是情况1，不存在环直接结束
        if(fast == null || fast.next == null){
            return null;
        }
        // 那么属于情况2,当前fast和slow指向同一点，只需要让slow或fast任意指针回到head
        // 接着两个指针齐步走，最终就可以找到环的入口结点
        slow = head;
        while(slow != fast){
            slow = slow.next;
            fast = fast.next;
        }
        return slow;
    }
}
```

## [21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)[简单]**✅**

**题目：**将两个升序链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753247772194-9553276f-6e78-4f11-b6bb-001e4068370f.png)

**思路：**当 l1 和 l2 都不是空链表时，判断 l1 和 l2 哪一个链表的头节点的值更小，将较小值的节点添加到结果里，并且将对应链表中的节点向后移一位。不断循环。

我们设定一个哨兵节点 dummy，这可以在最后让我们比较容易地返回合并后的链表。

在循环终止的时候， l1 和 l2 至多有一个是非空的。由于输入的两个链表都是有序的，所以不管哪个链表是非空的，它包含的所有元素都比前面已经合并链表中的所有元素都要大。这意味着我们只需要简单地将非空链表接在合并链表的后面，并返回合并链表即可。

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode();
        ListNode p = dummy;
        ListNode p1 = list1;
        ListNode p2 = list2;
        while(p1 != null && p2 != null){
            if(p1.val > p2.val){
                p.next = p2;
                p2 = p2.next;
            }else{
                p.next = p1;
                p1 = p1.next;
            }
            p = p.next;
        }
        if(p1 != null){
            p.next = p1;
        }else{
            p.next = p2;
        }
        return dummy.next;
    }
}
```

## [2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)[中等]**✅**

**题目：**给你两个**非空**的链表，表示两个非负的整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储**一位**数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753252089252-43600923-be45-4574-982f-f16449e85336.png)

思路：

- 342 逆序存储为：2 → 4 → 3
- 465 逆序存储为：5 → 6 → 4
- 342+465=807 逆序存储为：7 → 0 → 8

题目里逆序存储数字在链表中，其实会让我们的计算更方便！因为两个数的加法都是从个位数开始相加的

因此，只需要顺序遍历两条链表的节点，进行相加，注意保留好进位即可

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        if(l1 == null && l2 == null){
            return null;
        }
        ListNode p1 = l1;
        ListNode p2 = l2;
        int carry = 0;						// 保存进位
        ListNode dum = new ListNode(-1);    // 虚拟头节点
        ListNode p = dum;
        while(p1 != null || p2 != null || carry != 0){  // 记住这个判断条件，只要链表还有数或者有进位就得进入循环
            int sum = carry;
            if(p1 != null){
                sum += p1.val;
                p1 = p1.next;
            }
            if(p2 != null){
                sum += p2.val;
                p2 = p2.next;
            }
            carry = sum / 10;   // 进位(给下个循环使用)
            int temp = sum % 10; // 当前位的值
            
            // 新建节点,衔接到结果链表后
            ListNode tempNode = new ListNode(temp);
            p.next = tempNode;
            p = p.next;
        }
        return dum.next;
    }
}
```

## [19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)[中等]**✅**

**题目：**给你一个链表，删除链表的倒数第 `n`个结点，并且返回链表的头结点。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1751529215330-9d02bb61-1b5b-4cc0-8969-513016f63846.png)

**思路：**要删除倒数第n个结点，那么只需要找到倒数第n+1个节点

假设倒数第n+1个节点为 p，再通过 p.next = p.next.next 即可删除倒数第n个节点

且我们要考虑一种特殊情况，即如果链表长度为10，且要删除倒数第10个节点，即要删除第一个节点

那么就要找到倒数第11个节点，可链表并没有倒数第11个节点，这时候其实就是需要使用虚拟头结点

-

现在的问题在于如何找到倒数第n+1个节点，这里有个规律(记住或者自己在脑子里用实例模拟跑一下)：

- **使用快慢指针，都从dum虚拟头结点出发，让快指针先走n+1步**
- 注意边界情况如果链表的长度小于n则不符合题意（题意要求删除倒数第n个结点）

- 即如果fast先走的过程中，如果出现fast==null，即说明链表长度小于n

- 然后快慢指针同时每次走一步，当快指针走到 null 时，慢指针刚好到达倒数第n+1个结点

例如 // dum -> 1 -> 2 -> 3 -> 4

// 若n = 2 即要删除`节点3` 则需要找到 `节点2 (倒数第3个节点)`

// fast 从dum出发，先走 n+1 即 3 步，走完 fast 指向 `节点3`

// fast 和 slow 同时走，当 fast 指向null时，slow 会指向 `节点2 (倒数第3个节点)`

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 找到倒数第n+1个节点
        ListNode dum = new ListNode(-1, head);
        ListNode fast = dum;
        for (int i = 1; i <= n+1; i++) {
            if (fast == null) {
                // 链表的长度不够
                return head;
            }
            fast = fast.next;
        }
        ListNode slow = dum;
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        // slow就是倒数第n+1个节点
        slow.next = slow.next.next;
        return dum.next;
    }
}
```

## [24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)[中等]**✅**

**题目：**给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1753670192071-30324136-669c-4394-a6ff-7957edf68aaa.png)

**思路：**

**方案一：递归**，符合递归的特性，注意每一分组翻转后，需要将递归结果连接到前一组节点后面

1、从头到尾 进行 递深 (递归深入的过程)

2、会在尾部开始交换（即遇到了递归的终止条件后，需要开始交换了）

3、把交换后的节点返回给上一部分 即归的过程

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 递归终止条件
        if (head == null || head.next == null) {
            return head;
        }
        // 初始化当前两个节点指针,以1-2-3-4举例
        ListNode left = head;			// 1
        ListNode right = head.next;		// 2
        
        // 递归处理剩余链表（从right.next开始）, 递归深入的过程
        // 将递归结果连接到当前第一个节点后面
        left.next = swapPairs(right.next);
        
        // 交换当前两个节点：让第二个节点指向第一个节点
        right.next = left;		// 2——>1
        
        // 返回新的头节点（原第二个节点成为新头）
        return right;			// 返回2
    }
}
```

```java
           dum->1->2->3->4
        经过一次循环后应该变成如下：dum->2->1->3->4
                   p  c  t      开始反转下一组，则 p、c、t 应当是移动到如上位置
           dum->2->1->3->4
        */
        while (cur != null && cur.next != null) { // 至少有两个节点
            // 翻转本组节点 cur和temp
            ListNode temp = cur.next;
            // 注意这三个赋值的顺序不能颠倒
            pre.next = temp;      // 让dum的next指向2
            cur.next = temp.next; // 让cur.next指向3
            temp.next = cur;	  // 让temp.next指向1

            // 移动指针,翻转下一组两个节点
            pre = cur;
            cur = pre.next;
        }
        return dummy.next; // 返回新链表的头节点
    }
}
```

## [25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/)[困难]**✅**

**题目：**给你链表的头节点 `head` ，每 `k`个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k`的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762622956948-a23b4bd7-53f6-4c26-98c6-c1036d772bf9.png)

**思路：**符合递归的特性

- 递归的终止条件是 当前区间不满足k个节点，所以不需要反转，就直接返回那个区间的头节点，那么实际上需要去数一遍当前区间是否满足k个
- 递归每一层级的任务是反转当前区间的链表
- 注意分组翻转后，当前区间需要连接下一个反转区间返回的头节点

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 结束条件
        ListNode tail = head;
        for(int i = 0; i < k; i++){
            if(tail == null){
                return head; // 当前区间不满足k个节点,直接返回当前区间的头节点
            }
            tail = tail.next;	
            // 例如 1-2-3-4-5  k=2的情况下，第一轮循环后，tail会指向3
            // 因为第一个反转区间其实是[1-2] 而tail指向3,即tail是下一个反转区间的第一个节点
        }
        
        // 每级任务:反转链表的代码模式
        ListNode pre = null;
        ListNode cur = head;
        while(cur != tail){// 因为tail是下一个反转区间的第一个节点，所以这里的判断条件才是cur!=tail,如果还不明白可以去看下反转链表那个题目，那里写的是cur!=null
            ListNode temp = cur.next;
            cur.next = pre;
            pre = cur;
            cur = temp;
        }
        
        // 拼接上一级返回的链表,注意反转后，head变成了当前反转区间的最后一个节点
        // 因此用head.next去链接下一个反转区间返回的头节点
        head.next = reverseKGroup(tail, k);
        return pre;  // 例如 1-2-3-4-5  k=2的情况下, 要返回2，即返回每一层级反转后的头节点
    }
}
```

## [138. 随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/)[中等]**✅**

**题目：**给你一个长度为 `n` 的链表，每个节点包含一个额外增加的随机指针 `random` ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 [**深拷贝**](https://baike.baidu.com/item/%E6%B7%B1%E6%8B%B7%E8%B4%9D/22785317?fr=aladdin)。 深拷贝应该正好由 `n` 个 **全新** 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 `next` 指针和 `random` 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。**复制链表中的指针都不应指向原链表中的节点** 。

例如，如果原链表中有 `X` 和 `Y` 两个节点，其中 `X.random --> Y` 。那么在复制链表中对应的两个节点 `x` 和 `y` ，同样有 `x.random --> y` 。

返回复制链表的头节点。

用一个由 `n` 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 `[val, random_index]` 表示：

- `val`：一个表示 `Node.val` 的整数。
- `random_index`：随机指针指向的节点索引（范围从 `0` 到 `n-1`）；如果不指向任何节点，则为 `null` 。

你的代码 **只** 接受原链表的头节点 `head` 作为传入参数。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762609447935-c66554f2-cc9d-4776-8197-1626ffde1c79.png)

**思路：**两次遍历老链表 + 使用哈希表保存老节点与新节点的关系 <老节点，copy的新节点>

第一次遍历老链表，先Copy老节点的值生成新节点，并且保存在Map中，key为老节点，value为新节点

第二次遍历老链表，从Map中取出对应的新节点，并且设置新节点的 next 指针 和 random 指针

```java
class Solution {
    public Node copyRandomList(Node head) {
        Map<Node,Node> oldMapNew = new HashMap<>();
        Node oldCur = head;
        // 第一次遍历
        while(oldCur != null){
            // 生成新节点
            Node tempNew = new Node(oldCur.val);
            // 保存老节点和新节点的映射关系
            oldMapNew.put(oldCur, tempNew);
            oldCur = oldCur.next;
        }
        // 第二次遍历
        oldCur = head;
        while(oldCur != null){
            // 从Map中取出对应的新节点，并且设置新节点的 next 指针 和 random 指针
            Node tempNew = oldMapNew.get(oldCur);
            tempNew.next = oldMapNew.get(oldCur.next);
            tempNew.random = oldMapNew.get(oldCur.random);
            oldCur = oldCur.next;
        }
        return oldMapNew.get(head);
    }
}
```

## [148. 排序链表](https://leetcode.cn/problems/sort-list/)[中等]**✅**

**题目：**给你链表的头结点 `head` ，请将其按 **升序** 排列并返回 **排序后的链表** 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762609468719-76ea0a52-6bbe-4d65-a696-505fad8543df.png)

**思路：**利用归并排序的思想

1. **分割**：将链表从中间分割成两半，需要分割到什么程度呢？要分割到子链表是有序的，所以需要分割到子链表只有一个元素时，才能保证子链表是有序的。
2. **合并**：将两个已排序的子链表合并成一个有序链表

```plain
原始： 4 → 2 → 1 → 3
分割： 4→2  |  1→3
分割： 4 | 2 | 1 | 3  ← 都已有序
合并： 2→4  |  1→3
合并： 1→2→3→4
```

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null){
            return head;
        }
        // 利用快慢指针,将链表一分为二
        ListNode slow = head;
        ListNode fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        // 当循环结束后，慢指针指向的节点就是链表第一部分的最后一个节点
        ListNode secondHead = slow.next;
        slow.next = null; // 断开第一部分与第二部分
        // 对第一部分进行排序,对第二部分进行排序; 后再合并链表
        return mergeTwoLists(sortList(head), sortList(secondHead));
    }

    // 合并两个有序链表,参考上方的第21题
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode();
        ListNode p = dummy;
        ListNode p1 = list1;
        ListNode p2 = list2;
        while(p1 != null && p2 != null){
            if(p1.val > p2.val){
                p.next = p2;
                p2 = p2.next;
            }else{
                p.next = p1;
                p1 = p1.next;
            }
            p = p.next;
        }
        if(p1 != null){
            p.next = p1;
        }else{
            p.next = p2;
        }
        return dummy.next;
    }
}
```

## [23. 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)[困难]**✅**

**题目：**给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762622919562-1faf817a-4dd8-436d-a909-b5ced19fd107.png)

**思路：**

**方案一：**使用小顶堆，一开始 将所有链表的头节点加到小顶堆中，利用小顶堆的特性：最小的元素会排列在顶部，若执行弹出操作时元素从顶部弹出。因此就可以构造合并出新的升序链表。

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        // 创建一个优先级队列(小顶堆)
        PriorityQueue<ListNode> queue = new PriorityQueue<>((o1, o2) -> o1.val - o2.val);
        // 将所有链表的头节点加到小顶堆中
        for (ListNode node : lists) {
            if (node != null) {
                queue.add(node);
            }
        }
        while (!queue.isEmpty()) {
            // 小顶堆的特性：最小的元素在顶部，元素从顶部弹出
            ListNode node = queue.poll();
            cur.next = node;
            cur = cur.next;
            // 将被弹出的链表的下一个节点放回小顶堆
            if (node.next != null) {
                queue.add(node.next);
            }
        }
        return dummy.next;
    }
}
```

**方案二：**在掌握了21题合并两个有序链表的基础下，合并k个链表其实只要利用for循环分组两两合并即可

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }
        // lists中数量大于一个才需要合并
        while (lists.length > 1) {
            // tempLists 用来保存 lists 两两合并后的链表
            ListNode[] tempLists = new ListNode[(lists.length + 1) / 2];
            for (int i = 0, j = 0; i < lists.length; i += 2, j++) {
                ListNode l1 = lists[i];
                // 注意,当lists中链表个数为奇数时,l2有可能为null,因此需要判断
                ListNode l2 = null;
                if (i + 1 < lists.length) {
                    l2 = lists[i + 1];
                }
                tempLists[j] = mergeTwoLists(l1, l2);
            }
            // 当for循环结束,lists已经两两分组合并过一次了，且合并的内容都在tempLists中,因此让lists=tempLists后继续两两合并
            lists = tempLists;
        }
        // 最终合并到tempLists中只有一个元素后while循环可退出
        return lists[0];
    }
    // 合并两个有序链表,参考上方的第21题
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode();
        ListNode p = dummy;
        ListNode p1 = list1;
        ListNode p2 = list2;
        while (p1 != null && p2 != null) {
            if (p1.val > p2.val) {
                p.next = p2;
                p2 = p2.next;
            } else {
                p.next = p1;
                p1 = p1.next;
            }
            p = p.next;
        }
        if (p1 != null) {
            p.next = p1;
        } else {
            p.next = p2;
        }
        return dummy.next;
    }
}
```

## [146. LRU 缓存](https://leetcode.cn/problems/lru-cache/)[困难]**✅**

**题目：**请你设计并实现一个满足 [LRU (最近最少使用) 缓存](https://baike.baidu.com/item/LRU) 约束的数据结构。

实现 `LRUCache` 类：

- `LRUCache(int capacity)` 以 **正整数** 作为容量 `capacity` 初始化 LRU 缓存
- `int get(int key)` 如果关键字 `key` 存在于缓存中，则返回关键字的值，否则返回 `-1` 。
- `void put(int key, int value)` 如果关键字 `key` 已经存在，则变更其数据值 `value` ；如果不存在，则向缓存中插入该组 `key-value` 。如果插入操作导致关键字数量超过 `capacity` ，则应该 **逐出** 最久未使用的关键字。

函数 `get` 和 `put` 必须以 `O(1)` 的平均时间复杂度运行。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1762625275750-bc8a8f90-1a88-4b56-b841-9615dc396a8e.png)

**思路：**使用哈希表和双向链表实现

- 函数 get 和 put 必须以O(1)的平均时间复杂度运行，可以使用哈希表
- LRU 算法需要淘汰最久未使用的 key，因此可以使用双向链表: **维护访问顺序，实现O(1)时间复杂度的插入和删除**。如果使用了某个key，先把该key从链表中删除，然后把该key重新插入到链表头部，那么一直没有被使用的key就会逐渐跑到链表尾部，此时如果要淘汰key，只需要从链表尾部删除元素即可

**get操作：**

1. **哈希表查找**：O(1)找到节点
2. **链表调整**：将节点移到头部（先删除再头部插入）O(1)

**put操作：**

- **key存在**：更新值，将节点移到头部（先删除再头部插入）O(1)
- **key不存在**：

1. 如果容量满：删除尾部节点 O(1)
2. 创建新节点插入头部 O(1)
3. 哈希表添加映射 O(1)

```java
class LRUCache {
    // 双向链表的节点
    private class Node {
        int key, val;
        Node pre;
        Node next;
        private Node() {}
        private Node(int _key, int _val) {
            key = _key;
            val = _val;
        }
    }

    // 双向链表
    private class MyList {
        Node head = new Node(0, 0);
        Node tail = new Node(0, 0);

        private MyList() {
            head.next = tail;
            tail.pre = head;
        }

        // 添加元素到链表头部
        private void addFirst(Node node) {            
            node.next = head.next;
            node.pre = head;
            head.next.pre = node;
            head.next = node;
        }

        // 移除元素
        private void remove(Node node) {
            Node nodePre = node.pre;
            Node nodeNext = node.next;
            nodePre.next = nodeNext;
            nodeNext.pre = nodePre;
        }

        // 移除链表尾部的元素
        private Node removeLast() {
            Node res = tail.pre;
            remove(res);
            return res;
        }
    }

    public int capacity;
    public HashMap<Integer, Node> map;
    public MyList myList;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        map = new HashMap<>();
        myList = new MyList();
    }

    public int get(int key) {
        if (!map.containsKey(key)) {
            return -1;
        }
        Node node = map.get(key);
        myList.remove(node);   // 从链表中移除该元素
        myList.addFirst(node); // 该元素加到链表头部
        return node.val;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;  // 更新value
            myList.remove(node);   // 从链表中移除该元素
            myList.addFirst(node); // 该元素加到链表头部
        } else {
            // 添加新元素
            Node node = new Node(key, value);
            if (map.size() == capacity) {
                // 需要淘汰元素: 从链表尾部移除元素,并且从哈希表中移除该元素
                Node last = myList.removeLast();
                map.remove(last.key);
            }
            // 添加新元素到链表头部, 并且存入哈希表
            myList.addFirst(node);
            map.put(key, node);
        }
    }
}
```
