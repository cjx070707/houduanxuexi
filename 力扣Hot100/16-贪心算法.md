## [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)[简单]✅

**题目：**给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764609947841-0f8deee0-88a5-42d1-a44a-771c28c97fb9.png)

**思路：**如果对所有的买卖点进行枚举，即暴力解法，是O(n²)

实际上这里只需要枚举所有的卖点，因为股票的利润是 卖的价格-买的价格

遍历一遍数组即可，每遍历到一个元素

- 当卖的价格固定，买的价格越便宜，获得利润越大，例如 在 5 时卖出，那么买入点应该取[7,1]中较小者

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764609397258-cbb57630-f029-41e8-8d0c-4537b5e2a095.png)

```java
class Solution {
    public int maxProfit(int[] prices) {
        // 如果数组为空或只有一个元素，无法完成交易，返回0
        if (prices == null || prices.length < 2) {
            return 0;
        }
        int minBuyPrice = prices[0]; // 初始化最小买入价格为第一天的价格
        int maxProfit = 0; // 初始化最大利润为0
        // 从第二天开始遍历（因为至少需要两天才能完成一次买卖）
        for (int i = 1; i < prices.length; i++) {
            // 当前价格作为可能的卖出价格
            int currentPrice = prices[i];
            // 计算如果今天卖出的利润：当前价格 - 历史最低买入价
            int currentProfit = currentPrice - minBuyPrice;
            // 更新最大利润：取历史最大利润和当前利润的较大值
            if (currentProfit > maxProfit) {
                maxProfit = currentProfit;
            }
            // 更新历史最低买入价：取历史最低价和当前价格的较小值
            // 注意：这个更新必须在计算利润之后，因为买卖必须在不同天
            if (currentPrice < minBuyPrice) {
                minBuyPrice = currentPrice;
            }
        }
        return maxProfit;
    }
}
```

## [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)[中等]✅

**题目：**给你一个非负整数数组 `nums` ，你最初位于数组的 **第一个下标** 。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标，如果可以，返回 `true` ；否则，返回 `false` 。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764609928542-63dd73b4-5ff9-47ea-8782-b7f8923d3a14.png)

**思路：**这个问题可以用一种"从后往前"的思路来解决：

1. **如果我们知道某个位置能到达终点，那么这个位置就成了新的"终点"**

- 比如最后一个位置本身就是终点
- 如果倒数第二个位置能跳到最后一个位置，那么问题就变成了：能否到达倒数第二个位置？

2. **逐步向前推进**

- 我们从倒数第二个位置开始，向前检查
- 如果某个位置能跳到当前的"目标位置"，就更新目标位置为这个位置
- 这样不断向前移动目标位置

最终如果目标位置变成了0，那么说明从位置0到最后一个位置是可达的

```java
class Solution {
    public boolean canJump(int[] nums) {
        // 初始化目标位置是数组的最后一个元素的下标
        int targetIndex = nums.length - 1;
        // 从倒数第二个元素开始逆序遍历数组
        for (int i = nums.length - 2; i >= 0; i--) {
            // 如果从当前位置到目标位置是可达的,那么更新目标位置为当前位置
            if (i + nums[i] >= targetIndex) {
                targetIndex = i;
            }
        }
        // 遍历完数组后，如果当前位置为0，说明从位置0到最后一个位置是可达的
        if (targetIndex == 0) {
            return true;
        }
        return false;
    }
}
```

## [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)[中等]✅

**题目：**给定一个长度为 `n` 的 **0 索引**整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。换句话说，如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处:

- `0 <= j <= nums[i]`
- `i + j < n`

返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764689927247-448902ee-9bd4-4e7c-aeea-a8becad84a1f.png)

**思路：**贪心算法，通过局部最优解得到全局最优解，

- 如果我们「贪心」地进行正向查找，即假设站在下标 i 位置时，可以跳 [0-num[i]] 步远，但是跳几步呢，我们应该要找到下一次能让你跳的更远的位置
- 例如，对于数组 [2,3,1,2,4,2,3]，初始位置是下标 0，从下标 0 出发，最远可到达下标 2。下标 0 可到达的位置中，下标 1 的值是 3，从下标 1 出发可以达到更远的位置，因此第一步到达下标 1。
- 从下标 1 出发，最远可到达下标 4。下标 1 可到达的位置中，下标 4 的值是 4 ，从下标 4 出发可以达到更远的位置，因此第二步到达下标 4。
- 在遍历数组时，只需要遍历到倒数第二个位置，最后一个位置是不需要再跳的

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764692006097-86495e17-634e-4173-a85c-b408c442118f.png)

**可参考思路讲解：**[45. 跳跃游戏 II](https://www.bilibili.com/video/BV1Y24y1r7XZ?spm_id_from=333.788.videopod.sections&vd_source=9297c4d03d5f37a56605a3cb4627b688)

具体实现：

- `curRangeEnd`：当前跳跃轮次的"访问权限边界"

- 不是"当前能跳多远"，而是"这一轮允许探索到哪里"
- 初始化0：第0轮只允许探索位置0

- `nextRangeEnd`：下一跳跃轮次的"能力边界"

- 在当前轮次遍历过程中，收集下一轮能跳到的最远处

- `jumps`：已执行的跳跃动作次数

- 从位置0到位置0：0次跳跃（起点）
- 从位置0跳到位置1：1次跳跃

```java
class Solution {
    public int jump(int[] nums) {
        // curRangeEnd：当前跳跃轮次能访问的最远位置（当前轮的右边界）
        // 初始化：从位置0开始第0轮，本轮只能访问位置0本身
        int curRangeEnd = 0;
        
        // nextRangeEnd：下一跳跃轮次能访问的最远位置（下一轮的右边界）
        // 在遍历过程中不断更新，记录所有可达位置中能跳到的最远处
        int nextRangeEnd = 0; 
        
        // jumps：已完成的跳跃次数
        // 注意：从位置0开始算作第0轮，第一次跳跃会将轮次从0变为1
        int jumps = 0;
        
        // 遍历数组，不包含最后一个位置
        // 原因：到达最后一个位置时游戏结束，不需要再跳
        for (int i = 0; i < nums.length - 1; i++) {
            // 更新下一轮能到达的最远位置
            // 当前位置i最远能跳到 i + nums[i]
            // 取最大值确保记录所有可达位置中最远的
            nextRangeEnd = Math.max(nextRangeEnd, i + nums[i]); 
            
            // 如果当前位置i等于当前轮次的右边界
            // 说明：已经遍历完当前轮次允许访问的所有位置
            // 此时必须做一次跳跃选择，进入下一轮
            if (i == curRangeEnd) {
                // 更新：下一轮允许访问的右边界
                // 这是基于当前轮次所有位置计算出的最远可达位置
                curRangeEnd = nextRangeEnd;
                
                // 完成一次跳跃，跳跃次数加1
                jumps++;
            }
        }
        
        return jumps;
    }
}
```

执行流程示例

```java
nums = [2, 3, 1, 1, 4]

初始化：
curRangeEnd = 0  (第0轮只能访问位置0)
nextRangeEnd = 0
jumps = 0

位置0 (i=0)：
nextRangeEnd = max(0, 0+2) = 2  // 下一轮最远能到2
i == curRangeEnd? 0 == 0 ✓     // 第0轮探索完毕
curRangeEnd = 2                // 第1轮可以访问[0,2]
jumps = 1                      // 完成第1次跳跃

位置1 (i=1)：
nextRangeEnd = max(2, 1+3) = 4  // 下一轮最远能到4
i == curRangeEnd? 1 == 2 ✗     // 还在第1轮探索中

位置2 (i=2)：
nextRangeEnd = max(4, 2+1) = 4  // 最远仍是4
i == curRangeEnd? 2 == 2 ✓     // 第1轮探索完毕
curRangeEnd = 4                // 第2轮可以访问[0,4]
jumps = 2                      // 完成第2次跳跃

位置3 (i=3)：循环跳过（因为i < nums.length-1）

结果：jumps = 2
路径：第0轮(位置0) → 第1轮(位置1) → 第2轮(位置4)
```

## [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)[中等]✅

**题目：**给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s` 。

返回一个表示每个字符串片段的长度的列表。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1764696070073-8e5a1a4a-2c41-45eb-9261-4a62463a9760.png)

**思路：**由于同一个字母只能出现在同一个片段，显然同一个字母的第一次出现的下标位置和最后一次出现的下标位置必须出现在同一个片段。

1. **记录每个字母最后出现的位置：**扫描一遍字符串，记录每个字母最后一次出现的位置
2. **开始划分片段，动态扩展当前片段（start、end）的边界end**

- 从左到右扫描字符串
- 对于每个字符，查看它的最后出现位置
- 不断扩展当前片段的结束位置
- 当走到当前片段的边界时，就完成了一个片段，

3. 置start=end+1后，继续寻找下一个片段

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        // 步骤1：记录每个字母最后出现的位置，last[0]存'a'最后出现的位置，last[1]存'b'最后出现的位置...
        int[] last = new int[26];
        int length = s.length();
        // 遍历字符串，更新每个字母的最后出现位置
        for (int i = 0; i < length; i++) {
            // s.charAt(i) - 'a'：将字母转换为0-25的数字，比如'a'->0, 'b'->1, ..., 'z'->25
            last[s.charAt(i) - 'a'] = i;
        }
        
        // 存储结果的列表
        List<Integer> partition = new ArrayList<Integer>();
        
        // 当前片段的起始位置和结束位置
        int start = 0;  // 当前片段的开始索引
        int end = 0;    // 当前片段的结束索引（动态扩展）
        
        // 步骤2：划分片段
        for (int i = 0; i < length; i++) {
            // 查看当前字符的最后出现位置
            // 扩展当前片段的边界：取当前边界和当前字符最后位置中的较大值
            end = Math.max(end, last[s.charAt(i) - 'a']);
            
            // 如果当前位置i等于当前片段的边界end
            // 说明：1. 已经走到了当前片段能到达的最远位置
            //      2. 当前片段内所有字符的最后出现位置都 <= end
            //      3. 可以安全地划分这个片段了
            if (i == end) {
                // 计算当前片段的长度并加入结果
                // 长度 = 结束位置 - 开始位置 + 1
                partition.add(end - start + 1);
                
                // 开始下一个片段：从当前位置的下一个位置开始
                start = end + 1;
            }
        }
        return partition;
    }
}
```
