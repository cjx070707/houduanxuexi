## [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)[简单]✅

**题目：**假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765126269324-95532489-3020-479a-8b70-cd2d870b0bc7.png)

**思路：**动态规划，**可参考思路讲解：**[**70. 爬楼梯**](https://www.bilibili.com/video/BV1h1421t7W3/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

- n=1 → 1 种
- n=2 → 2 种
- n=3 → 3 种（刚好是 n=2 的方法数 + n=1 的方法数：2+1=3）
- n=4 → 5 种（刚好是 n=3 的方法数 + n=2 的方法数：3+2=5）
- n=5 → 8 种（5+3=8）

观察规律 **爬到 n 阶的总方法数 = 爬到 n-1 阶的方法数 + 爬到 n-2 阶的方法数**。

- 递推公式：dp[n] = dp[n-1] + dp[n-2]
- 边界条件：dp[0] = 1，dp[1] = 1

```java
class Solution {
    public int climbStairs(int n) {
        // 保存子问题的解
        int[] dp = new int[n + 1];
        dp[0] = 1;
        dp[1] = 1;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        return dp[n];
    }
}
```

## [118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/)[简单]✅

**题目：**给定一个非负整数 `numRows`*，*生成「杨辉三角」的前 `numRows`行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765209884286-f5e1abdc-3a85-4a06-abdd-45f78066e41e.png)

**思路：**动态规划，**可参考思路讲解：**[**118. 杨辉三角**](https://www.bilibili.com/video/BV11qM6zZEsV/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

先将杨辉三角变成下图这种形式，观察规律：

- 每一行的第一个元素和最后一个元素都是固定为1
- 每一行除了第一个元素和最后一个元素之外的其他元素=其上方元素+其左上方元素

从上往下逐行生成数值即可

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765210000214-05f4cd72-09d1-458d-909e-c38c3780d680.png)

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> res = new ArrayList<>();
        // 处理第一行的情况，杨辉三角第一行只有一个元素1
        List<Integer> firstRow = new ArrayList<>();
        firstRow.add(1);
        res.add(firstRow);
        // 从第二行开始遍历生成（i表示当前要生成的是第i行，从2到numRows）
        for (int i = 2; i <= numRows; i++) {
            // 定义当前行的元素集合
            List<Integer> curRow = new ArrayList<>();
            // 每行的第一个元素都是1
            curRow.add(1);
            // 获取上一行的元素集合
            List<Integer> lastRow = res.get(res.size() - 1);
            // 生成当前行中间的元素（j表示当前行的第j个元素，从1到i-2，因为首尾都是1）
            for (int j = 1; j < i - 1; j++) {
                // 元素=其上方元素+其左上方元素
                curRow.add(lastRow.get(j - 1) + lastRow.get(j));
            }
            // 每行的最后一个元素都是1
            curRow.add(1);
            // 将当前行加入结果集合
            res.add(curRow);
        }
        // 返回杨辉三角结果
        return res;
    }
}
```

## [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)[中等]✅

**题目：**你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765210877504-3806e121-ab45-41c5-94bd-fd7845c246cf.png)

**思路：**动态规划，**可参考思路讲解：**[**198. 打家劫舍**](https://www.bilibili.com/video/BV1RwvoeaENG/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

以[1、2、3、1]为例，由于相邻的两间房不能同一晚偷窃

- 假设不偷窃最后一间房，那么偷盗 [1、2、3、1] 四间房屋的最大利润就变成了偷盗 [1、2、3] 三间房屋能获得的最大利润
- 假设偷窃最后一间房(那么倒数第二间就不能偷了)，那么偷盗 [1、2、3、1] 四间房屋的最大利润就变成了偷盗 [1、2] 两间房屋的最大利润 + 偷盗最后一间房屋所能获得的金额（即1）

偷盗[1、2、3]或者偷盗[1、2]都可以按上述递归下去求解，直到边界条件 :

- 偷盗 0 间房的最大利润为 0
- 偷盗第1间房的最大利润为num[0]

因此总结归纳规律，偷盗n间房的最大利润dp[n] = Math.max( `偷盗n-1间房的最大利润dp[n-1]`，`偷盗n-2间房的最大利润dp[n-2]+nums[n-1]`)，前者代表没有偷盗第n间房，后者代表偷盗了第n间房

- dp[i] 表示偷窃前 i 个房屋的最大金额
- 例如`dp[4] = max(dp[3]=4, dp[2]+nums[3]=2+1=3)` → `dp[4]=4`。

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        // 保存子问题的解, dp[i] 表示偷窃前i个房屋的最大金额
        int[] dp = new int[n + 1];
        dp[0] = 0;          // 前0个房屋，利润为0
        dp[1] = nums[0];    // 前1个房屋，利润为nums[0]
        for (int i = 2; i <= n; i++) {
            // 两种选择：
            // 1. 不偷第i个房屋，利润为dp[i-1]（前i-1个房屋的最大利润）
            // 2. 偷第i个房屋，利润为dp[i-2] + nums[i-1]（前i-2个房屋的最大利润 + 第i个房屋的金额，nums[i-1]对应第i个房屋）
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i-1]);
        }
        return dp[n];
    }
}
```

## [322. 零钱兑换](https://leetcode.cn/problems/coin-change/)[中等]✅

**题目：**给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765213482080-d17e3607-91a0-472e-8659-c876ae549116.png)

**思路：**动态规划，**可参考思路讲解：**[**322. 零钱兑换**](https://www.bilibili.com/video/BV19iMxzAEwj/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

dp[i] 表示兑换金额为 i 需要的硬币数量

而 dp[i] 如何求解呢？由于前几个的答案显而易见，先列举出 dp[0]=0、dp[1]=1、dp[2]=1、dp[3]=2

分析 dp[4] 具体如何求解呢？此时我们的coins可用的硬币为[1、2、5]

- 假设我们先选一枚 1元 硬币，那么剩下要凑的金额就是 4-1=3元，而凑出3元即dp[3](之前已经计算过了)，因此先选一枚 1元 硬币时，凑出4元=dp[i-coin]+1 这里的i=4，coin=1
- 假设我们先选一枚 2元 硬币，那么剩下要凑的金额就是 4-2=2元，而凑出2元即dp[2](之前已经计算过了)，因此先选一枚 2元 硬币时，凑出4元=dp[i-coin]+1 这里的i=4，coin=2
- 我们无法选择一枚5元硬币，因为5>4

因此 dp[4] = Min（dp[4-coin]）+1 ， coin 需要遍历coins集合中的所有硬币面值

因此通用的公式为 dp[i] = Min(dp[i-coin]) + 1 ， coin 需要遍历coins集合中的所有硬币面值

那么就是两层for循环，外层for循环求解出所有的dp[i]，内层for循环为了求出dp[i]，需要遍历所有icons

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765296771098-38eb6299-f229-4512-943d-eb7b5947734d.png)

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        // dp数组：dp[i]表示凑出金额i所需的最少硬币数
        // 初始化dp数组长度为amount+1,
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);
        // 边界条件：凑出金额0需要0个硬币
        dp[0] = 0;
        // 遍历每个金额（从1到amount），计算凑出该金额的最少硬币数，即求解dp[i]
        for (int i = 1; i <= amount; i++) {
            // 遍历coins中的每种硬币，尝试用当前硬币凑金额i
            int temp = amount + 1;  // temp 记录下遍历coins过程中得到的最少硬币数
            for (int j = 0; j < coins.length; j++) {
                // 如果当前硬币的面值 ≤ 金额i（说明可以用这个硬币），否则不能使用
                if (coins[j] <= i) {
                    // dp[i] = Min(dp[i-coin]) + 1 ， coin 需要遍历coins集合中的所有硬币面值
                    temp = Math.min(temp, dp[i - coins[j]] + 1);
                }
            }
            // 遍历完coins,求解出当前的dp[i]
            dp[i] = temp;
        }
        // 如果最终dp[amount]还是初始值（amount+1），说明无法凑出该金额，返回-1；否则返回最少硬币数
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

## [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)[中等]✅

**题目：**给你一个整数 `n` ，返回 *和为* `n` *的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765298091377-9a932186-4695-4b05-95c6-466f80d84bf9.png)

**思路：**动态规划，**可参考思路讲解：**[**279. 完全平方数**](https://www.bilibili.com/video/BV12mNtzQEhh/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)（这里代码没有用视频里的方法,代码和上题零钱兑换一致）

dp[i] 表示和为 i 的完全平方数的最少数量

这题和零钱兑换是一样的思路，这里的n即是零钱兑换的amount，这里的coins是[1的平方、2的平方、3的平方...]

举例：假设n=5，即要求解dp[5]，我们可以使用的数的范围应该是从[1,根号5向下取整]，即能使用[1,2]（3的平方就超过5了），此时

- 假设我们先使用 1的平方 那么剩下要凑的就是 5-1 = 4 即dp[4]，前面使用了1的平方，因此要+1
- 假设我们先使用 2的平方 那么剩下要凑的就是 5-2 = 3 即dp[3]，前面使用了2的平方，因此要+1

那么dp[5] = Min(dp[5-j]) +1 , 其中 j 需要遍历 集合[1,2]

因此通用的公式为 dp[i] = Min(dp[i-j]) + 1 ， j 需要遍历集合[1,根号i向下取整]

```java
class Solution {
    public int numSquares(int n) {
        // dp[i] 表示凑出数字i所需的最少完全平方数个数
        int[] dp = new int[n + 1];
        // 初始化：把所有位置设为n+1（n最多需要n个1²，n+1是“不可能的数”，代表暂时凑不出来）
        Arrays.fill(dp, n + 1);
        // 边界条件：凑出数字0需要0个完全平方数
        dp[0] = 0;
        // 遍历1~n的所有数字，逐个计算最少平方数个数
        for (int i = 1; i <= n; i++) {
            // 遍历所有≤i的完全平方数（相当于零钱兑换里的“硬币面值”）
            // 平方数的形式是j²，j从1开始，直到j² ≤ i
            int temp = n + 1; // 临时变量，记录当前i的最少平方数个数
            for (int j = 1; j * j <= i; j++) {
                int square = j * j; // 当前尝试的完全平方数
                // 状态转移：凑i的最少个数 = min(当前temp, 凑i-square的最少个数 + 1个当前平方数)
                temp = Math.min(temp, dp[i - square] + 1);
            }
            // 把计算好的最少个数赋值给dp[i]
            dp[i] = temp;
        }
        
        // 如果dp[n]还是初始值n+1，理论上不可能（因为1是完全平方数，总能凑出），返回dp[n]即可
        return dp[n];
    }
}
```

## [139. 单词拆分](https://leetcode.cn/problems/word-break/)[中等]✅

**题目：**给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：**不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765299573504-d424ab69-8ff0-47d8-9539-b31ca95436ef.png)

**思路：**BFS，**可参考思路讲解：**[**139. 单词拆分**](https://www.bilibili.com/video/BV1Au3JzuEDu/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

画出决策树进行分析，原问题就可以转换为，在这棵树中找到一个节点的值==s，即需要遍历这颗决策树

这里采用 BFS 的方法，从根节点开始逐层向下遍历

curLevel表示当前层的有效字符，nextLevel表示下一层的有效字符

在遍历完当前层后，需要将 nextLevel 赋值给 curLevel，看代码即可比较直白。举个例子

初始时curLevel即第一层即只有根节点[""]，向下分叉，尝试拼接字典里的所有单词生成下一层的字符串

得到["apple"]和["pen"]，因为["apple"]是s的前缀，所以加入nextLevel中，而["pen"]不是s的前缀，则不加入

以此类推，最终看能否找到s

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765301695430-6ee4ea7e-1c03-474a-948c-66283afb1888.png)

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        // 用Set存储当前层的状态（已拼接的子串），避免重复处理
        Set<String> curLevel = new HashSet<>();
        // 初始状态：空串
        curLevel.add("");
        // BFS循环：当前层非空时继续处理
        while (!curLevel.isEmpty()) {
            // 存储下一层的状态
            Set<String> nextLevel = new HashSet<>();
            // 遍历当前层的每个已拼接子串
            for (String str : curLevel) {
                // 如果当前子串等于目标字符串s，说明拆分成功
                if (str.equals(s)) {
                    return true;
                }
                // 尝试拼接字典中的每个单词
                for (String word : wordDict) {
                    // 拼接当前子串和字典单词，得到新子串
                    String temp = str + word;
                    // 检查：新子串长度不超过s，且是s的前缀（避免无效拼接）
                    if (temp.length() <= s.length() && temp.equals(s.substring(0, temp.length()))) {
                        // 符合条件的新子串加入下一层
                        nextLevel.add(temp);
                    }
                }
            }
            // 切换到下一层继续处理
            curLevel = nextLevel;
        }
        // 所有可能的拼接都完成，仍未匹配到s，返回false
        return false;
    }
}
```

## [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)[中等]✅

**题目：**给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765302167472-01f91dc0-607c-4d97-bee3-5efa22e9097b.png)

**思路：**动态规划，**可参考思路讲解：**[**300. 最长递增子序列**](https://www.bilibili.com/video/BV1RRvheFEog/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

dp[n] = 以第n个元素结尾的最长子序列。 以 nums = [1,4,3] 为例

- dp[0] = 1 (以1结尾的最长子序列：1)
- dp[1] = 2 (以4结尾的最长子序列：1、4)
- dp[2] = 2 (以3结尾的最长子序列：1、3)

我们来分析dp[2] 是怎么求解出来的，以此来推导递推公式

在nums = [1,4,3]中，分析3之前的数[1,4]，把3和前面的数作比较

- 3 比 1 大，所以dp[2] = dp[0] + 1
- 3 比 4 小，所以以4结尾的最长递增子序列和以3结尾的最长递增子序列就不相关

按照规律，dp[n] 的求解，需要 用 n 与 nums[] 中的 前 n-1个数进行比较

- 如果 nums[n] > nums[i] (其中i从0到n-1)，那么dp[n] = max{dp[i]} + 1 (其中i需要遍历从0到n-1)

边界条件：dp[0]=1

```java
class Solution {
    // 计算最长递增子序列的长度
    public int lengthOfLIS(int[] nums) {
        // dp数组：dp[i]表示以nums[i]结尾的最长递增子序列的长度
        // 初始化每个元素的最长子序列至少包含自身，所以默认值为1
        int[] dp = new int[nums.length];
        Arrays.fill(dp, 1);
        // 记录全局最长递增子序列的长度
        int maxRes = 1;

        // 遍历每个元素（作为子序列的结尾元素）
        for (int i = 0; i < nums.length; i++) {
            // 遍历当前元素之前的所有元素
            for (int j = 0; j < i; j++) {
                // 如果当前元素比前面的元素大，说明可以构成更长的递增子序列
                if (nums[i] > nums[j]) {
                    // 更新dp[i]：取当前值和“以nums[j]结尾的最长子序列长度+1”的较大值
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                    // 更新全局最长长度
                    maxRes = Math.max(maxRes, dp[i]);
                }
            }
        }
        // 返回全局最长递增子序列的长度
        return maxRes;
    }
}
```

## [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)[中等]✅

**题目：**给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765302252307-15269c28-81d9-418e-9edb-fa23de030452.png)

**思路：**动态规划，**可参考思路讲解：**[**152. 乘积最大子数组**](https://www.bilibili.com/video/BV1qM4m1Q7nZ/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

以[1,2,3,4]举例

- 以1结尾的连续子数组的最大乘积值为1，记为dp[0]
- 以2结尾的连续子数组的最大乘积值为2，记为dp[1]
- 以3结尾的连续子数组的最大乘积值为6，记为dp[2]
- 以4结尾的连续子数组的最大乘积值为24，记为dp[3]

观察规律，可以发现规律，dp[3] = dp[2] x nums[3]，因此dp[n] = dp[n-1] x nums[n]

但是如果数组中存在负数，例如[-1,-2,-3,-4]举例

- 以-1结尾的连续子数组的最大乘积值为-1，记为dp[0]
- 以-2结尾的连续子数组的最大乘积值为2，记为dp[1]
- 以-3结尾的连续子数组的最大乘积值 如果按照上面的公式应该是 dp[2] = dp[1] x nums[2] = -6，但实际上以-3结尾的连续子数组的最大乘积值应该是 -2x-3 = 6，因此可知前面推导的公式是不适用于存在负数的情况，因为当前数是-3，如果已知前面的最小乘积值，且最小乘积值是负数 和 -3 相乘 就能得到一个更大的数

因此其实在动态规划时需要同时维护以第i个元素结尾的连续子数组的最大乘积值和最小乘积值

- cur\_max[i]：代表以第i个元素结尾的连续子数组的最大乘积值
- cur\_min[i]：代表以第i个元素结尾的连续子数组的最小乘积值

由上述示例，可推导出 cur\_max 和 cur\_min 的规律如下：

- cur\_max[n] = Math.max { cur\_max[n-1] x nums[n] , cur\_min[n-1] x nums[n] ， nums[n] }
- cur\_min[n] = Math.min { cur\_max[n-1] x nums[n] , cur\_min[n-1] x nums[n] ， nums[n] }

边界条件：cur\_max[0] = nums[0]、cur\_min[0] = nums[0]

```java
class Solution {
    public int maxProduct(int[] nums) {
        // 存储全局的最大乘积结果
        int maxRes = nums[0];
        // curMax：当前子数组的最大乘积；curMin：当前子数组的最小乘积
        // （因为负数×负数可能得到大的正数，所以需要同时维护最大和最小）
        int curMax = nums[0];
        int curMin = nums[0];

        // 从第2个元素开始遍历数组
        for (int i = 1; i < nums.length; i++) {
            // 临时保存遍历前的curMax和curMin（避免后续计算时被覆盖）
            int tempMax = curMax;
            int tempMin = curMin;

            // 计算当前的最大乘积：有三种可能
            // 1. 之前的最大乘积 × 当前元素
            // 2. 之前的最小乘积 × 当前元素（负数×负数可能变大）
            // 3. 仅当前元素（重新开始一个子数组）
            curMax = Math.max(Math.max(tempMax * nums[i], tempMin * nums[i]), nums[i]);

            // 计算当前的最小乘积：同理，有三种可能
            // 1. 之前的最大乘积 × 当前元素
            // 2. 之前的最小乘积 × 当前元素
            // 3. 仅当前元素
            curMin = Math.min(Math.min(tempMax * nums[i], tempMin * nums[i]), nums[i]);

            // 更新全局最大乘积
            maxRes = Math.max(maxRes, curMax);
        }

        return maxRes;
    }
}
```

## [416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)[中等]✅

**题目：**给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765302298132-d13671da-2424-4be4-9462-3f2d8b95d3f7.png)

**思路：**动态规划，**可参考思路讲解：**[**416. 分割等和子集**](https://www.bilibili.com/video/BV1q9NJz1EjR/?spm_id_from=333.337.search-card.all.click&vd_source=9297c4d03d5f37a56605a3cb4627b688)

nums所有元素之和为偶数，才有可能使得数组分割成两个子集且两个子集的元素和相等

若nums所有元素之和为奇数，则不可能达成目的

因此问题可以转化为可否在数组中找到子集，其子集元素和=数组所有元素和的一半

**以 nums=【1,1,2】举例，**所有元素之和 = 4，那么要找的子集的元素和 = 4/2 = 2

现在的问题就是如何找到 元素和为 2 的子集，通过画 (子集的) 决策树来分析

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765388505284-31a87428-1c48-41c4-a556-d5e37f373659.png)

dp[i] ：和为i的子集是否存在

当前这个例子中，需要找到的是 和为2的子集是否存在，即dp[2]，所以只需要定义dp[]的长度为3即可

然后从根节点开始，一层一层向下搜索值为2的叶子节点是否存在，同时更新dp数组，如上图所示

- 边界条件：dp[0] = True

```java
class Solution {
    public boolean canPartition(int[] nums) {
        // 计算数组所有元素的总和
        int totalSum = 0;
        for (int num : nums) {
            totalSum += num;
        }
        // 如果总和是奇数，无法分成两个相等的子集，直接返回false
        if (totalSum % 2 != 0) {
            return false;
        }

        // 目标：找到子集的和等于总和的一半
        int target = totalSum / 2;

        // dp[i]表示：能否凑出和为i的子集
        // 初始化dp数组，长度为target+1，默认值为false
        boolean[] dp = new boolean[target + 1];
        // 边界条件：和为0的子集一定存在（选空集）
        dp[0] = true;

        // 遍历每个数字，尝试用它来更新dp数组
        for (int num : nums) {
            // 临时数组dpTmp：避免在遍历中覆盖原dp的值
            boolean[] dpTmp = new boolean[target + 1];
            // 先把原dp的值复制到临时数组（保持已有的可能的和）
            System.arraycopy(dp, 0, dpTmp, 0, target + 1);

            // 遍历所有可能的和i
            for (int i = 0; i <= target; i++) {
                // 如果当前能凑出和i，且i+num不超过目标值
                if (dp[i] && i + num <= target) {
                    // 那么i+num也能被凑出，标记为true
                    dpTmp[i + num] = true;
                }
            }
            // 用临时数组更新dp
            dp = dpTmp;
            // 提前剪枝：如果已经能凑出target，直接返回true
            if (dp[target]) {
                return true;
            }
        }
        // 最终判断是否能凑出target
        return dp[target];
    }
}
```

## [32. 最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)[困难]✅

**题目：**给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

![](https://cdn.nlark.com/yuque/0/2025/png/54710028/1765302318014-1db1af9e-dcad-420c-a227-1ff26b2637ab.png)

**思路：**动态规划，**可参考思路讲解：**[**32. 最长有效括号**](https://www.bilibili.com/video/BV1fYKKz1E3A?spm_id_from=333.788.player.switch&vd_source=9297c4d03d5f37a56605a3cb4627b688&trackid=web_related_0.router-related-2206419-t6cb9.1765387768878.232)

- 以 s = ") ( ) ( ) ) ( ( ) )" 为例，当前字符串s有十个字符，先定义一个与字符串长度一致的boolean数组marks
- marks 数组的作用是 用来记录 括号是否合法
- 判断括号的正确性一般是使用栈，我们遍历一遍字符串，当遇到左括号时就压栈，遇到右括号就弹栈
- 第0个位置为右括号 当前stack为空，没有与其匹配的左括号，于是继续遍历字符串s的下一个位置
- 下一个位置为左括号，于是把其对应的索引压到栈中 stack={1}，继续遍历下一个位置(索引2)为右括号
- 当前栈顶有一个左括号与其匹配，弹栈，这两个括号的索引分别是1和2，于是把marks[1]和marks[2]置为true
- 继续遍历，以此类推，最终 marks[]的结果为 False、True、True、T、T、F、T、T、T、T
- 最终只需要遍历marks数组，找到最长的连续的True子数组即可，其长度即为答案

```java
class Solution {
    public int longestValidParentheses(String s) {
        // 栈：存储'('的索引（用于匹配')'）
        Stack<Integer> stack = new Stack<>();
        // marks数组：标记字符串中每个位置是否属于有效括号对
        boolean[] marks = new boolean[s.length()];

        // 第一步：遍历字符串，标记有效括号对的位置
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                // 遇到'(', 把它的索引压入栈
                stack.push(i);
            } else {
                // 遇到')'，尝试匹配栈中的'('
                if (!stack.isEmpty()) {
                    // 栈非空，说明有对应的'('，取出其索引
                    int leftIndex = stack.pop();
                    // 标记当前')'和对应的'('的位置为有效
                    marks[i] = true;
                    marks[leftIndex] = true;
                }
                // 栈空则说明当前')'无法匹配，不处理
            }
        }
        // 第二步：遍历marks数组，统计最长连续有效的长度
        int maxLen = 0;   // 记录最长有效长度
        int curLen = 0;   // 记录当前连续有效长度
        for (boolean mark : marks) {
            if (mark) {
                // 当前位置有效，连续长度+1，并更新最长长度
                curLen++;
                maxLen = Math.max(maxLen, curLen);
            } else {
                // 当前位置无效，重置连续长度
                curLen = 0;
            }
        }
        return maxLen;
    }
}
```
